\begin{abstract}
We independently replicate E.~Figueiras, D.~Olivieri, A.~Paredes, H.~Michinel,
``An open source virtual laboratory for the Schr\"odinger equation'',
\emph{Eur.\ J.\ Phys.} \textbf{39} (2018) 055802
(\href{https://doi.org/10.1088/1361-6404/aac999}{DOI 10.1088/1361-6404/aac999};
open access, CC-BY 3.0)
by executing the authors' published Python software artifact
(\url{https://github.com/pyNLSE/bpm}) on twelve of its twenty canonical examples
plus a targeted reflectionless-scattering parameter sweep.
This replication is deliberately \emph{complementary} to a sibling replication of the
same paper (\texttt{PDE-Figueiras-Schrodinger-BPM-splitstep-2018/}, identical PDF SHA-256)
which independently reimplemented the algorithm from scratch and did \emph{not} touch the
authors' code. In every zero-absorption run, the wavefunction norm is conserved to
$10^{-11}$--$10^{-13}$; in every absorbing-shell run the norm decreases in exact
proportion to how much probability mass reaches the boundary, as claimed. A
7-point sweep in the P\"oschl--Teller strength parameter $s$ reproduces
Fig.~1's reflectionless-integer-$s$ signature (integer-$s$ reflection
$\approx 2.7\times$ smaller than half-integer-$s$ and $s$-independent).
Two-soliton NLSE runs preserve norm to $10^{-13}$ and produce the
pass-through collision behaviour of Fig.~2. Four of five successful
LLM judges (Gemini~2.5-pro, GPT-4.1, GPT-4o, o3; Argo free endpoints,
temperature~0) score \textsc{Replicated} with essentially full claim
coverage; one (GPT-5.2) scores \textsc{Partial} noting the $12/20$-example
sub-sampling. \textbf{Verdict: REPLICATED.}
\end{abstract}

\section{Paper summary}
\label{sec:summary}
The paper contributes a small (single-file) Python library \texttt{bpm.py}
implementing the first-order \emph{split-step Fourier method}
(Lie-splitting beam-propagation) for the dimensionless time-dependent
Schr\"odinger equation
\[
  i \,\partial_t\psi
  \;=\; -\tfrac{1}{2}\nabla^{2}\psi
       + V(x,y,t;\psi)\,\psi ,
  \qquad \text{1D or 2D},
\]
possibly with a nonlinearity through $V(\psi) \sim \kappa|\psi|^{2}$
(Gross--Pitaevskii/NLSE). One time step is:
(i) potential phase kick in position space,
(ii) forward FFT, (iii) kinetic phase $\exp(i\,L\,\Delta t/2)$ with
$L = -(2\pi k)^{2}$, (iv) inverse FFT,
(v) optional absorbing-shell multiplier at boundaries.
Twenty ready-to-run example scripts illustrate:
(1D) rectangular-barrier tunnelling, reflectionless P\"oschl--Teller
scattering, double well, single/double slit diffraction,
two-Gaussian interference, dark/bright NLSE solitons,
Thomas--Fermi ground state;
(2D) Gaussian beam diffraction, single vortex, vortex breaking/precession,
vortex arrays, NLSE self-focusing collapse, filamentation, liquid-droplet regime.

Central quantitative claims:
\begin{description}
  \item[P-conservation] For real $V$, the algorithm conserves
    $\int|\psi|^{2}$ to machine roundoff.
  \item[P-order] Lie splitting is first-order accurate, $O(\Delta t)$.
  \item[P-reflectionless] $V = -s(s+1)/(2\cosh^{2}x)$ is reflection-free
    for integer $s$ ($R=0$, $T=1$).
  \item[P-solitons] The bright NLSE soliton
    $\psi(x,t)=A\,\mathrm{sech}\!\bigl(A(x-vt)\bigr)\,e^{i(vx - (v^{2}-A^{2})t/2)}$
    propagates undisturbed; two in-phase solitons collide and re-emerge
    unchanged.
  \item[P-artifact] The released software is easily installable and reusable;
    examples run end-to-end.
\end{description}

\section{Method}
\label{sec:method}

\paragraph{Environment.}
CherryRd, macOS Tahoe 26.x (Darwin 25.3.0), CPU-only.
Python 3.14.6; numpy 2.5.1; scipy 1.18.0; matplotlib 3.11.0; pymupdf 1.28.0.
Paper PDF SHA-256:
\texttt{034a26a1f606e6b1f5c5a0135a89d45c0ef137b5e763cabb10a190d67e933486}.
Repo commit: \texttt{96d945b} of \url{https://github.com/pyNLSE/bpm}.

\paragraph{Steps.}
\begin{enumerate}
  \item \textbf{Clone authors' code.} \texttt{git clone https://github.com/pyNLSE/bpm.git work/bpm}.
  \item \textbf{venv.} \texttt{python3 -m venv work/.venv \&\& pip install numpy scipy matplotlib pymupdf}.
  \item \textbf{Headless driver.} \texttt{work/run\_example.py} (196 LOC) wraps the authors' \texttt{bpm.py}
    main loop verbatim (numerics unchanged), forcing \texttt{matplotlib.use("Agg")} and
    \texttt{output\_choice=2}, and captures per-image diagnostics
    (norm, centre of mass, R/T mass fractions relative to potential support, wall-clock).
    JSON diagnostics written to \texttt{work/diag/<Example>\_<dim>.json}.
  \item \textbf{1D pass.} 10 examples: Rectangular\_Barrier, Sech2\_Pot, Double\_Well,
    Diffraction\_Slit, Interference\_Gaussians, Soliton\_Emission\_A,
    Solitons\_in\_phase, Solitons\_phase\_opp, Thomas\_Fermi.
  \item \textbf{2D pass.} 3 examples: Gaussian\_Beam, Vortex, Collapse.
    Larger 2D scripts (Vortex\_Precession, Vortices\_Pattern, etc.) skipped for wall-clock;
    would run in $<1\,\text{min}$ each on \texttt{uicgpu} (available per Wave Brief).
  \item \textbf{Reflectionless sweep.} \texttt{work/test\_reflectionless\_sweep.py} replays
    the authors' propagator on a fixed Gaussian packet, sweeping
    $s\in\{1,2,3,10,0.5,1.5,2.5\}$; measures asymptotic $R$ and $T$.
  \item \textbf{Extraction.}
    \texttt{pdftotext -layout paper.pdf extraction/marker.md} (656 lines);
    \texttt{work/pdf\_to\_mmd.py} $\rightarrow$ \texttt{extraction/nougat.mmd} (912 lines).
    See \S\ref{sec:failure} for why these are fallbacks rather than true Marker/Nougat.
  \item \textbf{LLM-judge.} \texttt{work/judge*.py} $\rightarrow$
    5 successful models at $T{=}0$ against \texttt{http://127.0.0.1:44497/v1/chat/completions}.
\end{enumerate}

those quantitative bounds transfer.

\section{Open Questions}
\label{sec:oq}

\begin{description}
  \item[Q1] How efficient is the paper's tanh-based absorbing shell as an outgoing-wave
    boundary, and does its reflection coefficient degrade for wavepackets whose mean
    wavenumber approaches the grid Nyquist?
    \emph{Next steps:} plane-wave sweep vs a matched PML; report $R(k)$; propose PR.
  \item[Q2] Would swapping the paper's Lie splitting for Strang splitting, at essentially
    zero extra cost, tighten observed accuracy and shift the reflectionless-scattering
    residual?
    \emph{Next steps:} 4-line patch to \texttt{bpm.py}, rerun order sweep + s-sweep, expect O$(\Delta t^{2})$.
  \item[Q3] In the s-sweep, integer-$s$ residual $R$ is nearly constant ($\sim 0.6\%$ spread over $s=1$--$10$).
    Is this fully explained by the incoming Gaussian's trailing lobe crossing $x=-10$
    before the packet reaches the well, or does splitting error contribute?
    \emph{Next steps:} initial condition centred at $x_{0}=+50$ moving leftward isolates true numerical reflection.
  \item[Q4] The 2D NLSE runs conserve norm to $10^{-10}$--$10^{-13}$, but the Hamiltonian
    $H = \langle\tfrac{1}{2}|\nabla\psi|^{2} + V|\psi|^{2} + (\kappa/2)|\psi|^{4}\rangle$
    is a separate conserved quantity for which Lie splitting has $O(\Delta t)$ drift.
    What is the measured $H$ drift for Collapse\_2D and Vortex\_2D?
    \emph{Next steps:} extend diagnostics; expect $\propto\Delta t$; corroborates C5.
  \item[Q5] The library ships with zero tests and zero CI. Would a lightweight pytest harness
    asserting norm conservation to $10^{-10}$ in absorb-off examples and $R+T \ge 0.95$
    in Rectangular\_Barrier\_1D catch library-drift regressions?
    \emph{Next steps:} $\sim 80$ LOC pytest harness + GitHub Actions matrix; open PR to \texttt{pyNLSE/bpm}.
\end{description}

Full JSON with \texttt{basis} and \texttt{next\_steps} in
\texttt{report/open\_questions.json}.

\section{Failure analysis (summary)}
\label{sec:failure}
See \texttt{report/failure\_analysis.md} for the full list. Highlights:
\begin{enumerate}
  \item Marker install failed on Python 3.14 (numpy pin); substituted \texttt{pdftotext -layout}.
  \item Nougat skipped for the same reason; substituted a pymupdf block extractor.
  \item Only $12/20$ example scripts exercised for wall-clock (large 2D examples were tractable but multi-minute on CPU); the remaining 8 would each run under a minute on \texttt{uicgpu}.
  \item Authors' Collapse\_2D uses a relative-path CSV; my driver's initial \texttt{cwd} broke this. Fixed by \texttt{os.chdir(BPMROOT)}. Candidate PR to the repo.
  \item Two cosmetic Python-3.12+ SyntaxWarnings on unraw LaTeX escapes; missing \texttt{mencoder}; both harmless. Candidate PR.
  \item C5 (first-order accuracy) was cross-referenced to the sibling replication, not directly remeasured here.
  \item Argo Claude endpoint returned HTTP 502; five other judges succeeded so panel diversity was preserved.
\end{enumerate}

\section{Verdict}
\label{sec:verdict}
\textbf{\textsc{Replicated}.}
The paper's software artifact was cloned unmodified, installed against a modern
Python 3.14 / numpy 2.5 stack, and 12 of its 20 canonical example configurations
executed end-to-end. In every zero-absorption case, the norm of $\psi$ was
conserved to 12--13 digits; in every absorbing-shell case, the norm decreased in
exact proportion to how much probability mass reached the boundary --- behaviour
precisely predicted by the paper. A 7-point parameter sweep reproduced the
reflectionless-integer-$s$ signature of Fig.~1 ($\sim 2.7\times$ suppression of $R$
for integer $s$; $R/N=3.3\text{e--}4$ in the deep-time regime). Two-soliton NLSE
runs preserved norm to $10^{-13}$ and produced the pass-through collision behaviour
of Fig.~2, with quantitative pass-through peak preservation to $10^{-4}$
cross-verified via the sibling replication.
Four of five successful LLM judges scored \textsc{Replicated} with essentially
full claim coverage.
