# Brief — Stim (Gidney 2021)

**What/why:** Independently replicate Gidney 2021 "Stim: a fast stabilizer circuit simulator" (Quantum 5, 497; arXiv:2103.02202). Stim's contribution is a fast Clifford/stabilizer-circuit simulator using an inverse-tableau trick (linear-time deterministic measurement instead of CHP's quadratic), 256-bit SIMD, and a Pauli-frame bulk sampler that amortizes an expensive reference sample across cheap batched shots. We `pip install`ed the public tool (Stim 1.16.0 + PyMatching 2.4.0), regenerated the paper's benchmark circuits via the public API (no paper code copied), and re-measured its headline performance and correctness claims — plus the canonical downstream use (surface-code decoding with PyMatching yielding a threshold). Verdict: **PARTIAL** — correctness, linear-scaling, bulk-amortization, and the ~1% surface-code threshold all reproduce cleanly; the analyze-time headline reproduces (10.7 s vs the paper's ~15 s), but the sustained 1 kHz full-shot rate does not (we measure ~0.15–0.24 kHz, ~4–7× short, attributable to hardware/version/memory-bound output).
