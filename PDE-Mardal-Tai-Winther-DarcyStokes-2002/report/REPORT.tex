\begin{abstract}
We independently re-implement the 9-DOF nonconforming H(div) triangular
finite element introduced by Mardal, Tai, and Winther (2002) for the
Darcy--Stokes / Brinkman problem
$(I-\varepsilon^2\Delta)u-\nabla p = f$, $\operatorname{div} u = g$,
and reproduce the paper's Table~5.1 convergence rates to within
$\pm 0.07$ (mean absolute deviation $0.024$) across
$\varepsilon\in\{1,2^{-2},2^{-4},2^{-8},0\}$ and
$h\in\{2^{-2},2^{-3},2^{-4},2^{-5}\}$.  The motivating
negative results for P2--P0, Crouzeix--Raviart, and Mini elements
(Tables~3.1, 3.3, 3.5, 3.6) are likewise reproduced.  \textbf{Verdict:
REPLICATED.}
\end{abstract}

\section{Paper summary}
The Darcy--Stokes problem on $\Omega\subset\mathbb{R}^2$ reads
\begin{equation}
    (I-\varepsilon^2\Delta)u-\nabla p = f,\quad
    \operatorname{div} u = g,\quad u|_{\partial\Omega}=0,
\end{equation}
with $\varepsilon\in[0,1]$.  For $\varepsilon=1$ this is Stokes plus a
mass term; for $\varepsilon=0$ it degenerates to mixed Poisson with
Neumann pressure BCs.  Robust well-posedness requires
$u\in H_0(\operatorname{div})\cap\varepsilon\cdot H^1_0$ under the
energy norm
$|||v|||^2_\varepsilon = \|v\|_0^2+\varepsilon^2\|Dv\|_0^2+\|\operatorname{div} v\|_0^2$.

The paper introduces the local space
\[
V(T)=\{v\in P_3(T)^2 : \operatorname{div} v\in P_0,\;
(v\cdot n)|_e\in P_1\;\forall e\subset\partial T\},\qquad
\dim V(T)=9,
\]
with DOFs $\int_e (v\cdot n)\tau^k\,d\tau$ ($k=0,1$) on each edge and
$\int_e v\cdot t\,d\tau$.  Global $V_h\subset H_0(\operatorname{div})$
but $V_h\not\subset H^1_0$ (only the tangential mean is continuous).
Pressure space $Q_h$ is piecewise constants.

\subsection{MTW element implementation from scratch}
\emph{Local $V(T)$.}  Parameterize $P_3^2$ by 20 monomial coefficients.
Build an 11-row constraint matrix $C\in\mathbb{R}^{11\times 20}$: 5
rows for $\operatorname{div} v\in P_0$ (compare $\operatorname{div}
v(x_i)$ against $\operatorname{div} v(x_0)$ at 6 $P_2$-unisolvent
sample points) and 6 rows for $(v\cdot n)|_e\in P_1$ (Vandermonde-set
$s^2$ and $s^3$ coefficients to zero on each edge).  Numerical
verification: $\operatorname{rank}(C){=}11$, $\dim\ker C=9$.  The
$9\times 20$ DOF matrix $M$ uses 5-point Gauss--Legendre for edge
integrals.  Basis $\Phi$ obtained via $M\Phi = I_9$ with $\Phi$
constrained to $\ker C$.  Self-test: DOF-of-basis identity to
$2.9\times 10^{-14}$; $\operatorname{div}\varphi_i$ constant to
$<10^{-12}$ per basis function.

\emph{Global assembly.}  3 DOFs per edge (mean-$n$, first-moment-$n$,
mean-$t$).  Global edge orientation fixed once as
$v_{\text{low}}{\to}v_{\text{high}}$ with
$n_{\text{glob}}{=}[t_1,-t_0]$.  Per-triangle sign transform
$R_T[e]\in\mathbb{R}^{3\times 3}$ maps global$\to$local DOFs; if
tangent agrees ($s_t{=}{+}1$) only $\pm$ on $n$-moments; if
$s_t{=}{-}1$ the $k{=}1$ first-moment mixes, giving
$\text{local}_{n_1}=2s_n\,\text{global}_{n_0}-s_n\,\text{global}_{n_1}$
(derived analytically from $s_{\text{local}}=1-s_{\text{global}}$).
12-point Dunavant degree-6 quadrature per triangle.  Boundary
condition: all 3 DOFs on each boundary edge set to zero.  One pressure
DOF pinned; final $p_h$ mean-corrected.

\subsection{Standard-elements sweep (P2-P0, CR, Mini)}
Assembled in scikit-fem, mesh built to match the paper's
negative-slope-diagonal convention.  SymPy manufactured solution and
right-hand side.  6-point quadrature for errors.  Rates by
least-squares slope of $\log(\text{rel-err})$ vs $\log h$.

\section{Verdict: REPLICATED}
\begin{enumerate}
\item The paper's central novel contribution (a new nonconforming
H(div) element yielding $\varepsilon$-uniform Darcy--Stokes
convergence) is quantitatively reproduced (C1, C3, C4).
\item The paper's motivating negative results for P2-P0, CR, and Mini
elements are independently reproduced (C2).
\item The theoretical bound
$|||u-u_h|||_\varepsilon\le c(h^2+\varepsilon h)\|u\|_2$ is
empirically consistent with the observed $\sim 1\to\sim 2$ energy-rate
transition (proxy for C5).
\item The replication is \emph{independent} in the strong sense: no
MTW code was inherited from the authors, and the k=1
orientation-dependent DOF transform was rederived from scratch.
\end{enumerate}

\section{Genuine critique}
\subsection*{Strengths}
\begin{itemize}
\item The paper's contribution is unusually crisp: a specific
$\dim{=}9$ local space whose two-moment normal DOFs and single mean
tangential DOF encode exactly the continuity needed for
$H(\operatorname{div})$-conformity without over-constraining
$H^1$-conformity.  This ``just enough continuity'' design is why
$\operatorname{div} V_h\subset Q_h$ holds and why the discrete
divergence-free subspace coincides with the analytic one.
\item Numerical tables are tight and reproducible.  Every rate we
computed agrees with the paper to within noise expected from a
different linear-solver stack, quadrature choice, and coefficient
basis.
\end{itemize}
\subsection*{Limitations and residual doubts}
\begin{itemize}
\item \textbf{No boundary-layer replication.}  Example 6.1 predicts
$O(h\varepsilon^{-1/2})$ energy convergence for solutions with a
boundary layer of width $\varepsilon$.  This is the more delicate
regime because it directly probes the $\varepsilon h$ term of the
error estimate; we did not test it.  A smooth manufactured solution
is a comparatively soft target.
\item \textbf{No condition-number / preconditioning study.}  The
paper is a stability-and-convergence paper, not a solver paper;
however, without a preconditioner analysis the practical utility of
the element at very small $\varepsilon$ (where the block operator
degenerates from elliptic in $H^1$ to elliptic in $H(\operatorname{div})$)
is not established here.
\item \textbf{Only one geometry.}  All experiments are on the unit
square meshed by uniform diagonally-split squares.  Robustness on
unstructured, anisotropic, or curved-boundary meshes is unverified.
\item \textbf{No 3D analogue.}  MTW 2002 is strictly a 2D construction.
A tetrahedral element with analogous properties is a separate,
harder problem (see Tai--Winther 2006 and successors).
\item \textbf{C7 (\S7 elliptic system extension) not tested.}
Reproducibility across the corollary problem class is claimed but not
independently verified here.
\end{itemize}
\subsection*{What a stronger replication would add}
A boundary-layer test (Example 6.1), an unstructured-mesh sweep, and a
block-diagonal preconditioner benchmark of the type advocated in later
Mardal--Winther work would upgrade this from ``central-claim
replication'' to ``robustness replication.''
