## Selection method

- **Score components** (max ~25): recency, citation tier, public-data signal (SRA/NCBI/Illumina/Nanopore/PacBio), workflow specificity (pangenome / phylogeny / AMR / plasmid / BGC / CRISPR), and single-organism title penalty for mega-surveys.
- **Hard excludes:** tool / infrastructure papers (RAST, BV-BRC, PATRIC, KBase, proGenomes), reviews / meta-analyses / protocols, mega-consortium surveys (HMP, Tara Oceans, Earth Microbiome), and title near-duplicates of the 19 done replications.
- **`repro_rationale`** starting with *abstract-implied* means the abstract didn't explicitly state SRA/BioProject accessions; verify in the paper body before BV-BRC submission.
- **BV-BRC workflow strings** are derived per-paper from abstract+title keyword signals. Most candidates exercise multiple BV-BRC services (Comprehensive Genome Analysis = assembly + RASTtk annotation + AMR + specialty genes; Comparative Systems = pan-genome / Proteome Comparison; Codon Tree = phylogeny; PlasmidFinder via Similar Genome Finder).
