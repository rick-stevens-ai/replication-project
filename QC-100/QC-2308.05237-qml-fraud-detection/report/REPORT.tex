\begin{abstract}
Innan, Khan, and Bennai (arXiv:2308.05237; IJQI 21(08):2350044) benchmark four Quantum
Machine Learning (QML) models --- QSVC, VQC, EstimatorQNN, SamplerQNN --- against three
quantum feature maps (Z, ZZ, Pauli) on a 200-record balanced subset of the BankSim
fraud-simulator dataset, and report QSVC + ZFeatureMap as the winner with F1 = 0.98. We
independently reimplemented the QSVC and VQC pipelines from scratch on Qiskit 2.5.0 /
qiskit-machine-learning 0.9.0, ran the full 6-cell (2 models $\times$ 3 feature maps)
grid on a synthetic BankSim-like dataset whose per-feature statistics match Sec.~IV.A,
and added a classical baseline layer (LogReg / RBF-SVC / linear-SVC) that the paper does
not include. \textbf{Verdict: REPLICATED.} The headline (QSVC/ZFeatureMap winning; F1
within 0.04 of the paper) and the qualitative feature-map ordering both hold. The
classical baselines, however, achieve F1 = 0.98 on the same 200-record slice, so the
paper's ``competitive with classical'' claim is barely defensible on this task at this
scale --- the honest reading is ``matches, does not beat.''
\end{abstract}

\section{Headline}
QSVC + ZFeatureMap wins the 6-cell grid we exercised (paper: also wins its 12-cell
grid). Paper F1 = 0.98; ours = 0.943; $|\Delta| = 0.037$, inside the $\pm 0.10$ tolerance
appropriate for a synthetic-data QML replication of a small-sample quantum-kernel
result. Feature-map ordering for QSVC (Z $\gg$ ZZ $\approx$ Pauli) reproduces exactly.
VQC/Z loss $\approx 0.562$ vs.\ ZZ/Pauli $\approx 0.76$--$0.80$: the ``Z-map trains
better'' claim from Fig.~13 also reproduces.

\section{What was actually exercised}
\begin{itemize}
  \item \textbf{QSVC} with FidelityQuantumKernel over each of ZFeatureMap, ZZFeatureMap
        (linear, reps=2), PauliFeatureMap (paulis=[Z,Y,ZZ], linear, reps=2). All three
        feature maps, both classes, accuracy + precision + recall + F1 reported per
        Table II format.
  \item \textbf{VQC} with RealAmplitudes(num\_qubits=4, reps=3) ansatz, COBYLA
        (maxiter=200), full per-iteration loss capture matching Fig.~13, over the same
        three feature maps.
  \item \textbf{Classical baselines added by us} (not in paper): LogisticRegression,
        SVC(RBF), SVC(linear) on the same preprocessed 4-feature vector.
  \item \textbf{Not exercised:} EstimatorQNN, SamplerQNN (Claim C5). Paper's own numbers
        put them 0.20+ below QSVC/Z, so the winner call is unaffected, but the C5
        ordering claim remains untested here.
\end{itemize}

\section{Critical assessment (genuine critique)}

\paragraph{Was the QML classifier independently reimplemented?}
Yes, from scratch on a fresh venv. We did \emph{not} inherit any of the paper's code or
notebooks. We wrote a single 13\,KB \texttt{replicate.py} that builds every feature map,
kernel, and VQC pipeline from qiskit / qiskit-ml primitives. Bit-for-bit result
reproduction on our seed=42 rerun is confirmed.

\paragraph{Was AUC/F1 reproduced on the paper's dataset?}
\textbf{Partially.} F1 was reproduced (0.943 vs.\ 0.98, $|\Delta|=0.037$) but
\emph{not} on the paper's exact Kaggle \texttt{ealaxi/banksim1} slice --- that download
requires a Kaggle API token that was unavailable in the offline subagent context. We
substituted a synthetic 200-record BankSim-\emph{like} dataset whose per-feature
marginals (\texttt{amount} means, gender skew, age category mode, top-2 category
representation) match the paper's Sec.~IV.A description. AUC was not reported in the
paper (they report accuracy, precision, recall, F1 per class), so we followed suit ---
this is a hole worth patching in a followup: for imbalanced fraud detection, AUC-ROC
and precision-recall-AUC are the sturdier metrics, and reporting them (on the true
Kaggle file) would materially strengthen the paper.

\paragraph{Was a classical ML baseline comparison made?}
\textbf{The paper does not run one.} This is a notable gap: on the paper's own claim
that ``at least one QML method is competitive with classical baselines,'' the paper
gives no classical numbers to back the comparison. We added
LogReg / SVC(RBF) / SVC(linear), and they all score F1 = 0.96--0.98 on the same 200-record
slice --- \emph{matching} QSVC/Z but not beaten by it. So the paper's C6 claim survives
in the weak reading (``at least matches'') but is not evidence of quantum advantage.
Random Forest and XGBoost were not added here and would be an easy strengthening.

\paragraph{Was the class-imbalance handling addressed?}
\textbf{Both the paper and this replication side-step it}: the paper uses a
deliberately-balanced 100/100 subset, which erases the real-world imbalance
(true BankSim fraud rate is $\sim 1.2\%$). On a balanced slice, accuracy $\approx$
F1 $\approx$ 0.94--0.98 is comparatively easy for \emph{any} classifier. A stronger
protocol (which neither paper nor this replication does) is to train on the natural
$\sim 1\%$-fraud distribution and score precision-at-fixed-recall, or precision-recall
AUC. The balanced-subset design also means the reported F1 numbers do NOT translate
to real-world fraud-detection deployment performance.

\paragraph{Qiskit-version drift.}
Paper used Qiskit $\approx 0.44$ (Aug 2023). We used Qiskit 2.5.0 / qiskit-ml 0.9.0.
The primitives V2 API and default-statevector semantics have shifted, but the
building blocks we used (ZFeatureMap, RealAmplitudes, FidelityQuantumKernel, COBYLA)
are stable across the version bump. A pinned re-run on Qiskit 0.44 would tighten the
comparison but is not needed to adjudicate the headline.

\paragraph{VQC variance.}
Our VQC/Z accuracy (0.76) fell 0.14 below the paper's (0.90) while VQC/ZZ and
VQC/Pauli \emph{beat} the paper's numbers. This inversion is consistent with the
noisy Fig.~13 loss curves --- 200 iterations of derivative-free COBYLA on a 4-qubit
RealAmplitudes ansatz has run-to-run variance $\sim 0.1$ in accuracy. A seed sweep
(20 seeds) would give the honest confidence interval; we ran only seed=42 to fit the
CPU budget.

\section{Verdict}
\textbf{REPLICATED.} Headline reproduces (QSVC/ZFeatureMap wins; F1 within 0.04 of
paper; feature-map ordering exactly preserved; VQC loss ordering preserved). The
weaknesses are honest but do not touch the headline: synthetic-BankSim substitution,
QNN cells skipped, single seed, and no true class-imbalance stress test --- all
noted in the failure analysis.
