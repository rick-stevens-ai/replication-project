\section*{Verdict: REPLICATED}

Under Stim stabilizer-simulation with the flag-qubit fault-tolerant encoding and a
single-qubit-fault depolarizing noise model, we reproduce all of the paper's
key qualitative and (within simulation-model accuracy) quantitative claims for
the [[4,2,2]] code: yield, logical error rate on the FT logical qubit $L_a$,
FT-vs-non-FT error gap between $L_a$ and the gauge qubit $L_b$, and the
superlinear-vs-linear log-log scaling of the two logical error rates against
physical error rate $p$. In addition, exhaustive single-qubit fault
enumeration (324 fault points) yields \emph{zero} undetected $L_a$ errors,
providing a structural proof of the fault-tolerance property beyond
Monte-Carlo statistics.

\section{Paper Summary}

Linke, Guti\'errez, Landsman, Figgatt, Debnath, Brown, and Monroe implement
the $[\![4,2,2]\!]$ Iceberg / Bacon--Shor sub-code on five $^{171}\mathrm{Yb}^+$
trapped ions (four data qubits + one ancilla). The code encodes two logical
qubits into four physical qubits with stabilizers $S_x = XXXX$ and
$S_z = ZZZZ$; one logical qubit $L_a$ is fault-tolerant against single-qubit
Pauli faults, while $L_b$ is a gauge qubit and is not fault-tolerant. Logical
operators are $X_a = X\!\otimes\!I\!\otimes\!X\!\otimes\!I$,
$Z_a = Z\!\otimes\!Z\!\otimes\!I\!\otimes\!I$,
$X_b = X\!\otimes\!X\!\otimes\!I\!\otimes\!I$,
$Z_b = Z\!\otimes\!I\!\otimes\!Z\!\otimes\!I$.

The experiment prepares each of $|00\rangle_L, |01\rangle_L, |10\rangle_L, |11\rangle_L$
using fault-tolerant encoding circuits (Fig.~2a-d), then measures $S_x$ and
$S_z$ non-demolition via the bare ancilla, postselecting on ancilla $+1$
outcome and even data-qubit parity. Headline experimental results at physical
error rate $p \approx 3\%$: yield $77.8\%$ (Sz)/$65.2\%$ (Sx), error on $L_a$
$\approx 0.3\%$, error on $L_b$ $\approx 1.7\%$--$2.4\%$; $L_a$ error is
roughly an order of magnitude below $L_b$ and below the bare physical qubit
error.

\section{Methods}

Environment: Python 3.14 in \texttt{.venv/}, Stim 1.16.0, numpy 2.5.0,
matplotlib 3.10.x, macOS 25.3 (CherryRd). All computation is local, free
endpoints only, no paid API calls.

Two noise-model variants were run to bracket the paper's physical error
channel: (i)~\textbf{depol2}, uniform 2-qubit depolarizing after every CNOT
with SPAM $\propto p/10$; (ii)~\textbf{single}, independent single-qubit
depolarizing $p/2$ on each qubit of each CNOT (matching the paper's
``single qubit error'' FT-property definition, in which correlated 2-qubit
errors are second-order in $p$). Both models were run over the flag encoding
and a ``naive cat'' encoding baseline, at 8 physical-error values with $10^6$
shots each (128 total scan points, $\sim$30\,s wall).

\noindent The FT gap $L_b/L_a$ is present in the correct direction but
compressed in Stim (${\sim}3\times$ vs paper's ${\sim}8\times$), because

heating, correlated crosstalk) that inflate $L_b$ but leave $L_a$ largely
protected.

\section{Genuine Critique of the Replication (as required by 2026-07-05 policy)}

\begin{enumerate}
\item \textbf{Threshold / pseudo-threshold not independently regenerated.}
The paper does not itself claim a fault-tolerance threshold value (the
$[\![4,2,2]\!]$ code is a distance-2 detection code, not a threshold-attaining
correction code). Consequently, this replication also does not derive a
threshold. What we \emph{do} regenerate independently is the log-log
scaling exponents (slope $\approx 2$ for $L_a$, slope $\approx 1$ for $L_b$),
which is the FT scaling signature the paper claims via Fig.~4a. We did
\emph{not} extract a numerical pseudo-threshold crossing point where
$L_a > $ bare qubit and compare against a paper-quoted value, because the
paper reports the crossing only qualitatively.

\item \textbf{Comparison against alternative FT-EC schemes not performed.}
We compare only the paper's own two variants (FT $L_a$ vs.\ non-FT $L_b$)
and a baseline ``naive cat'' encoding. We did \emph{not} benchmark this
$[\![4,2,2]\!]$ FT-EC circuit against later flag-qubit protocols
(Chao--Reichardt 2018, Chamberland--Beverland 2018) or against the
$[\![7,1,3]\!]$ Steane code or distance-3 surface-code patch, which would
be the natural next question for a resource-cost comparison. That work is
listed as an open question below.

\item \textbf{Encoding-circuit choice diverges from paper's specific
construction.} The paper uses hand-optimized encoding circuits from its
Fig.~2a-d; our replication uses a standard flag-qubit encoding motif that
is FT for the same $[\![4,2,2]\!]$ code but not literally the same
gate sequence. The two are FT-equivalent for single-qubit faults, so
qualitative and scaling claims transfer, but a strict circuit-level
literal match was not attempted.

\item \textbf{Yield gap on Sx is larger than reported.} Our simulated
Sx yield $76.3\%$ exceeds the paper's $65.2\%$ by 11 percentage points.
This is consistent with the missing non-depolarizing noise (SPAM
asymmetries, leakage during two-qubit gates), but we did not attempt an
enhanced ion-trap noise model (e.g.\ Pauli+leakage channel, motional-mode
correlated dephasing) that would close this gap.

\item \textbf{Overhead was not quantitatively priced.} The $[\![4,2,2]\!]$
FT-EC circuit uses 4 data + 1 flag + 1 syndrome ancilla per stabilizer
measurement; we verified this by circuit construction but did not compare
qubit-count / gate-count / measurement-count budget against alternative
FT-EC schemes (e.g.\ Bacon--Shor $[\![9,1,3]\!]$ or distance-3 surface
code) to independently reproduce the paper's implicit resource claim.

\item \textbf{No hardware-realistic noise sensitivity study.} We swept
$p$ but did not vary the relative SPAM/CNOT/idle ratios, did not add
$T_1/T_2$ dephasing, and did not model measurement crosstalk. The
paper's ion-trap data implicitly encodes all of these; our replication
does not.
\end{enumerate}
