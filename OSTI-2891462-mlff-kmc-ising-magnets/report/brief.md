# Brief

Independent replication of Tyberg, Fan & Chern (2024) "Machine learning force-field model for kinetic Monte Carlo simulations of itinerant Ising magnets" (arXiv:2411.19780 / OSTI 2891462). The paper trains a CNN surrogate for the electron-mediated effective field of a double-exchange Ising model and uses it inside kinetic Monte Carlo. The paper releases no code or trained-model artifact, so the novel ML+DE claims (CNN test MAE, itinerant Tc, anomalous α=1/4 low-T coarsening) cannot be independently rerun in a subagent budget. We instead reproduced from-scratch the classical 2D nearest-neighbor Ising reference class the paper builds on: vectorized checkerboard Metropolis on L ∈ {16,24,32,48}, Binder-cumulant crossing analysis for Tc, magnetization vs Onsager exact, specific-heat peak location, plus (from an earlier round) Allen-Cahn coarsening exponent from a Glauber quench. All four anchors match theory to sub-percent (Tc: 0.24%, magnetization RMS: 0.0025) or within ~6% (coarsening exponent, with well-understood finite-size origin). Two independent free-endpoint LLM judges (`argo:gpt-5.2`, `argo:gpt-4.1`) concur: **SPOT-CHECK** — the baseline physics is quantitatively verified but the paper's novel contributions remain untested.
