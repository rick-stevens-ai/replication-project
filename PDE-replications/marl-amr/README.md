# MARL-AMR Replication

Replication of **Yang et al., "Multi-Agent Reinforcement Learning for Adaptive Mesh Refinement", AAMAS 2023** ([arXiv:2211.00801](https://arxiv.org/abs/2211.00801), [code](https://github.com/LLNL/marl-amr)).

This was chosen as the canonical PDE-RL-AMR replication target after the originally-planned Foucart Deep-RL-AMR paper was confirmed to have no code release.

**TL;DR:** The headline claim of the paper — a learned MARL policy beats error-threshold heuristics on the cost/error Pareto frontier for adaptive mesh refinement on linear advection — **reproduces cleanly** using the pretrained checkpoint that ships with the repo. See `REPORT.md` for the full claim-by-claim table.

## Quick start

If you want to reproduce these numbers from scratch on a Linux host with conda:

```sh
# 1. On a Linux host with conda installed:
ssh <linux-host>
mkdir -p /scratch/marl-amr && cd /scratch/marl-amr

# 2. Pull the build script and run it (creates conda env, builds MFEM):
bash scripts/build_marl_amr_env.sh

# 3. Fix the crypt.h sysroot issue (one-time):
cp /usr/include/crypt.h \
   ~/miniconda3/envs/marlamr/x86_64-conda-linux-gnu/sysroot/usr/include/

# 4. Build the custom PyMFEM:
bash scripts/build_pymfem_step3.sh

# 5. Run the eval (VDGN + heuristic sweep + fixed-mesh baselines):
bash scripts/run_eval2.sh

# 6. Generate plots:
python3 scripts/make_plots.py
```

Total wall-clock on a 16-core Xeon: **~22 minutes**.

## Headline result

20 random Gaussian ICs on the paper's training distribution (16×16 periodic mesh, max_depth=1, t_final=0.75):

| Method | Mean DoF | Mean L2 error |
|---|---:|---:|
| **VDGN (pretrained)** | **5,349** | **0.0254** |
| Best error-threshold heuristic (h=1e-4) | 5,217 | 0.0289 |
| Uniform refinement (fixed fine) | 16,384 | 0.0244 |

VDGN matches uniform-refine error at **3× lower DoF** and beats every error-threshold heuristic at comparable DoF.

See `plots/pareto_dof_vs_error.png` for the main figure.

## Caveats / footguns we hit (and patched)

See `REPORT.md` §4 for full detail. Briefly:

1. **`crypt.h` missing in conda gcc sysroot** — Python 3.6 still `#include`s it; Ubuntu 20.04+ split it into `libxcrypt`. One-line fix.
2. **`pip install mfem==4.4.0.0` shadows the custom PyMFEM** — uninstall before custom build, or you get `ImportError: cannot import name 'ProlongToMaxOrder'`.
3. **`test.py --save_err_time` writes to a non-existent directory** — `mkdir -p` first.
4. **Default `advection_test` config is a single deterministic IC** — single-sample is misleading; paper averages over random ICs. Use `advection_test_random` (generated by `run_eval2.sh`) for the publication-comparable Pareto.
