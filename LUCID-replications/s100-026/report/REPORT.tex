\section*{Paper}
Klapproth, A.\ P., Schuemann, J., Stangl, S., Xie, T., Li, W.\ B., \& Multhoff, G.\ (2021).
\emph{Multi-scale Monte Carlo simulations of gold nanoparticle-induced DNA damages for
kilovoltage X-ray irradiation in a xenograft mouse model using TOPAS-nBio.}
\textbf{Cancer Nanotechnology} 12:27.
DOI: \href{https://doi.org/10.1186/s12645-021-00099-3}{10.1186/s12645-021-00099-3}.
Author code: \url{https://github.com/AKlapproth/MultiScale_AuNP_TOPAS}.

\section{Model and method}

Three-stage TOPAS / TOPAS-nBio multi-scale Monte Carlo pipeline
(TOPAS v3.2, Geant4 v10.5p1):

\begin{itemize}
\item \textbf{Stage 1 --- Mouse.} Xie--Zaidi 21-g voxel mouse in a $120\times 120\times 160$~mm$^3$
      air box; $200\times 200\times 512$ voxels, 200~$\mu$m pitch. Ellipsoidal mammary tumor
      $5\times 4\times 5$~mm$^3$ (G4\_WATER) implanted near left hind leg. 5-mm flat circular
      photon source 20~cm below tumor center; 100 or 200~kVp SARRP-style spectrum from
      SpekCalc. Geant4 EM opt.~3. Phase-space file of all particles entering tumor;
      $\times 750$ multiplicity with rotated positions/momenta.
\item \textbf{Stage 2 --- Tumor.} $5\times 4\times 5$~mm$^3$ water ellipsoid, three
      100-$\mu$m-diameter ``cell-region'' spheres (Front / Center / Back). Fed by Stage-1
      phase-space; outputs a phase-space per sphere.
\item \textbf{Stage 3 --- Cell.} 20-$\mu$m water cell, 13.8-$\mu$m nucleus, 24,464 cubical
      3.833-$\mu$m voxels divided into 40 mouse chromosomes ($\approx 5.19$~Gbp); chromatin
      fibres along 1st-order 3D Hilbert curves; histones + DNA backbone
      ($\rho = 1.407$~g/cm$^3$) + hydration shells. AuFeNPs (4-nm OD = 2-nm Fe$_2$O$_3$ core
      + 1-nm Au shell) at $10^6$ per cell, randomly within $\leq 100$~nm of the nucleus.
      Stage-2 phase-space fed in with $\times 100$ multiplication and random $y$-rotation.
      Geant4-DNA physics + chemistry in water; Livermore in gold/Fe$_2$O$_3$;
      region-switching at NP boundaries. Chemistry stage 1.0~ns; direct SB if
      $\geq 17.5$~eV in a backbone+hydration volume per history; indirect SB if $\cdot$OH
      enters backbone (40\% probability); DSB $=$ two SBs on opposing strands within
      $\leq 10$~bp. Output: SDD format.
\end{itemize}

Two arms per scenario (with / without AuFeNPs). $2$~spectra $\times\ 3$~depths $\times\ 2$~conditions
$=$ 12 runs.

\section{Precise reproducible claims}

\begin{enumerate}
\item Table~3 chemical-species enhancement ratios (with $\div$ without AuFeNPs) across
      (100, 200) kVp $\times$ (Front, Center, Back):
      OH $\approx 2.05$--$2.23$ (mean $\approx 2.16$);
      H$_2$ $\approx 2.69$--$2.94$ (mean $\approx 2.81$);
      H $\approx 1.51$--$1.65$ (mean $\approx 1.59$);
      H$_2$O$_2$ $\approx 1.03$--$1.09$ (mean $\approx 1.06$);
      H$_3$O$^+$ $\approx 0.23$--$0.35$ (mean $\approx 0.29$, \emph{suppressed});
      e$_\text{aq}^-$ $\approx 0.38$--$0.59$ (mean $\approx 0.49$, \emph{suppressed}).
\item Qualitative: nucleus dose, SB count, DSB count all rise with AuFeNPs in every scenario
      (Figs.~7--9); indirect SB $\approx 2\times$ direct SB in every scenario; depth
      dependence (Front $>$ Center $>$ Back) significant only for 200~kVp.
\item Audit parameters: direct-SB threshold 17.5~eV; $\cdot$OH$\to$indirect-SB probability 40\%;
      chemical stage 1.0~ns; DSB window $\leq 10$~bp; AuFeNP concentration claimed
      $\approx 0.225$~wt\% (with $10^6$ NPs per cell).
\end{enumerate}

\section{Reproduction performed}

\item Encodes Table~3 verbatim and recomputes per-species min/max/mean and sign-of-enhancement.
\item Audits the wt\% claim from the paper's NP geometry, densities

\section{Coverage / Agreement}

\textbf{Coverage} $= 6/10$. All published parameter values, both photon spectra, AuFeNP
geometry, chemistry settings, DNA model size, and Table~3 captured and re-summarized.
Figures 7--9 (SSB/DSB time series) and per-species absolute counts (Fig.~10) require
the MC engine and are not regenerated. The headline enhancement-ratio matrix and the
qualitative dose/SB/DSB dependence on AuFeNP presence are covered analytically.

\textbf{Agreement} $= 7/10$. All Table~3 numerical and sign-of-enhancement claims pass
the internal consistency tests. OH dominance and OH/H$_2$ ordering are consistent with
the chemistry mechanism. \textbf{One documented disagreement:} the claimed 0.225~wt\%
AuFeNP loading does not reconstruct from the stated NP geometry under any denominator
interpretation tried. Closest match: ``100-nm shell around nucleus'' $\approx 0.96$\%
($4\times$ high); whole-cell $= 0.014$\% ($16\times$ low). The paper's 0.225\% number
may rely on a volume assumption not made explicit in the text.

\section{Critique (honest --- no whitewash)}

The paper is unusually reproducible \emph{by field standards}: code on GitHub, parameter
file structure named, phase-space files documented, SDD output. That is not the same as
\emph{bit-near reproducible}, and this replication does not clear that bar. The following
frictions are genuine and matter:

\begin{enumerate}
\item \textbf{We did not re-run the Monte Carlo.} Everything in \S3 is an
      \emph{arithmetic and logic audit of the published Table 3}, not an independent
      generation of the numbers. A ``PASS'' here means ``the paper's own numbers agree with
      themselves and with the qualitative story,'' not ``we regenerated them.'' A truly
      independent replication requires standing up TOPAS + Geant4 + TOPAS-nBio + Xie--Zaidi
      voxel-mouse + custom mouse-DNA voxel model, which is a multi-week cluster campaign
      and is out of scope for the LUCID budget.
\item \textbf{The one thing we did check numerically failed:} the wt\% claim.
      $0.225$\% cannot be reconstructed from the stated NP geometry under any of six
      denominator interpretations. Best match is off by $4\times$; whole-cell off by
      $16\times$. This is not a rounding issue --- it is a factor-of-4-to-16 gap in a
      published headline concentration figure.
\item \textbf{Compute envelope is unspecified.} No wall-clock, no per-stage history counts
      beyond the $\times 750 / \times 100$ multiplications, no memory or CPU/GPU usage.
      A funded replicator cannot scope the ask.
\item \textbf{No random seeds.} With 12 scenario runs and reported ratios as tight as
      OH $\in [2.05, 2.23]$, per-scenario seed sensitivity is the dominant uncertainty
      and is not bounded.
\item \textbf{No AuFeNP coordinate file.} ``$10^6$ AuFeNPs placed randomly within
      $\leq 100$~nm of the nucleus'' fixes a distribution, not a realisation. The exact
      chemical enhancement in Table 3 depends on which molecules are killed at NP surfaces,
      which depends on the specific placement. Without a fixed cloud, exact reproduction
      is impossible.
\item \textbf{Mouse-DNA model referenced ``in the repo'' without a version tag.} The
      $5.19$-Gbp mouse DNA model (24,464 voxels, 40 chromosomes, Hilbert-curve fibres)
      is described as a modification of Zhu et al.\ 2020a; the actual modified geometry
      files are referenced as ``in the GitHub repository'' but no \verb|git rev-parse|
      pin is given.
\item \textbf{Intermediate phase-space files not published.} Stages 1$\to$2 and 2$\to$3
      communicate by \verb|.phsp| files. None are released. A Stage-3-only perturbation
      still requires the full multi-kJob campaign upstream.
\item \textbf{Verdict-label vs.\ substance:} the queue label for this dir is ``REPLICATED''.
      That is over-optimistic. The substance is \emph{spot-check / partial audit + one
      documented numerical disagreement}. We flag this in \verb|failure_analysis.md| and
      have propagated the honest label ``PARTIAL / SPOT-CHECK'' to the harvest note.
\end{enumerate}

\section{Verdict}

\textbf{Actual verdict:} \emph{Partial / spot-check only.} Analytical audit consistent
except for the wt\% claim, which fails a stated-geometry cross-check by 4$\times$--16$\times$.
MC pipeline not re-run. Queue label ``REPLICATED'' is not supported by the evidence in
this dir; it should read PARTIAL.

\textbf{Most precise missing artifact:} the authors' AuFeNP coordinate dump \emph{plus} the
Stage-2 tumor-stage phase-space files for both 100 and 200~kVp. Either would unblock
partial re-running; both together enable bit-near reproduction of Table 3.
