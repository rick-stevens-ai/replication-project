\section{Paper summary}

Let $T[0..N-1]$ be an unsorted table of $N$ distinct comparable values. The
minimum-searching problem is to find the index $y^\star$ such that $T[y^\star]
= \min_j T[j]$. Classically this takes $\Theta(N)$ probes on any deterministic
or randomized Turing machine, and a linear-lower-bound argument matches it.
D\"urr \& H\o yer\footnote{Also known as Grover-based amplitude amplification
in the pre-BBHT era; the paper's subroutine is what became Boyer--Brassard--H\o yer--Tapp
``exponential searching''.} present a quantum algorithm running in
$O(\sqrt{N})$ Grover queries, matching the known $\Omega(\sqrt{N})$ lower bound
up to constant factor.

The algorithm:
\begin{enumerate}
    \item Draw an initial threshold index $y$ uniformly from $\{0,\dots,N-1\}$.
    \item Repeat until total running time exceeds $22.5\sqrt{N} + 1.4\lg^2 N$:
    \begin{enumerate}
        \item Prepare the uniform superposition $\frac{1}{\sqrt{N}}\sum_j |j\rangle$.
        \item Mark every $j$ with $T[j] < T[y]$.
        \item Apply the quantum exponential searching (BBHT) subroutine.
        \item Measure the first register; call the outcome $y'$. If $T[y'] < T[y]$
              set $y \gets y'$.
    \end{enumerate}
    \item Return $y$.
\end{enumerate}

The paper's Theorem 1 states that the returned $y$ is the index of the minimum
with probability at least $\tfrac{1}{2}$.

\section{Method (numbered)}

\begin{enumerate}
    \item \textbf{Environment.} Python 3.14.6 (Homebrew), NumPy 2.4.3.
    Pure state-vector simulation on $n = \log_2 N$ qubits; no external quantum SDK
    (Qiskit/Cirq/PennyLane) was used, on purpose --- this ensures the replication
    is genuinely independent and cannot inherit any bugs from those libraries.

    \item \textbf{Grover core.}
    \begin{itemize}
        \item State: $|s\rangle = \frac{1}{\sqrt{N}}\sum_{j=0}^{N-1}|j\rangle$
              --- a length-$N$ \verb|complex128| array.
        \item Oracle: phase flip of amplitudes at marked indices
              (\verb|state[mask] *= -1|).
        \item Diffusion: reflection about the mean amplitude
              (\verb|2*state.mean() - state|), i.e.\ $2|s\rangle\langle s| - I$.
        \item Measurement: inverse-CDF sampling from the discrete distribution
              $\{|\psi_j|^2\}$.
    \end{itemize}

    \item \textbf{Independent Grover sanity check.}
    For $(N,k)$ on a 12-cell grid, ran $r^* = \mathrm{round}(\tfrac{\pi}{4}\sqrt{N/k})$
    Grover iterations 2000 times each and compared the empirical success rate to
    the closed-form $\sin^2((2r+1)\theta)$ with $\sin\theta = \sqrt{k/N}$.
    Worst deviation was $|\Delta| = 0.027$, mean $|\Delta| = 0.008$.

    \item \textbf{BBHT subroutine.}
    Standard BBHT ``exponential searching'':
    initialise $m \gets 1$; on each round pick $r$ uniformly from
    $\{0, \dots, \lceil m \rceil - 1\}$, run $r$ Grover iterations on the current
    uniform superposition + marker, measure, and check whether the observed index is
    marked. On failure, $m \gets \min(\lambda m, \sqrt N)$ with $\lambda = 6/5$;
    otherwise return the marked index. If no items are marked (the initial threshold
    $y$ already equals the minimum), the subroutine runs until the caller-supplied
    Grover budget is exhausted --- faithful to the paper's ``infinite algorithm''
    idealization.

    \item \textbf{Outer D\"urr--H\o yer loop.}
    Uniform-random initial $y$; while total Grover iterations used $<$ budget,
    build \verb|marked_mask = values < values[y]|, call BBHT with the remaining
    Grover budget, and adopt any returned index whose value is strictly smaller
    than $T[y]$.

    \item \textbf{Budget.}
    Implemented exactly as \verb|ceil(22.5*sqrt(N) + 1.4*log2(N)**2)|
    (see Table~\ref{tab:budget}).

    \item \textbf{Main experiment.}
    5 sizes $N \in \{4,8,16,32,64\}$, 300 trials each, random permutation
    $T[j] = \pi(j)$ where $\pi$ is a fresh Fisher--Yates shuffle of
    $\{0,\dots,N-1\}$. Recorded per-trial: correctness, Grover iterations used
    (always equals budget since we don't early-stop), Grover iterations until $y$
    first equals the true min, and number of outer threshold updates.
    Seeded with $20260706$; deterministic re-run.

    \item \textbf{BBHT $t$-sweep.}
    $N \in \{16, 32, 64, 128\}$, $t \in \{1, 2, 4, N/8, N/4, N/2\}$, 300 trials
    per cell. Each trial samples a random $t$-subset of $\{0,\dots,N-1\}$ as the
    marked set, gives BBHT a Grover ceiling of $100\lceil\sqrt{N/t}\rceil + 200$
    iterations (never exhausted in practice), records the total Grover iterations
    used until a marked index was observed.

    \item \textbf{Classical baseline.}
    Deterministic linear scan: track running argmin, probe every element.
    100 trials per $N \in \{4,\dots,512\}$.

    \item \textbf{LLM judge.}
    POST paper text + all evidence blobs to Argo
    (\verb|http://localhost:44497/v1/chat/completions|, free key \verb|stevens|)
    with a strict per-claim rubric. First-preference model
    \verb|argo:claude-opus-4.7| returned HTTP 502 (upstream); fell back to
    \verb|argo:gpt-5.2|. Parsed JSON verdict.
\end{enumerate}

\section{What worked / what didn't (per claim)}

\begin{description}
\item[C1 --- worked.] The full end-to-end algorithm returns the true minimum on
every one of the $5\times 300 = 1500$ trials. The paper's $\geq 1/2$ guarantee is
massively exceeded on small $N$.
\item[C1 --- didn't (fully).] The judge is correct that observing 300/300 does
not \emph{test tightness} of the $\geq 1/2$ bound --- a stress test would need
regimes where the algorithm sometimes fails. Small $N$ (up to 64) doesn't
provide that regime. Would require reducing the iteration budget below the paper
value, or scaling $N$ several orders of magnitude.
\item[C2 --- worked.] Formula match.
\item[C3 --- worked.] $t$-sweep clean, ratios bounded.
\item[C3 --- didn't (fully).] Mild upward drift of the ratio at fixed $t$ as $N$
grows (0.46 $\to$ 0.80 for $t=1$, $N=16 \to 128$). Consistent with the
$O(\log)$ lower-order term in BBHT but I didn't quantify it against the paper's
exact constant.
\item[C4 --- worked.] Trivially and exactly.
\end{description}

\section{Verdict + justification}

\textbf{PARTIAL} (LLM-judge \verb|argo:gpt-5.2|). The paper's central operational
claim (success $\geq 1/2$ within the stated budget) is reproduced with margin at
five tested sizes; the budget formula, the BBHT subroutine's $O(\sqrt{N/t})$
scaling, and the classical $\Theta(N)$ baseline are all directly and quantitatively
confirmed. The verdict is PARTIAL rather than REPLICATED because the empirical
range ($N \leq 64$) is too narrow to stress the $\geq 1/2$ bound and no
confidence intervals are reported.

\section{Open Questions}

\begin{enumerate}
    \item \textbf{Q1.} At what $N$ (or reduced iteration budget) does the
    empirical success prob start dropping toward the $\geq 1/2$ bound? See
    \verb|open_questions.json| for the concrete parameter sweep.
    \item \textbf{Q2.} The BBHT ratio $\bar\imath / \sqrt{N/t}$ drifts upward at
    fixed $t$ with $N$; is this the $O(\log)$ lower-order term BBHT predicts or
    an artifact of the small-$m$ start?
    \item \textbf{Q3.} What is the empirical distribution of the number of
    outer-loop threshold updates, and does it match the harmonic-number
    $H_N$ analysis in the paper's lemma 2?
    \item \textbf{Q4.} How does the algorithm degrade under ties (non-distinct
    $T$)? Paper explicitly assumes distinct values.
    \item \textbf{Q5.} Sensitivity of BBHT to $\lambda$ (I used $6/5$): does
    another $\lambda \in (1, \sqrt{2})$ meaningfully improve total Grover-iters?
\end{enumerate}
