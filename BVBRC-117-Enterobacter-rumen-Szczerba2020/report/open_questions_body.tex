  \item[Q1. Aligner-choice contribution to the LU2-vs-KCTC ANI shift (paper 99.44\%, ours 98.26\%).]
  \textbf{Basis:} we used \texttt{blastn -perc\_identity 70} (permissive); the paper likely used web-BLAST megaBLAST defaults. Mash on the same pair gives $\sim$98.61\%. \textbf{Next steps:} run pyani (ANIm, ANIb) and FastANI on the same 8-reference set; compare all three aligners to isolate methodology-vs-biology; contact author for exact BLAST parameters if needed.

  \item[Q2. Are the intrinsic \emph{oqxAB} + \emph{fosA} + \emph{uhpT}-E350Q signals AMRFinderPlus surfaces in LU2 phenotypically active?]
  \textbf{Basis:} 11 loci found now vs $\sim$5 in the paper's 2020 ResFinder 3.1 scan. This is a DB delta, but silent DNA presence does not equal expressed resistance --- and LU2 is being proposed as an industrial chassis where AMR-freedom matters. \textbf{Next steps:} MIC assays on LU2 for ciprofloxacin (\emph{oqxAB}) and fosfomycin (\emph{fosA}, \emph{uhpT}); rerun current ResFinder 4.x to separate DB-vs-tool contributions.

  \item[Q3. Is the reductive-TCA + glyoxylate route actually used for succinate biosynthesis \emph{in vivo}, or is that inference contradicted by carbon-flux measurements on whey permeate?]
  \textbf{Basis:} we confirmed every pathway gene is present, but presence $\neq$ flux. The paper never measured actual carbon flux. \textbf{Next steps:} $^{13}$C-MFA on LU2 grown on U-$^{13}$C-lactose whey permeate; if reductive branch is dominant, paper's mechanism is supported; if not, mechanism needs revision.

  \item[Q4. Has PHASTER's $\sim$4$\times$ larger reference DB (2026 vs 2019) changed the identity, boundaries, or count of intact prophages detected in LU2?]
  \textbf{Basis:} paper's PHASTER call was made against the 2019 DB; the annotation clearly has prophage machinery, but the specific boundaries and best-hit reference (\emph{Salmonella phage RE-2010}) are 2019-DB-specific. \textbf{Next steps:} rerun PHASTER/PHASTEST; also run VirSorter2 and geNomad as independent second opinions.

  \item[Q5. Given LU2's rumen ecology, is its mobilome burden (prophage + 47 GIs + many IS/tandem repeats) elevated compared to the K.\,aerogenes species baseline, as one would predict --- or is it typical?]
  \textbf{Basis:} paper reports mobile-element counts for LU2 alone but never runs the same IslandViewer 4 + PHASTER + IS-scan pipeline on the 22 comparator K.\,aerogenes genomes. \textbf{Next steps:} run identical IslandViewer 4, PHASTER, and ISEScan pipelines on all 22+ complete K.\,aerogenes genomes at NCBI; compute per-Mb GI/IS/prophage burden; test for LU2 outlier status; correlate with each strain's ecological source (clinical / environmental / rumen) to rigorously test the rumen-HGT-enrichment hypothesis.
