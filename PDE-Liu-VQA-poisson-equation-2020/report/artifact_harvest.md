**No external data files** are needed for this replication — the paper's problem
is fully specified by a tridiagonal Toeplitz matrix `A_m` (dimension 2^m) built
from the 1-D finite-difference stencil, and the RHS `b` is generated by sampling
`f(x)=x` at interior grid points as stated in the paper. All simulation is
classical statevector algebra, identical in principle to Liu et al.'s ProjectQ
simulator runs.

**Software versions:**
- Python 3.13
- numpy 2.5.0
- scipy 1.18.0 (BFGS optimizer)
- macOS (CherryRd, arm64)

**No paid endpoint or external LLM inference was required for the numerical
replication itself.** The LLM-judge verdict at the end of the report is scored
against a FREE Argo endpoint (Claude Opus 4.7 via localhost:44497).
