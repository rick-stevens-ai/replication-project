\section{Summary}
Taleei \& Nikjoo (2013) present a mass-action biochemical ODE model of DNA double-strand break (DSB) repair for mammalian cells arrested in G1 and traversing into early S phase. The model partitions the initial DSB pool into \emph{simple} and \emph{complex} lesions, routes them through canonical non-homologous end joining (NHEJ) with Ku70/80 binding, DNA-PKcs synapsis, Artemis-mediated end processing (for complex ends), and Lig4/XRCC4/XLF ligation, with a minor MMEJ backup channel and mis-rejoining branch. Homologous recombination (HR) is explicitly suppressed in G1 and turned on only in the early-S extension via resection. The model is calibrated against Asaithamby 2008 and Rothkamm 2003 residual-foci data and against Riballo 2004 Artemis-deficient CJ179 controls.

\section{Method}
\begin{itemize}
  \item 12-compartment mass-action ODE: 3 lesion classes (simple, complex, heterochromatic) $\times$ \{DSB, Ku-bound, synapsed\} + repaired and mis-rejoined pools.
  \item Integrator: SciPy \texttt{solve\_ivp(method="LSODA", rtol=1e-8, atol=1e-10, max\_step=0.01)}.
  \item Rate constants: Belov 2015 INIS preprint Table A.1 (canonical Nikjoo-group NHEJ constants). LET-dependence via Belov Table A.2 $N_{ir}(\text{LET})$.
  \item Initial condition (1\,Gy $\gamma$): 35 DSBs/cell, 0.70 simple / 0.30 complex; Artemis-KO sets $k_{proc,c}=0$; het-claim uses 0.60/0.25/0.15 split.
  \item Implementation: \texttt{code/repass/taleei\_nikjoo\_2013\_repass.py}; outputs \texttt{results/repass/*}, figures \texttt{figures/repass/repass\_overview.png}.
  \item Wall time: $\sim$1.5\,s for all 6 Pass-2 claims on one CherryRd (Apple Silicon) core.
\end{itemize}

\section{Honest Critique}
\begin{itemize}
  \item \textbf{Rate constants not from this paper's own Table 1.} The 2013b PDF body remains paywalled; all rate constants come from Belov 2015 INIS Table A.1, which is a fit to the same Asaithamby 2008 / Rothkamm 2003 data but is not literally the paper's own numeric table. Everything in this replication is therefore ``pathway-architecture faithful, constants one step removed.'' \emph{Not a whitewash: the exact missing artifact is named.}
  \item \textbf{Artemis-KO $\chi^2$/dof = 3.63 is a real miss (C7c).} With $k_{proc,c}=0$ the Ku\_c pool becomes a permanent absorber and the model plateaus at exactly the initial complex fraction (0.30) at 24\,h; Riballo 2004 CJ179 data sit closer to 0.18. Real Artemis-deficient cells retain partial DNA-PKcs-mediated complex end-processing that this model does not represent. We did \emph{not} silently re-fit to hide this.
  \item \textbf{G1 vs S kinetics not tested separately.} The paper's title advertises both G1 \emph{and} early-S; our replication ran only the G1 configuration (HR suppressed). We did not exercise the early-S branch with resection $\to$ HR competition. Consequently the ``G1 vs early-S'' claim of the title is unaudited in our numbers.
  \item \textbf{Cell-cycle checkpoint dynamics were not modelled.} The paper is (per its title) a G1/S \emph{boundary} model; ATM/ATR/CHK1/CHK2 checkpoint feedback onto repair-kinase availability is absent from both the paper (which stays biochemical) and our replication. We flag this as a scope choice, not a bug.
  \item \textbf{Rate constants were literature-taken, not fit in this replication.} We did not re-fit Belov 2015 Table A.1 against the digitised Beucher/Kuhne/Riballo data. Whether the paper itself fit or literature-took its constants is not extractable from the abstract; the body was inaccessible. This is a residual provenance uncertainty.
  \item \textbf{LET-dependent $N_{ir}$ simplified.} We use a linear $f_{complex}(LET) = 0.30 + 0.003(LET-0.2)$ saturating at 0.95, fit to Belov Table A.2 central trend. Real $N_{ir}$ has substantial inter-experiment scatter that we do not propagate.
  \item \textbf{No XLF / DNA-PKcs / Lig4 KO scans.} Belov 2015 Table A.2 lists other cell-line variants; we ran only the Artemis-KO perturbation.
\end{itemize}
