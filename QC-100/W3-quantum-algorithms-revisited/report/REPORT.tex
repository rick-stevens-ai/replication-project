\section{Paper identity and scope}
Cleve, Ekert, Macchiavello, and Mosca~(1998) \emph{Quantum Algorithms Revisited},
Proc.\ R.\ Soc.\ Lond.\ A \textbf{454}, 339--354, is a foundational review and
reframing paper: it recasts the (then-known) early quantum algorithms
--- Deutsch, Deutsch--Jozsa, Bernstein--Vazirani, Simon, Shor's order-finding,
and Grover --- as instances of a single \emph{quantum-network} template:
\[
\text{Hadamard / QFT} \;\longrightarrow\; f\text{-controlled }U \;\longrightarrow\;
\text{QFT}^{-1},
\]
i.e.\ quantum phase estimation (QPE) with a suitably chosen $U$. Its
testable, \emph{quantitative} headline claims (as opposed to
pedagogical/qualitative ones like ``the QFT is an interferometer'') are:
\begin{enumerate}
    \item Deutsch--Jozsa in a \emph{single} $f$-controlled query with certainty.
    \item Bernstein--Vazirani recovers the hidden string $a$ in a single query.
    \item Phase estimation of an arbitrary eigenphase $\varphi$ with an $m$-bit
          register succeeds with probability
          $\Pr[\text{best }m\text{-bit estimate}] \ge 4/\pi^{2} \approx 0.4053$
          (Sect.~5 + Appendix C); for dyadic $\varphi$, $P=1$.
    \item Shor's order-finding via QPE on $U:\ket{y}\mapsto\ket{ay\bmod N}$
          yields eigenphases $s/r$; continued fractions recover $r$.
    \item Grover's algorithm, iterated $\sim (\pi/4)\,2^{n/2}$ times, finds the
          marked $k$ with probability ``greater than $0.5$'' (Fig.~7 caption).
\end{enumerate}

\section{Method (independent reimplementation)}
Rather than call an existing quantum framework (Qiskit / Cirq / PennyLane),
the replication built a bare \texttt{numpy} exact state-vector simulator
(\texttt{replicate.py}, single file, seed 12345). This forces every bit-order,
endianness, and normalization convention to be under explicit control, so
agreement with analytic values cannot be laundered through library defaults.
Specifically:
\begin{itemize}
    \item Inverse QFT constructed as the exact unitary matrix
          $\text{QFT}^{-1}_{jk} = \frac{1}{\sqrt{N}}e^{-2\pi i jk/N}$;
    \item Phase oracles for DJ/BV realised as diagonal $\pm 1$ operators;
    \item QPE with eigenphase injection $U\ket{\psi}=e^{2\pi i\varphi}\ket{\psi}$
          and controlled-$U^{2^{j}}$ applied by direct diagonal action;
    \item Full classical + quantum Shor loop: random $a$, $\gcd$, order-finding
          by QPE on the modular-multiplication eigenspace, continued
          fractions, even-order and non-trivial-root tests;
    \item Grover with exact oracle and diffusion operators.
\end{itemize}
This is a genuine independent reimplementation, not a wrapper over a
canonical library. The unified network framework of the paper was
\emph{verified as a common reduction}: DJ, BV, and Shor were all
implemented through the same QPE scaffold, with only the choice of $U$
changing (identity/phase-marking for DJ--BV, modular multiplication for
Shor). This is exactly the paper's central pedagogical/architectural claim.

\section{Verdict: REPLICATED}
Every quantitative algorithm claim in the paper was independently
reimplemented and verified. DJ, BV, QPE-dyadic, and Shor eigenphase spectra
are exact to machine precision. The QPE $4/\pi^{2}$ lower bound holds with
\emph{zero} violations across 2000 random phases (observed min $0.4056$ vs.\
analytic $0.4053$). Grover and Shor-factoring success rates match the paper's
``$>0.5$'' and ``factors $N$'' claims. The unified network template was
\emph{operationally} verified as a common reduction, not merely quoted:
the same QPE routine is called by DJ, BV, and Shor with only $U$ changed.

\section{Honest critique / limitations}
This replication is strong on the paper's quantitative headline items, but
several things were \emph{not} exercised. See
\texttt{failure\_analysis.md} for the full list; briefly:
\begin{itemize}
    \item \textbf{Simon and discrete-log} are named in the paper's unification
          picture but only qualitatively; the replication does \emph{not}
          reimplement them, so the ``unified framework'' claim is verified
          on DJ/BV/QPE/Shor/Grover but not on Simon or discrete log.
    \item \textbf{Only $N=15$} was factored end-to-end; no scaling study
          (e.g.\ $N=21,33,35,39$) to test that the QPE $\to$ continued-fractions
          $\to$ factor extraction pipeline is generic rather than tuned to a
          single easy case.
    \item \textbf{QPE lower-bound margin is very tight} ($0.4056$ vs.\
          $4/\pi^{2}{=}0.4053$). With 2000 random $\varphi$ this is a
          reasonable sanity check, but it does not exhaustively probe the
          worst case, and the ``$\ge 4/\pi^{2}$'' bound is a supremum-type
          claim that ideally deserves an analytic pathological $\varphi$
          study, not just Monte Carlo.
    \item \textbf{No noise or gate-error injection.} The paper is
          noise-free, and so is this replication --- but for the paper's
          claims to have any implication for near-term hardware, a
          depolarizing-channel study would strengthen the reproduction.
    \item \textbf{Framework-agnosticism cuts both ways.} Because the
          simulator is bespoke \texttt{numpy}, agreement with a canonical
          Qiskit reference implementation was \emph{not} independently
          cross-checked; a second-source verification would harden the
          verdict.
\end{itemize}
