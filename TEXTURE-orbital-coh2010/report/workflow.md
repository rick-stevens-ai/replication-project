# Workflow — TEXTURE-orbital-coh2010

**Paper:** Coh, Vanderbilt, Malashevich, Souza, "Chern-Simons orbital
magnetoelectric coupling in generic insulators," arXiv:1010.6071 (PRB 83,
085108 (2011)). Texture class: orbital. Method class: Wannier-based DFT
Chern-Simons ME.

## Approach
The paper's material results (Cr2O3, BiFeO3, GdAlO3, Bi2Se3) are DFT +
Wannier90 + fine-k-grid Chern-Simons integration — DFT-heavy, out of scope
for an in-process replication with free endpoints. We instead replicate the
**central tractable object**: the axion angle θ (Chern-Simons 3-form,
Eq. 22) on a minimal 3D Wilson-Dirac topological insulator whose phase
diagram is known analytically, verifying the paper's conceptual pillars
(quantization, unit conversion, smallness, T-breaking → metallization).

## Tools / codes used
- **Python 3.13** + **NumPy 2.4.3** / **SciPy 1.18.0** — linear algebra
  (band diagonalization, Wilson loops, Berry connections).
- **Matplotlib** (Agg) — figures.
- **pdflatex** — compiled report/REPORT.pdf.
- No external/paid endpoints. No DFT. No network calls. All in-process.

## Code (in `code/`)
- `cs_theta.py` — naive direct CS 3-form (Eq. 22) on raw grid. *Demonstrates
  the paper's gauge-scrambling problem (returns garbage).*
- `cs_theta_smooth.py` — smooth-gauge (log-cabin parallel transport) CS
  integral. Works for trivial phases; returns ~0 for the TI (Z2 obstruction
  boundary term) — an honest reproduction of the paper's Sec. III difficulty.
- `theta_z2_robust.py` — Fu-Kane parity oracle (exact θ for inversion-sym
  insulators) + Wilson-loop / HWCC utilities. **Primary θ determination.**
- `theta_final.py`, `theta_hwcc_flow.py`, `cs_theta_wilson.py`,
  `theta_z2pack.py` — auxiliary/experimental θ estimators (band-summed
  A·Ω, HWCC partner-switching). Kept for provenance; see failure_analysis.
- `run_replication.py` — production driver. Writes `work/results.json` +
  3 figures.

## Run
```
cd code && python3 run_replication.py     # ~1-2 min, writes work/
cd ../report && pdflatex REPORT.tex        # -> REPORT.pdf
```
