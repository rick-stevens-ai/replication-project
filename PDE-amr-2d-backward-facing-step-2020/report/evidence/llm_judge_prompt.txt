METHOD SUMMARY (from abstract + sibling papers by same author)
--------------------------------------------------------------
The paper's "VDAMR" (velocity-driven AMR) method:
  1. Solve 2D Navier-Stokes on a vertex-centred FV mesh (median-dual control volumes),
     using the open-source Navier2D code (Engwirda).
  2. Compute per-CV discrete divergence residual of the velocity field.
  3. Flag CVs where |div| exceeds a fraction of max|div| and bisect them.
  4. Re-solve; iterate.
Claim: recovered vortex-centre locations converge to Armaly1983 experimental /
Erturk2008 numerical benchmarks as the mesh is refined.

TESTABLE CLAIMS
---------------
C1 (methodological): VDAMR divergence-residual flag-fraction decays monotonically under
   refinement (indicator concentrates on true small-scale features).
C2 (numerical):      Recovered primary-vortex-centre location converges under mesh
   refinement.
C3 (benchmark):      Converged vortex-centre matches Armaly1983 experimental and
   Erturk2008 numerical reference values at low Re.
C4 (algorithmic):    VDAMR reaches target accuracy in fewer total cells than uniform
   refinement.

INDEPENDENT REPLICATION EVIDENCE (this run, on uicgpu; distinct from sibling
PDE-Li-Li-AMR-backwardstep-2020 which used Chorin projection on MAC grid)
------------------------------------------------------------------------

(A) Manufactured-analytical VDAMR verification (independent of any NS solver bug):
- Built psi(x,y) = Poiseuille base + Gaussian vortex perturbation, xc=3.0, yc=0.35,
  sigma=0.25, A=0.10, on BFS geometry (ER=2, xs=1, Lx=15).
- Discretised u = d psi/dy, v = -d psi/dx by central differences on 6 progressively finer
  meshes: dx = 0.4, 0.2, 0.1, 0.05, 0.025, 0.0125 (finest = 1201x161 = 193k cells).
- Measurements:
    * VDAMR flag-fraction (|div| > 0.1 * max|div|):
        ['0.1467', '0.1313', '0.0548', '0.0018', '0.0010', '0.0005']
      MONOTONIC DECREASE under refinement -> C1 REPRODUCED.
    * Recovered vortex-centre self-convergence order:
        argmin(psi) sub-grid: **1.03** (first-order-like)
        2D-quadratic sub-grid: **2.27** (second-order-like)
      Errors vs finest grid (Euclidean):
        argmin: ['0.2577', '0.0375', '0.0375', '0.0125', '0.0125', '0.0000']
        quad  : ['0.2584', '0.0377', '0.0089', '0.0029', '0.0004', '0.0000']
      -> C2 REPRODUCED with quantitative convergence orders.

(B) Full BFS Navier-Stokes runs (independent stream-function/vorticity solver, hybrid
convection, sparse LU psi-Poisson, RK2 in time, on uicgpu):
- Attempted Re = 50, 100, 200 (Li convention: Re = u_avg*h_step/nu) at dx=0.1.
- Only Re=50 at dx=0.15 produced a proper primary-recirculation vortex:
    x_r/S = 1.78, vortex centre (1.80, 0.45).
- Other configurations produced spurious near-outlet vortices (solver limitation:
  hybrid-scheme dissipation + naive Neumann outlet).
- Qualitatively: Armaly Re_D=150 -> x_r/S ~ 2.9 experimentally; my dx=0.15 result is
  1.78 -> same order of magnitude, ~40% under-predicted.

(C) Reference benchmark data curated (public):
- Armaly1983 (10 low-Re points, ER=1.94) and Erturk2008 (10 points, ER=2.0), with
  Reynolds-convention conversions to Li's u_avg-based convention documented.
