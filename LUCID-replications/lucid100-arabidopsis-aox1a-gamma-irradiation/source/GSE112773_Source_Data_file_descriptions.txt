'Source data 1' contains the input files, parameters and DREM (the Dynamic Regulator Events Miner) models generated for the wild-type and sog1 gamma-IR transcriptional responses.

'Source data 2' contains, for each DREM path, the list of genes, the results of the Gene Ontology analysis made with the GO-TermFinder software via the Princeton GO-TermFinder interface (http://go.princeton.edu/cgi-bin/GOTermFinder) and the subsequent refinement of GO terms through the REVIGO platform (http://revigo.irb.hr/).

'Source Data 3' contains the input and output files from the motif searches performed using the promoters of genes present in each wild-type and sog1 DREM paths through MEME (Bailey et al., 2009) as well as their comparison to the DAP-seq database of motifs (O'Malley et al., 2016) using Tomtom (Bailey et al., 2009).

'Source Data 4': The SourceData_Fig4 folder contains the input file, the network file and the Cytoscape 3.4.0 session corresponding to the interaction network of the 141 SOG1 target genes that could be assigned to relevant functional categories. The SourceData_FigS11 folder contains the input and network files for the subnetworks of transcription factors targeted by SOG1 generated using Cytoscape 3.4.0.



Bailey TL, Boden M, Buske FA, et al., 2009. MEME SUITE: tools for motif discovery and searching. Nucleic Acids Res 37, W202-8.

Boyle EI, Weng S, Gollub J, et al., 2004. GO::TermFinder--open source software for accessing Gene Ontology information and finding significantly enriched Gene Ontology terms associated with a list of genes. Bioinformatics 20, 3710-5.

O'Malley RC, Huang SC, Song L, et al., 2016. Cistrome and Epicistrome Features Shape the Regulatory DNA Landscape. Cell 165, 1280-92.
