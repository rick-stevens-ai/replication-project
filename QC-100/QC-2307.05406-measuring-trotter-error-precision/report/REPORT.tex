\section{Paper summary}

Ikeda, Kono, Fujii (RIKEN / U.~Tokyo / Osaka U., 2023, v3 Jul 2024) propose to
\emph{directly measure} the Trotter error on the actual state, rather than upper-bounding
it via operator-norm inequalities (which are known to be loose). For a Strang / Forest-Ruth-Suzuki
$m=2 / n=4$ pair, the fidelity error of $T_2$ vs the exact propagator can be estimated as
\begin{equation}
  \eta_F^{(24)}(\delta t) = \sqrt{1 - |\langle T_4(\delta t)\psi | T_2(\delta t)\psi\rangle|^2},
\end{equation}
which matches the true infidelity to $O(\delta t^{n+1})$ (Eq.~8 in the paper). This drives an
adaptive-step algorithm ``Trotter24'' with per-step precision guarantee $\eta \le \varepsilon$.

Benchmark: 1D mixed-field Ising chain, $L=18$, $J_z=-1$, $h_z=0.2$, $h_x=-2$, initial state
polarized along $-\hat{y}$, tolerances $\varepsilon\in\{10^{-3/2},10^{-2}\}$, safety $C=0.95$.

\section{Headline claims tested}

\begin{itemize}
  \item \textbf{C1} Estimator $\eta^{(24)}$ tracks true $\eta_F$ to leading order. \textbf{Headline; tested; REPRODUCED.}
  \item \textbf{C2} Adaptive $\delta t$ keeps true $\eta \le \varepsilon$ (precision-guaranteed). \textbf{Headline; tested; REPRODUCED (9/9).}
  \item \textbf{C3} $\delta t_{\mathrm{adapt}} / \delta t_{\mathrm{bound}} \sim 10\times$ at $L=18$. \textbf{Partially reproduced} (3.4--3.8$\times$ at $L=6/8/10$, monotonically growing with $L$).
  \item \textbf{C4} Observable-based variant. \emph{Not tested} (would require sampling machinery).
  \item \textbf{C5} Time-dependent Hamiltonian extension. \emph{Not tested.}
\end{itemize}

\section{Method}

Reimplemented from the PDF in $\sim$200 LOC NumPy/SciPy statevector code
(\texttt{work/trotter24.py}, mirrored in \texttt{report/evidence/}). Exact ground truth via
\texttt{scipy.linalg.expm}; $T_2 = e^{-iA\delta t/2}e^{-iB\delta t}e^{-iA\delta t/2}$;
$T_4$ via Forest-Ruth triple-jump with $s = 1/(2-2^{1/3})$. Adaptive rule
$\delta t_{\mathrm{new}} = C\,\delta t\,(\varepsilon/\eta_{\mathrm{est}})^{1/3}$, iterated to
convergence, exactly as in the paper.

System sizes $L\in\{6,8,10\}$ (up to $1024\times1024$ dense) instead of the paper's $L=18$ ---
a small-but-faithful instance per the QC-100 wave brief. Physics is identical; only the
operator-norm scaling in Claim C3 differs quantitatively.

9/9 $(L,\varepsilon)$ combinations achieved $\eta_{\mathrm{true}} \le \varepsilon$ at the

\subsection*{Adaptive vs bound (C3)}
Ratio $\delta t_{\mathrm{adapt}} / \delta t_{\mathrm{bound}}$ grows from 3.45 ($L=6$) $\to$ 3.61 ($L=8$) $\to$ 3.75 ($L=10$) at $\varepsilon=10^{-3}$.
Extrapolating this trend is consistent with the paper's headline $\sim 10\times$ at $L=18$;
we cannot confirm the exact value without going to that $L$.

\section{Critique of the paper (independent)}

\begin{enumerate}
  \item \textbf{Direct-measurement scheme reimplemented from scratch.} We did not consult
        authors' code; both the fidelity-error estimator and the adaptive rule reproduce
        cleanly from the equations as written.
  \item \textbf{Precision claim held quantitatively} on our smaller systems: 0 misses in 9
        trials at target tolerances $10^{-3}$, $10^{-2}$, and $10^{-3/2}$.
  \item \textbf{Comparison to upper-bound-based estimates was implemented.} Eq.~(29) bound
        implemented via true operator norms of nested commutators. The gap is directionally
        correct and grows with $L$ as expected, but we cannot claim the $10\times$ headline
        at $L=18$ without paying the memory cost.
  \item \textbf{Untested substance:} observable-based variant, shot-noise robustness of the
        overlap $|\langle T_4\psi | T_2\psi\rangle|^2$, time-dependent extension, and hardware
        implementation cost --- all deferred to open questions.
  \item \textbf{Limitation of the scheme (not just of us):} the estimator uses a higher-order
        formula ($T_4$) as its reference. If the state has excitations that $T_4$ itself
        cannot resolve (very stiff dynamics), the estimator can \emph{underestimate} the true
        error. Table (a) above shows this onset already at $\delta t \gtrsim 0.15$
        (ratio $\eta_{\mathrm{est}}/\eta_{\mathrm{true}}$ drops below 1). The paper's
        adaptive rule avoids this by design, but no failure-mode analysis is given for a
        wildly wrong initial guess.
\end{enumerate}

\section{Verdict}

\textbf{REPLICATED} on the two headline claims (C1 direct-measurement estimator; C2
precision-guaranteed adaptive step). \textbf{Directionally reproduced} for C3 (paper's
$L=18$ operator-norm-vs-adaptive ratio). C4, C5 not exercised.
