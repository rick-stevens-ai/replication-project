\begin{abstract}
We independently reimplement the two-ancilla, measurement-driven fixed-point
quantum-search algorithm of Tulsi, Grover \& Patel (QIC 2005), as a real
statevector simulation in NumPy. We verify the paper's headline Eq.~(6) claim
--- that after \(q\) iterations the residual error probability is
\emph{exactly} \(\varepsilon^{2q+1}\) for every positive integer \(q\) ---
across three register sizes (\(n=2,3,4\); \(N=4,8,16\)) and four query depths
(\(q=1,2,3,4\)). The measured residual error matches the predicted
\(\varepsilon^{2q+1}\) to \(\le 3.3\times 10^{-15}\) in all 12 cells, well below
our declared tolerance of \(10^{-9}\). \textbf{Verdict: REPLICATED.}
\end{abstract}

\section{Paper summary}

The paper introduces a fixed-point quantum-search algorithm that uses two
ancilla qubits and mid-circuit measurements to enforce monotone convergence
towards the marked (target) state. Given an initial preparation
\(U|s\rangle = \sin\theta|t\rangle + \cos\theta|t_\perp\rangle\) with initial
error probability \(\varepsilon = \cos^2\theta\), the algorithm performs \(q\)
identical iterations of an oracle-plus-measurement-plus-diffusion block on
the extended \((a_1, \text{register}, a_2)\) system, exiting early whenever
ancilla-2 reads 1 (indicating the register has collapsed onto the target).

Its central theoretical result is that this yields net error probability
\begin{equation}
\varepsilon_q = \varepsilon^{2q+1} \quad \text{for every positive integer } q,
\tag{Paper Eq.~6}\label{eq:main}
\end{equation}
matching the asymptotically optimal Phase-\(\pi/3\) rate of Grover~(2005)
but for \emph{all} \(q\) rather than only \(q=(3^n-1)/2\), and with strictly
better average-case behavior because early ancilla-2-reads-1 measurements
exit the loop.

\section{Method}

\textbf{Tools.} macOS 14 on CherryRd; Python \texttt{3.13.x}; NumPy \texttt{2.4.3};
poppler \texttt{pdftotext} for the source-text extraction; no Qiskit needed
(numpy suffices for exact statevector simulation at these sizes).

\textbf{Fetch and read paper.}
\begin{lstlisting}
curl -sSL https://arxiv.org/pdf/quant-ph/0505007 -o paper.pdf   # 189,924 bytes, 12 pages
pdftotext -layout paper.pdf work/paper.txt
\end{lstlisting}

\textbf{System size.} The algorithm uses two ancillas (\(a_1, a_2\)) around
an \(n\)-qubit register. We instantiate the total \(2n+2\) qubits (dim
\(2\!\cdot\!2^n\!\cdot\!2 = 4N\)) with \(n\in\{2,3,4\}\), i.e.\ 6/8/10 qubits
total (dim 16 / 32 / 64). The database has \(N=2^n\) items with one marked
element at index 0. The initial error probability is
\(\varepsilon = 1 - 1/N = 3/4, 7/8, 15/16\) respectively.

\textbf{Operators built explicitly (numpy, dense).}
\begin{itemize}
  \item Source preparation: \(U = H^{\otimes n}\), giving
        \(U|0\ldots 0\rangle = |s\rangle\).
  \item Oracle: dense \(4N\times 4N\) matrix that swaps ancilla-2 \(|0\rangle\!\leftrightarrow\!|1\rangle\)
        exactly on the two-dim subspace \(\{|1\rangle_{a_1}|\text{target}\rangle_{\text{reg}}|0\rangle_{a_2},\, |1\rangle_{a_1}|\text{target}\rangle_{\text{reg}}|1\rangle_{a_2}\}\); identity elsewhere.
  \item Joint diffusion: \(R = 2|s_j\rangle\langle s_j| - I\) with
        \(|s_j\rangle = (H\otimes U)|0\rangle_{a_1}|0\ldots 0\rangle_{\text{reg}}\),
        tensored with \(I_2\) on ancilla-2.
  \item Projectors \(P^{(a_2)}_0, P^{(a_2)}_1\) for the ancilla-2 measurement.
\end{itemize}

\textbf{Simulation branch bookkeeping.} At each iteration we split
the state into the outcome-1 branch (probability \(p_1\); register
is target; contributes to accumulated success probability) and the
outcome-0 branch (probability \(p_0\); renormalized and passed to the
next joint-diffusion step). This is a faithful implementation of the
algorithm as literally written --- the outcome-1 arm terminates with
guaranteed target, the outcome-0 arm continues.

\textbf{Comparison metric.} After \(q\) iterations, the total success
probability is
\(P_\text{succ} = \sum_{k=1}^{q} p^{\text{(exit at $k$)}}_1 \;+\; p^{\text{(still running)}} \cdot P(\text{register}=|t\rangle\,|\,\text{still running})\).
We compare \(1 - P_\text{succ}\) to \(\varepsilon^{2q+1}\).

\subsection{What worked}
\begin{itemize}
  \item Direct explicit matrix construction of the oracle, joint diffusion, and
        ancilla-2 projectors reproduces Eq.~(6) exactly.
  \item Renormalising the outcome-0 branch between iterations (matching the
        analytical treatment in \S3 of the paper) is what makes the identity
        \(\varepsilon^{2q+1}\) hold; see \S\ref{sec:friction}.
  \item Monotone decrease in \(q\) at each fixed \(n\) holds (claim C3).
\end{itemize}

\subsection{What didn't (initially)}\label{sec:friction}
Our first-pass implementation tracked the outcome-0 branch \emph{without}
renormalising after each ancilla-2 measurement. In that formulation, \(q=1\)
still matched the paper's \(\varepsilon^3\) to machine precision, but
\(q\ge 2\) showed a systematic overshoot (measured error \(>\) predicted). The
fix was to renormalize the outcome-0 branch so the subsequent joint diffusion
acts on a unit vector proportional to \(|t'_j\rangle|0\rangle_{a_2}\), which is
precisely what the paper's analytical treatment implicitly does when it
writes \(|\psi_f\rangle = \sqrt{1-\varepsilon^2}|t_j\rangle + \varepsilon|t'_j\rangle\)
(a normalized state, not \((1/N)|t'_j\rangle\)). After that fix all rows
match to \(\sim 10^{-15}\). See \texttt{report/failure\_analysis.md} for the
full trace.

\subsection{Not tested}
\begin{itemize}
  \item Average-case query count vs Phase-\(\pi/3\) at matched worst-case (C6):
        would require also implementing Phase-\(\pi/3\) and averaging over an
        \(\varepsilon\)-distribution. Deferred as out-of-scope for the
        1-hour replication window.
  \item Fault tolerance / behavior under gate noise (mentioned as a bonus
        feature in the paper's Discussion).
\end{itemize}

\section{Verdict}

\textbf{REPLICATED.} The paper's central claim (Eq.~6) that the
two-ancilla algorithm delivers residual error probability
\(\varepsilon^{2q+1}\) for every positive integer \(q\) is confirmed by
independent NumPy statevector simulation to machine precision across
12 \((n,q)\) cells with \(n\in\{2,3,4\}\), \(q\in\{1,2,3,4\}\). Max
\(|\text{measured}-\text{predicted}|=3.3\times 10^{-15}\); monotonicity
in \(q\) verified. The reproducible code and results are in
\texttt{report/evidence/}.
