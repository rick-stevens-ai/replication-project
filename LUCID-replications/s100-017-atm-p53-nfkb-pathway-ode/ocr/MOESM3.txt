                    Definition of the variables

  Generally, in the mathematical model values of the variable are considered as the
number of molecules per cell. Variables describing genes indicate the number of
active genes with the assumption that there are two alleles of each gene in each cell.
DSB and Ra stand for number of DNA double-strand breaks and active receptors,
respectively. Values of the variables as presented separately for Ctr-RNAi and Wip1-
RNAi cells.
