#### Software and code

Policy information about <u>availability of computer code</u>

Data collection

The open source Agent-Based Modeller BioDynaMo was used both to generate and collect the data. It can be found on GitHub under https://github.com/BioDynaMo/biodynamo. The open source Monte-Carlo simulator Topas-nBio was used to generate data. In can be found on GitHub under https://github.com/topas-nbio/TOPAS-nBio.

The custom code used to implement the Agent-Based - Monte-Carlo model is available on Zenodo.

Data analysis

No software was used for data analysis

For manuscripts utilizing custom algorithms or software that are central to the research but not yet described in published literature, software must be made available to editors and reviewers. We strongly encourage code deposition in a community repository (e.g. GitHub). See the Nature Portfolio guidelines for submitting code & software for further information.
