PAPER'S CORE CLAIMS:
- Theorem 1 (McClean-type): for a random hardware-efficient PQC where sub-blocks form unitary 2-designs, E[gradient]=0 and Var[gradient] in O(c^{-N}) with c>1 (exponential decay in qubit count N = "barren plateau").
- Main new result: Var[d<H>/d theta] decreases exponentially with the DISTANCE between a Hamiltonian term and the canonical centre of the tensor network.
- Consequence: for qMPS the observable-to-centre distance grows LINEARLY in N so gradient variance decays EXPONENTIALLY in N (barren plateau); for qTTN (and qMERA) that distance grows only LOGARITHMICALLY in N so gradient variance decays only POLYNOMIALLY in N (trainable). Gradients are exponentially cheaper classically.
