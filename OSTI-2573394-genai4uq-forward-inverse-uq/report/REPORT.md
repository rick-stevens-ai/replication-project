## 2. Methods

### 2.1 Problem definition (exactly per paper §4.1)

- Prior: X ~ U(−2, 2).
- Forward: g(X) = X², observation Y = g(X) + ε with ε ~ N(0, σ²), σ = 0.01.
- Target: for a held-out y* draw samples from p(X | Y = y*), which analytically is
  `p(x|y*) ∝ exp(−(y* − x²)²/(2σ²)) · 1[−2 ≤ x ≤ 2]`.
  For y* > 0 this posterior has two symmetric peaks at x = ±√y*.

### 2.2 Reverse-time ODE with MC score (paper §2.2)

For the choice γ_t = 1 − t and ρ_t² = t on t ∈ [0,1] we derive

- δ(t) = d log γ_t / dt = −1/(1−t)
- dρ²/dt = 1, so τ²(t) = 1 − 2·δ(t)·ρ² = 1 + 2t/(1−t) = (1+t)/(1−t)

Reverse-time ODE (from t=1 down to t=0):

```
dZ_t/dt = δ(t)·Z_t − ½·τ²(t)·S(Z_t, t; y)
        = −Z_t/(1−t)  −  ½·(1+t)/(1−t)·S(Z_t, t; y)
```

Score approximation (paper Eq. 7–8) with α_t = γ_t = 1−t and β_t² = ρ_t² = t, using a mini-batch reference set {x_{jn}}ⁿⁿ⁼¹ drawn from the prior:

```
Q_{t|0}(Z_t | x_j) = N(Z_t ; (1−t)·x_j, t)
p(y | x_j) = N(y ; x_j², σ²)
w_n ∝ Q_{t|0}(Z_t | x_{jn}) · p(y | x_{jn}) · p(x_{jn})     (uniform prior → indicator)
S(Z_t, t; y) ≈ Σ_n [ −(Z_t − (1−t)·x_{jn}) / t ] · w_n
```

We integrate with plain **explicit Euler** on a uniform t-grid, n_steps=40, from t=1 to t=0.01. Everything vectorised across B pairs per batch (see §2.3 for compute cost). Paper doesn't state which ODE solver they use, but the choice of scheme is downstream of the framework and shouldn't change the fixed-point of the mapping.

### 2.3 Labeled dataset & FCNN training

- **M = 6 000** labeled pairs (paper: 20 000). Each pair (y_m, z_m, x_m) is built by:
  1. Sampling x_true ~ U(−2, 2), computing y_m = x_true² + ε.
  2. Sampling z_m ~ N(0, 1). Integrating the reverse ODE with z_m as Z₁ and y_m fixed, producing x_m as Z₀.
- **Reference set:** n_ref = 2 000 (paper doesn't state, but their labeled set is 20 000 so a similar order is plausible). Ref set drawn once from the prior, reused across all M pairs and all ODE steps.
- **FCNN:** input (y, z) ∈ ℝ², 3 hidden layers × 128 units, GELU activations, dropout 0.05, output x ∈ ℝ. Adam, lr 1e-3, batch 128, 400 epochs, MSE loss on x_m targets. 15% held out as validation. Device: MPS (Apple M2).

### 2.4 Evaluation protocol

- **Test set:** 200 fresh (x_test, y_test) pairs from the forward model.
- **Posterior recovery at 4 specific y*'s:** y* ∈ {0.25, 1.00, 2.25, 3.24}, corresponding to true modes at x = ±{0.5, 1.0, 1.5, 1.8}. For each y*, we draw 2 000 z ~ N(0, I) and evaluate G(y*, z) → 2 000 posterior samples; we compare against 2 000 samples from the analytical posterior obtained via rejection sampling.
- **Metrics:**
  - Wasserstein-1 between our samples and the analytical posterior samples.
  - Bimodality: fraction on positive branch, mean of each branch, error vs ±√y*.
  - Coverage of 95% and 50% central credible intervals across all 200 test cases.
  - Forward PICP@95: fraction of true y in the 95% predictive interval, which for this problem is x_test² ± 1.96·σ.

Everything is single-seed (`--seed 42`) and reproducible with the command below.

### 2.5 How to reproduce

## 5. Failure modes and honest caveats

1. **Score estimator saturates at high |x|.** The mini-batch MC score of Eq. 7 with a fixed reference set drawn once from a uniform prior degrades where the likelihood N(y; x², σ²) is very sharp (σ = 0.01). At y=3.24 the likelihood is essentially a delta at x = ±1.8, and 2 000 uniform reference points give only a handful with x² near 3.24. Fix: (i) larger reference set, (ii) importance-weighted reference sampling that concentrates ref points near modes, (iii) adaptive ODE solver instead of plain Euler. Paper's exact solver is unspecified.
2. **FCNN capacity + label noise.** With val MSE ≈ 0.28 the model is at the label-noise floor; it cannot produce sharper posteriors than its own training targets. Increasing M and n_ref simultaneously (say M=20 000, n_ref=10 000) would tighten this ~10×.
3. **Coverage failures.** 95%-HDI over-covers (100%) because posteriors are too wide; 50%-HDI under-covers (19.5%) because mode locations are slightly biased at moderate/high y*. These two errors are consistent with a "wide, slightly-shifted-mode" posterior — exactly the failure mode expected from (1)+(2).
4. **We didn't attempt Examples 2 (ELM) or 3 (CO₂).** ELM needs the AmeriFlux LH observations from Gu et al. 2016 and 8-parameter ranges; CO₂ needs a 250 MB Google-Drive-hosted dataset from Fan et al. 2024. Both are downloadable via the paper's `patrickfan/GenAI4UQ` GitHub, but our replication is deliberately from-scratch (no code reuse).
