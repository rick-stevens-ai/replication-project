# Brief — OSTI 2887218

Schuster, Yin, Gao & Yao (*Phys. Rev. X* **15**, 041018, 2025; DOI 10.1103/xct1-7kf2) prove that ANY noisy quantum circuit with local depolarizing noise of strength γ > 0 can be classically simulated to compute expectation values of any observable in polynomial time (Theorem 1, uniform noise) or quasi-polynomial time (Theorem 2, gate-based noise), on *most* input states drawn from a "low-average ensemble" (e.g. the computational basis).  The algorithm is Pauli-path truncation: enumerate Pauli paths `(P_0,…,P_d)` with total Hamming weight `∑_t w[P_t] ≤ ℓ`, damp each by `e^{-γ·∑w}`, and multiply per-layer transition amplitudes `a^{(t)}_{PQ} = (1/2^n) tr(Q U_t† P U_t)`.  The paper is pure theory: no numerical figures beyond three schematics and no accompanying code.  We independently implement Algorithm 1 from scratch, verify it converges to the *exact* Kraus-simulated expectation value (agreement at machine precision when ℓ reaches the true path support), and confirm the paper's two central quantitative predictions on 4-qubit brick-wall circuits: (V2) at fixed truncation ℓ, RMS error decays monotonically as γ grows; (V3) the number of low-weight Pauli paths at fixed ℓ scales polynomially in the qubit count n. All compute done on uicgpu; free tooling only (numpy, no LLM inference calls needed).
