# NO_GO_REPORT — LUCID100 slot 46

**Paper:** Priya et al., *Int. J. Radiat. Biol.* 102:455–464 (2026) · DOI 10.1080/09553002.2025.2607004 · PMID 41677130.

**One-paragraph rationale:** Wet-lab MS-HRM + RT-qPCR pilot on n=26 male Kerala HLNRA residents stratified by lifetime cumulative dose (`<100` vs `>100` mSv). Headline claim: RAD23B / DNMT3A / MRE11A / BRCA1 promoter hypermethylation in the high-dose subgroup. Publisher closed-access (T&F); Unpaywall `closed`; OpenAlex no repo full-text; EuropePMC `hasSuppl=N`; no GEO/SRA/ENA/Zenodo/dbGaP accessions; only artifact deposited publicly is one CC BY 4.0 supplement on figshare (article 31324581 → `irab_a_2607004_sm4756.docx`, MD5 verified) containing **MS-HRM primer sequences + cycling conditions only — no methylation matrix, no per-sample mSv, no expression data**. The headline correlation is therefore not testable from public artifacts and the assay is not virtualizable. Replication would require bench work and a new chronic-LDIR cohort, which is outside LUCID100 slot scope (no author contact, no wet lab).
