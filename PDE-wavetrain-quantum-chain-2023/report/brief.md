# Brief — WaveTrain (Riedel et al., 2023) — Independent Replication #2

**Paper.** J. Riedel, P. Gelß, R. Klein, B. Schmidt, *"WaveTrain: A Python package for numerical quantum mechanics of chain-like systems based on tensor trains,"* J. Chem. Phys. **158**, 164801 (2023). DOI: [10.1063/5.0147314](https://doi.org/10.1063/5.0147314). arXiv preprint: [2302.03725v2](https://arxiv.org/abs/2302.03725). Code: <https://github.com/PGelss/wave_train>, backend <https://github.com/PGelss/scikit_tt>.

**What we did.** Independent from-scratch reproduction (this is the second replication of this paper; sibling dir `PDE-Riedel-WaveTrain-tensor-trains-2023` did the first). We downloaded the arXiv PDF, installed WaveTrain + scikit_tt in a fresh Python 3.12 venv, ran the paper's bundled `Exciton/tise_1.py` example, hit the same numpy safe-casting bug in `scikit_tt/solvers/evp.py`, independently derived a minimal patch (cast `micro_op` to complex128 only when the deflation addend is complex), then built our own instrumented driver `replication_bench.py` that captures per-state energy and TT bond-rank profile (WaveTrain does not persist the full spectrum on the TISE object in ALS mode). We swept N ∈ {4, 6, 8, 10, 12} periodic homogeneous rings at n_levels = N+1 and compared to the closed-form single-exciton tight-binding spectrum `E_k = α + 2β·cos(2πk/N)` (plus vacuum ground state at E=η). Bonus: a N=6 OPEN chain check that switches the analytic reference to `E_k = α + 2β·cos(πk/(N+1))`.

**Bottom line.** REPLICATED on core physics — N=4 error at machine precision (~6e-15), N=6 max error ~1e-4 Ha vs analytic single-exciton band; software artifact **fails as-shipped on modern NumPy** (independently reproduces the sibling report's finding) and requires a small patch to `scikit_tt/solvers/evp.py`. The rank-scaling claim is only WEAKLY supported by the sweep because the `ranks=15` ALS cap saturates at N≥8, so we can conclude "r=15 suffices for the single-exciton band across N=4..12" but not the stronger "TT bond ranks grow near-linearly in N" claim as stated.
