# Brief — OSTI 2587616 (Reimer et al. 2025)

Reimer et al. train a graph-convolutional network as a per-atom transition-rate ansatz for KMC-based vacancy diffusion in an equiatomic FeNiCrCoCu high-entropy alloy, using 10 LAMMPS-MD trajectories (Farkas EAM, 1500 K, 863 atoms + 1 vacancy) as training data and comparing two variants (1-NNI: 12-atom graph; 2-NNI: 54-atom graph including 2nd neighbours). The authors released their post-processed transition-event data + KMC code on GitHub (CLEANit/EvoSys-Research-Data-Code, MIT). This replication independently recomputed all 8 dataset-count values in the paper's Table I and all 20 per-element transition proportions in Table II from the released pickles — every number matches exactly (residuals ≤ 0.005 pp). An independent KL-divergence and total-variation analysis on the released transition sequences confirms the paper's comparative claim that the 2-NNI model reproduces MD dynamics ~3× more faithfully than 1-NNI (D_KL 0.012 vs 0.037 against MD-train). Tables III/IV/V (NEB barriers, jump rate, ASD, diffusion coefficient) cannot be re-derived from the released artifact — those require re-running the LAMMPS MD and 5000-configuration NEB, which is well-defined in the paper but was out of scope for this pass. Verdict: **PARTIAL REPLICATION (strong)** — data is authentic, all released-scope numbers reproduce exactly, one core comparative claim independently confirmed.
