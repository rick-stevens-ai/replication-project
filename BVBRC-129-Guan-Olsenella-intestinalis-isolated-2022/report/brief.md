# Brief

Independent replication of Guan et al. 2022 (*Arch. Microbiol.* 204:384), a novel-species announcement describing **Olsenella intestinalis sp. nov.** (type strain BGYT1ᵀ = KCTC 25379ᵀ = GDMCC 1.3011ᵀ) from cow feces. Using only the paper's publicly-deposited artifacts (`GCF_023276655.1` / `NR_181929.1`) and free-endpoint tooling (fastANI, skani, hand-rolled reciprocal BLASTn ANIb, Biopython + Clustal Omega for 16S phylogeny, NCBI Datasets + E-utilities), we replicate the core taxonomic conclusion (BGYT1 is a distinct *Olsenella*/*Parafannyhessea* species — every ANI method well below the 95% species boundary) and the primary 16S neighbor claim (~98.4% to *O. umbonata*), and expose several concrete discrepancies: the paper's abstract genome length (2,476,083 bp) contradicts its own body text (2,453,694 bp) and NCBI (2,453,694 bp); its ANI value (76.8%) is 3–7 pp below what modern tools report for the same pair; and its "chitinase / β-1,3-glucanase" claim is not supported by the current PGAP annotation. Verdict: **PARTIAL**.
