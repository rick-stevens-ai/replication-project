# One-paragraph brief — Zeng et al. 2025, G2PDeep-v2 (biom15121673)

**What:** OSTI-3362513 / DOI 10.3390/biom15121673 is the tool paper for **G2PDeep-v2**, a web platform (https://g2pdeep.org/) that lets researchers upload up-to-three types of multi-omics data (gene expression, miRNA expression, DNA methylation, protein expression, SNP, CNV), auto-tune deep-learning models (multi-CNN + LR/SVM/DT/RF), and get back phenotype predictions, saliency-based biomarkers, and GSEA. Headline benchmarks: multi-CNN AUC = **0.907** on TCGA-BRCA 3-omics long-term-survival, and out-of-the-box outperformance on the SKCM 41-omics-combination sweep. **Why replicate:** it is a tool paper whose central claim is that a live, general-purpose deep-learning multi-omics web server exists, and that its underlying CNN methodology works on real data. Both parts are cheaply testable. **What I did:** verified the server + backend REST API are live (187 datasets / 68 models / 590 projects served), confirmed the reference code repo (shuaizengMU/G2PDeep_model, Apache-2.0) and the FireBrowse TCGA data source are still online, and — on a real A100 (uicgpu) — independently re-implemented and trained the G2PDeep dual/multi-CNN architecture on the actual SoyNAM SNP data shipped with the repo, obtaining held-out test PCC = **0.6148** (height) and **0.4894** (yield), in the reasonable ballpark for genomic-selection CNNs on this well-known benchmark. The single number I did **not** re-run is the specific TCGA-BRCA AUC=0.907 (needs 6-omics preprocessing for hundreds of BRCA patients — out of scope for one replication pass). Verdict: **PARTIAL**.
