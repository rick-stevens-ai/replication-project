\section{Paper summary}

Kirby and Love propose a polynomial-time, ansatz-independent classical test
that decides whether the objective Hamiltonian of a VQE run is
\textbf{contextual} --- a hallmark of genuine non-classicality and a barrier
to efficient classical simulation --- or \textbf{non-contextual}, in which case
the VQE instance admits an efficient noncontextual hidden-variable simulation
and is therefore not a bona-fide demonstration of quantum advantage.

The central result (Theorem 3) states: for a set $S$ of Pauli operators, let
$T \subseteq S$ be obtained by removing any operator that commutes with all
others in $S$. Then $S$ is non-contextual if and only if commutation is an
equivalence relation on $T$. Constructively (Theorem 2 / Sec.~II algorithm),
$S$ is \emph{contextual} iff there exist three operators $A, B, C \in T$
with $[A,B]=0$, $[A,C]=0$, but $\{B,C\}=0$: commutation on $T$ fails
transitivity. Applied to Table~I to published VQE experiments, small-molecule
runs (all $\mathrm{H}_2$ variants and the deuteron) are non-contextual,
whereas larger molecules and richer active spaces ($\mathrm{HeH}^+$, LiH,
BeH, $\mathrm{H}_2\mathrm{O}$, Schwinger model) are contextual.

\textbf{What the code does.}
\begin{enumerate}
\item Build \emph{real} molecular Hamiltonians from PySCF integrals via
  OpenFermion: $\mathrm{H}_2$/STO-3G (JW 4q, BK 4q, BK-tapered 2q via
  \texttt{symmetry\_conserving\_bravyi\_kitaev}), $\mathrm{HeH}^+$/STO-3G
  (JW 4q), LiH/STO-3G (occ=[0], active=[1,2,5], BK 6q),
  $\mathrm{H}_2\mathrm{O}$/STO-3G (occ=[0,1], active=[2..5], JW 8q).
\item \textbf{Contextuality test (Theorem 3, direct implementation):}
  extract $S$ (unique non-identity Pauli strings); form
  $T = \{P \in S : \exists Q \in S,\ \{P,Q\}=0\}$; search for a triple
  $(A,B,C) \subset T$ with $[A,B]=[A,C]=0$ and $\{B,C\}=0$. If found:
  \emph{contextual}, return the witness; else \emph{non-contextual}.
  Commutation is decided by counting per-qubit non-identity mismatches
  (commute iff even).
\item \textbf{Real VQE sanity check} on 2-qubit $\mathrm{H}_2$: build the
  dense $4{\times}4$ Hamiltonian by summing coefficient$\cdot\otimes$Pauli;
  exact-diagonalize; run a hardware-efficient Ry-Ry-CNOT-Ry-Ry ansatz
  (4 params) with COBYLA (5 seeds, 500 iters each); compare to FCI.
\end{enumerate}

Raw evidence: \texttt{report/evidence/contextuality\_results.json}.

\section{Verdict}

\textbf{REPLICATED.} All six paper contextuality verdicts (three
$\mathrm{H}_2$ variants non-contextual; $\mathrm{HeH}^+$, LiH,
$\mathrm{H}_2\mathrm{O}$ contextual) are independently reproduced from a
from-scratch OpenFermion/PySCF pipeline and a direct implementation of
Theorem~3 (non-transitivity of commutation on $T$). The 2-qubit $\mathrm{H}_2$
VQE sanity check recovers FCI to $1.6\times10^{-10}$~Ha, confirming the
Hamiltonian under test is chemically real. Witness triples $(A,B,C)$ are
reported for each contextual case, matching the paper's algorithmic
characterization ($A$ commutes with $B$ and $C$; $B$ anticommutes with $C$).

\section{Critique (honest failure analysis)}

This replication reproduced the paper's \emph{headline algorithmic
deliverable} --- the polynomial contextuality classifier and its verdicts
on Table~I VQE Hamiltonians --- but several important caveats limit the
strength of the corroboration:

\begin{itemize}
\item \textbf{Contextuality-witness test WAS independently reimplemented
  for the paper's specific Hamiltonians.} We did not merely quote the paper's
  yes/no labels; we regenerated the molecular integrals from PySCF, mapped
  through OpenFermion's JW/BK transforms, and ran our own from-scratch
  Theorem~3 implementation (non-transitivity of commutation on $T$). Witness
  triples are reported for each contextual case. This is the strongest
  form of independent verification for this class of paper.

\item \textbf{Numeric $|S|$ differs from Table~I (major caveat).} For BK 4q
  $\mathrm{H}_2$ we get $|S|=14$ vs.\ paper's 5; for $\mathrm{HeH}^+$ 26
  vs.\ 8; LiH 117 vs.\ 13; $\mathrm{H}_2\mathrm{O}$ 104 vs.\ 22. The paper's
  $|S|$ column reports the number of Pauli terms in the \emph{particular
  reduced Hamiltonian used in the cited experiment} --- typically after Z2
  tapering, active-space selection, symmetry reductions, and encoding-specific
  term cancellations tuned to the hardware. We use default OpenFermion
  transforms with straightforward active-space choices. The
  \emph{contextuality verdict} is preserved (it is invariant under the
  operations that trim $S$ in these ways), but we did not independently
  reconstruct each cited experiment's exact reduced Hamiltonian. A stronger
  replication would rebuild the Hempel/Peruzzo/Nam reduced Hamiltonians
  term-for-term and confirm $|S|$ matches before running the test.

\item \textbf{Classical simulability threshold was NOT quantitatively
  verified.} The paper's underlying claim --- that non-contextual VQE
  instances admit an efficient noncontextual hidden-variable simulation
  (i.e., are classically tractable in a specific sense) --- was NOT tested.
  We verified the classifier gives the same verdict as the paper on the
  same inputs, but we did not construct the noncontextual hidden-variable
  model for any non-contextual instance and confirm it reproduces observables.
  This is the theoretical content that makes the non-contextual verdict
  \emph{mean} ``classically simulable''; that link is quoted, not
  independently established here.

\item \textbf{$CD_0$ heuristic (quantitative claim) NOT reproduced.} The
  paper's $CD_0 \in \{0.27, 0.33, 0.38, 0.74, 0.77\}$ values for the larger
  molecules quantify \emph{how contextual} the Hamiltonian is. We reproduced
  only the binary contextual/non-contextual verdict. The heuristic uses a
  specific approximation scheme (Appendix C) that we did not implement.
  This means we can say the paper's classification is right; we cannot
  say the paper's degree-of-contextuality quantification is right.

\item \textbf{No comparison against alternative advantage-witnesses.} The
  paper implicitly positions contextuality as \emph{the} witness of
  non-classicality for VQE. Alternative witnesses --- magic (stabilizer
  rank / mana), entanglement entropy of the VQE ground state, negativity
  of the Wigner function --- would give correlated but not identical
  verdicts. A stronger replication would classify the same six
  Hamiltonians with two or three alternative witnesses and report agreement
  / disagreement. We did not do this.

\item \textbf{Only the specific molecules in Table~I were tested.} The
  paper's Table~I includes BeH (contextual, $CD_0{=}0.74$) and the Schwinger
  model (contextual, $CD_0{=}0.77$), which we did not test. Extending to
  these would strengthen the coverage of the ``larger $\Rightarrow$
  contextual'' pattern.

\item \textbf{No LLM was used in scoring.} The verdict is a direct
  algorithmic yes/no with an explicit witness triple in each contextual
  case; there is no soft-judgment component. That is a strength.

\item \textbf{Compute: $\sim$90s CPU on CherryRd.} No paid API, no GPU,
  no HPC. Fully in scope for the QC-100 wave budget.
\end{itemize}

Bottom line: the paper's headline algorithmic classifier is
correctly implemented and gives the paper's verdicts on real molecular
Hamiltonians at STO-3G. What is NOT independently verified: the exact term
counts (we use default reductions), the quantitative $CD_0$ heuristic,
the underlying ``non-contextual $\Rightarrow$ classically simulable''
theoretical claim, and any comparison with alternative non-classicality
witnesses.
