# Brief — BVBRC-73

We independently re-ran the BV-BRC-style whole-genome analysis of Rahman et al. 2023's *Aeromonas veronii* strain **Alim_AV_1000**, sequenced from ulcerative lesions of stinging catfish (*Heteropneustes fossilis*) in Bangladesh. Using the paper's deposited assembly (GenBank **JALLKR000000000** / RefSeq **GCF_026738955.1**, from BioProject **PRJNA810265**) and free/open tools (skani for ANI, Prodigal for CDS, barrnap for rRNA, aragorn for tRNA, abricate against CARD/NCBI/ResFinder/ARGannot/MEGARes/VFDB, PubMLST REST API for MLST), the paper's central genome-content claims replicated cleanly — genome size (Δ 51 bp on 4.49 Mb = 0.001%), GC% (58.87% exact), contig count (93 exact), rRNA count (13 exact), species-level ANI clustering with *A. veronii* TH0426 (96.34%) and B565 (96.47%) above the 95% species boundary, and the full T2SS/T3SS/T6SS + flagella/pili/adhesion virulence-factor repertoire. Four independent LLM judges (GPT-5.2, Sonnet 4.5, Gemini 2.5 Pro, GPT-4.1) unanimously scored the replication **PARTIAL** (mean coverage 8.75, agreement 7.0, fidelity 7.5, reproducibility 7.5). Two claims did **not** replicate: (a) the reported MLST **ST 492** is **CONTRADICTED** — none of the five exactly-matched allele IDs we found (gyrB=633, groL=91, gltA=340, metG=124, recA=1460) match ST 492's PubMLST profile (gyrB=112, groL=347, gltA=44, metG=217, ppsA=384, recA=381), and no ST in the current 2,755-profile PubMLST table matches our observed alleles; (b) the paper's tetracycline resistance gene was not detected in current CARD/ResFinder scans (β-lactam resistome — cphA4 carbapenemase, OXA-12/blaOXA-12/ampS, rsmA regulator — did replicate cleanly). The 4,229-CDS and 102-tRNA counts are 3–6% lower with modern callers (Prodigal 4,063 / aragorn 96) — expected annotation-tool drift.
