Data for "A Pair Measurement Surface Code on Pentagons"

Authors/Creators

  • Craig Gidney1
  • 1. Google

Description

Code, circuits, and statistical data created as part of writing the paper "A Pair Measurement Surface Code on Pentagons".

code.zip: A snapshot of the source code from https://github.com/Strilanc/cairo-surface-code/releases/tag/v1

circuits.zip: The noisy circuits that were generated and sampled for the results in the paper.

stats.csv: The Monte Calro statistics collected from the circuits for the results in the paper.
