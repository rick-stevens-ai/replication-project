# Brief — BVBRC-88 / Blackwell et al. 2021 (661k bacterial genomes)

Independent replication target: **Blackwell GA, Hunt M, Malone KM, Lima L, Horesh G, Alako BTF, Thomson NR, Iqbal Z.** *Exploring bacterial diversity via a curated and searchable snapshot of archived DNA sequences.* PLoS Biology 19(11): e3001421 (Nov 9, 2021). DOI 10.1371/journal.pbio.3001421. PMID 34752446.

This is a **Methods & Resources** dataset paper: 661,405 bacterial genomes assembled by a uniform pipeline (Unicycler/SPAdes wrapper) from the Nov-2018 ENA snapshot, plus a searchable COBS bit-sliced index (872 GB), MinHash sketches, ppSketch (67 GB), full QC + AMR + plasmid metadata, and 3 Rnotebooks reproducing every figure. Full re-assembly requires ~30k CPU-months so is out of the wave brief's budget. Replication therefore targets the paper's central *dataset* claims — cardinality (661,405 total, 639,981 high-quality, 2,336 species, top-20 ≈ 90%), file/manifest availability (checklist + path index + Figshare metadata + per-genome contigs.fa.gz), and species-composition pattern — via manifest verification + MD5-checksummed random sample + independent recount of the composition statistics from the raw metadata files. Every one of these end-to-end checks passed.
