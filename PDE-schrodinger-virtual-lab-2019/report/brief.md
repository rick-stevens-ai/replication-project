# Brief

**Paper:** Figueiras, Olivieri, Paredes, Michinel, *"An open source virtual laboratory for the Schrödinger equation,"* Eur. J. Phys. **39** (2018) 055802, DOI [10.1088/1361-6404/aac999](https://doi.org/10.1088/1361-6404/aac999). Open-access (CC-BY 3.0).

**What:** Independent replication of the paper by *running the authors' own published Python code library* ([`github.com/pyNLSE/bpm`](https://github.com/pyNLSE/bpm)) on 12 of its 20 canonical example configurations (10 in 1D + 3 in 2D + a targeted reflectionless-scattering sweep). This complements the sibling replication `PDE-Figueiras-Schrodinger-BPM-splitstep-2018/` (same DOI), which independently *reimplemented from scratch and deliberately did NOT use the authors' code*. Together the two replications verify both (a) that the paper's algorithm is correct in principle (sibling) and (b) that the released software artifact actually reproduces the paper's stated behavior (this dir).

**Why solid:** In every zero-absorption run the split-step Fourier method conserves ∫|ψ|² to **10–13 digits** (Solitons_in_phase 7.6e-13, Thomas_Fermi 4.7e-12, Soliton_Emission_A 3.6e-11, Collapse_2D 2.7e-13, Gaussian_Beam_2D 2.2e-12). In every absorbing-shell run the norm decreases exactly as expected (outgoing tails swallowed). Reflectionless integer-s Pöschl-Teller potentials produce ~3× less reflection than half-integer s (measured across s ∈ {1, 2, 3, 10} vs {0.5, 1.5, 2.5}) with the residual dominated by the incoming Gaussian's spatial spread — reproducing Fig 1. All 20 published example scripts execute out of the box on Python 3.14 with only two cosmetic warnings, i.e., the artifact is genuinely reusable.
