\section{Paper}

A genome-report describing the first complete genome of \emph{Streptococcus thermophilus} ACA-DC 2,
a yogurt starter isolate. Sequenced (Illumina + gap-filling), assembled into \textbf{one circular
chromosome}, and annotated with \textbf{RAST v2.0} plus Prodigal / MetaGeneAnnotator / FGENESB gene
calling, GenePRIMP pseudogene detection, WebMGA / EggNOG COG assignment, Pfam / Phobius domain and
topology analysis, and CRISPRFinder / REBASE / BAGEL3 for defense and bacteriocin features. The
paper's central deliverable is the \textbf{Table 3 genome-statistics report} plus qualitative
findings on CRISPR-\emph{cas}, restriction-modification systems, stress-response genes,
antimicrobial peptides, and whole-genome phylogeny. It is exactly the class of paper the BV-BRC
\textbf{Comprehensive Genome Analysis (RASTtk)} workflow is designed to reproduce.

\section{Method}

All data pulled from \textbf{free public endpoints only}; all inference via \textbf{free Argo}
(localhost:44497). No paid PDF / image tools used --- paper text obtained via Europe PMC OA XML.

\begin{enumerate}[leftmargin=*, itemsep=2pt]
  \item \textbf{Paper text.} Fetched Europe PMC OA full-text XML
  (\texttt{PMC5282782/fullTextXML}, 107 KB), stripped to plain text
  (\texttt{work/paper\_text.txt}), extracted Table 3 verbatim and ENA \textbf{LT604076} +
  BioProject \textbf{PRJEB14916}.
  \item \textbf{Assembly resolution.} NCBI Datasets v2alpha REST
  \texttt{genome/bioproject/PRJEB14916/dataset\_report} $\rightarrow$ \textbf{GCA\_900094135.1}
  (author GenBank) and \textbf{GCF\_900094135.1} (RefSeq / PGAP).
  \item \textbf{Genome download.} NCBI Datasets REST
  \texttt{genome/accession/<acc>/download} with GENOME\_FASTA + PROT\_FASTA + GENOME\_GFF +
  CDS\_FASTA for both assemblies (free, no auth).
  \item \textbf{Statistics recompute.} \texttt{work/genome\_stats.py} (pure Python stdlib):
  length, GC bp/\%, contig count, CDS count (protein.faa + GFF), tRNA / rRNA / pseudogene from
  GFF, gene-biotype breakdown.
  \item \textbf{De-novo re-annotation (RASTtk-analog).} Copied GCA chromosome to \textbf{uicgpu}
  (conda env \texttt{bvbrc28}), ran \textbf{Prokka 1.12}
  (\texttt{-{}-kingdom Bacteria -{}-genus Streptococcus -{}-species thermophilus}), which bundles
  Prodigal (CDS), Aragorn (tRNA/tmRNA), barrnap (rRNA) --- same tool families the BV-BRC CGA
  RASTtk pipeline uses.
  \item \textbf{CRISPR detection.} \textbf{minced} on the chromosome at default \texttt{minNR=3}
  and at \texttt{minNR=2}.
  \item \textbf{LLM-judge scoring.} Fed the full claims table + real recomputed results to
  \textbf{argo:gpt-5.2} (free) for verdict / coverage / agreement. Output in
  \texttt{report/evidence/judge\_output.txt}.
\end{enumerate}

\section{GENUINE CRITIQUE}

This section is a deliberately hostile, honest reading of what this replication actually
demonstrated and where it falls short. It is written to be useful to a reviewer, not to defend the
result.

\subsection{What genuinely replicated}
\begin{itemize}[leftmargin=*, itemsep=2pt]
  \item \textbf{Record fidelity is perfect.} Every Table 3 number was recomputed by an independent
  pure-stdlib parser and matched to the digit --- including the somewhat unusual GC bp count
  (679{,}104), pseudogene count (224), and total gene count (1{,}850). If a mistake or silent
  post-publication edit had happened, this check would have caught it. It did not.
  \item \textbf{Structural annotation is robust across pipelines.} PGAP, RAST (paper), and Prokka
  all converge on \textbf{56 tRNAs} exactly, and on rRNA within $\pm 1$. tRNA calling is the least
  ambiguous piece of the annotation, and everyone agrees.
  \item \textbf{The paper's most distinctive CRISPR claim survived a null test.} Default
  \texttt{minced} finding \emph{zero} arrays is genuinely corroborative of ``both CRISPRs are
  single-spacer,'' because that is precisely the arrangement that fails default repeat-count
  thresholds. This is one of the strongest non-trivial confirmations in the replication.
\end{itemize}

\subsection{What did NOT replicate, and why it matters}
\begin{itemize}[leftmargin=*, itemsep=2pt]
  \item \textbf{The exact Table 3 agreement is largely tautological.} The deposited assembly IS
  the paper's assembly. Recomputing statistics from that assembly is a strong record-fidelity
  check but a weak scientific-replication check --- the numbers cannot really disagree unless
  the deposit itself is broken. C2--C7 should therefore be read as ``the public record faithfully
  reflects Table 3,'' not ``an independent group re-derived Table 3.''
  \item \textbf{The 63.89\% function-assignment number is nowhere close to being reproduced}
  (Prokka default: 35.9\%). The paper achieved 63.89\% via RAST + WebMGA + EggNOG + Pfam + manual
  curation. A single-tool default run naturally undershoots. This is a large gap and it should be
  flagged rather than papered over: \emph{if the claim of interest is functional coverage, this
  replication does not reproduce it.} A fair test would require rerunning the full multi-tool
  stack, or running the actual BV-BRC CGA service.
  \item \textbf{The ``exactly two CRISPRs'' claim is not reproduced.} \texttt{minced} at
  \texttt{minNR=2} returns \emph{six} candidate arrays. One of them positionally coincides with
  the paper's \emph{cas}-flanked array near STACADC2\_0849, which is genuinely supportive, but
  ``6 candidates including the right one'' is not the same as ``exactly 2 curated arrays.''
  The paper's count comes from CRISPRFinder + manual curation; we ran neither. The presence /
  short-array / \emph{cas}-adjacency claim survives; the exact count does not.
  \item \textbf{Prokka's 1{,}818 CDS vs the paper's 1{,}556 CDS is a $\sim$17\% overcall.} The
  explanation offered (1{,}556 curated + 224 pseudo + $\sim$38 small ORFs = 1{,}818) is arithmetically
  plausible but is a post-hoc reconciliation, not a demonstration --- we did not actually map
  Prokka CDS calls one-to-one against the paper's CDS + pseudogenes to prove the accounting.
  A rigorous version of that check would require locus-level intersection.
  \item \textbf{Secondary qualitative claims were not tested at all}: RM systems, stress-response
  gene inventory, bacteriocin repertoire (BAGEL3), and whole-genome phylogeny. These are important
  parts of the paper's biological story and are simply out of scope here. Do not read this
  replication as endorsing those claims.
\end{itemize}

\subsection{Methodological weaknesses in the replication itself}
\begin{itemize}[leftmargin=*, itemsep=2pt]
  \item \textbf{The RASTtk-analog is an analog, not RASTtk.} Prokka bundles Prodigal / Aragorn /
  barrnap, which is close to the RAST tool family, but the BV-BRC CGA RASTtk service has
  additional curation logic. Not running actual BV-BRC CGA is a real gap for a paper this workflow
  was designed to reproduce.
  \item \textbf{Only one CRISPR tool was tried.} CRISPRFinder (paper) and \texttt{minced} (ours)
  can disagree; \texttt{CRT}, \texttt{PILER-CR}, and \texttt{CRISPRCasFinder} would triangulate
  better. A single-tool disagreement is not a paper-vs-truth disagreement.
  \item \textbf{The LLM-judge (argo:gpt-5.2) was fed our own numbers.} It concurred with our
  coverage 10/10 and agreement 7/10, but it is not an independent oracle --- it saw the same
  evidence we assembled. Its concurrence is a consistency check, not an independent adjudication.
  \item \textbf{Pipeline versions can drift.} Prokka 1.12 (used here) is not current; PGAP output
  will change with future NCBI reruns; \texttt{minced} thresholds are tunable. None of the
  numerical partial-agreements are guaranteed stable across future reruns.
\end{itemize}

\subsection{Why the verdict is PARTIAL and not REPLICATED}

A REPLICATED verdict would require reproducing the workflow-dependent claims (function \%, exact
CRISPR count) with the paper's actual toolchain (or a credible equivalent like BV-BRC CGA), and
independently deriving --- not just record-checking --- the Table 3 statistics via a de-novo
assembly from raw reads. Neither was done. What was done is strong record-fidelity + convergent
structural-annotation confirmation across three pipelines + a genuine (if partial) CRISPR
corroboration. That earns PARTIAL (strong), not REPLICATED.

\section{Limitations}
