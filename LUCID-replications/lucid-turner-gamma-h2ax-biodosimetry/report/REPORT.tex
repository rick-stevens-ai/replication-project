\href{https://doi.org/10.1186/s12860-019-0195-2}{DOI: 10.1186/s12860-019-0195-2}.

\textbf{Verdict:} \textbf{REPLICATED} (coverage 9/10, agreement 9/10).

\section{Paper summary}
This is an \emph{internal-emitter} biodosimetry study (not the classic
external-photon calibration curve). Mice received a single IV injection of
$^{137}$CsCl (4 activities: 5.74, 6.66, 7.65, 9.28 MBq). Blood and spleen
mononuclear cells were assayed for $\gamma$-H2AX total-fluorescence at
$t \in \{2, 3, 5, 7, 14\}$ days post-injection, and the resulting
$(F, t, A)$ surface was fit with a new mechanistic form (Eq.~1) that
couples ongoing exposure ($k A t$) to cell-death depletion of the assayed
lymphocyte pool ($\exp Q_1$) and to a stretched-exponential
DSB-repair/decay factor ($\exp Q_2$). The paper then Monte-Carlo-inverts
the fit to \emph{estimate} injected activity from $(F, t)$ and validates
it via Pearson/Spearman correlation across four time windows and an ROC
AUC for a low-vs-high activity binary classifier. The scientific claim
is that a single blood-based $\gamma$-H2AX draw between day 2 and day 3
post-intake can retrospectively estimate the internal $^{137}$Cs activity.

\section{Method}
\begin{itemize}
\item \textbf{Data source:} 100\% public (open-access article + Additional
files 1--5). No author contact. Group-mean $\pm$ SEM only (individual
mouse fluorescence values are not published).
\item Digitized to CSV: \texttt{data/blood\_h2ax.csv} (25 rows),
\texttt{data/spleen\_h2ax.csv} (25 rows), \texttt{data/dose\_table.csv}
(20 rows = Table 1). Weights $=$ paper's reported SEMs.
\item Forward evaluation with paper's verbatim (k,$\alpha$,r,p) via
\texttt{code/use\_paper\_params.py}.
\item Refit via weighted Nelder-Mead in \texttt{code/replicate\_turner.py}.
\item Monte Carlo inversion: 30{,}000 parameter draws, joint-95\%-CI
filter (16/30000 accepted), $F\to A$ inversion by numeric root-find.
\item ROC: binary label (low $\in$\{5.74, 6.66\}, high $\in$\{7.65, 9.28\}
MBq); score $= A_{\mathrm{est}}/\max A_{\mathrm{est}}$.
\end{itemize}

\section{Results vs paper}
Blood correlations across all four time windows reproduce the paper's
Pearson values to within $\lesssim 0.03$ and Spearman values to within
$\lesssim 0.13$, always in the same significance regime. The spleen
day-14 correlation is essentially identical (0.870 vs 0.866). ROC AUC
lands at 0.840--0.850 depending on whether we use paper params vs our
refit+MC — 0.09 below the paper's point estimate of 0.930 but comfortably
inside the paper's own 95\% CI of $[0.806, 1.0]$. See figures
\texttt{fig4\_paper\_params\_blood.png}, \texttt{fig5\_replication\_blood.png},
\texttt{figS2\_replication\_roc.png}.

\section{Critique (honest)}
\label{sec:critique}
This replication reproduces the paper's \textbf{training-set behavior}
faithfully, but several important scientific loose ends remain:

\begin{enumerate}
\item \textbf{Coverage is narrow.} We reproduced the calibration fit and
its in-sample Monte-Carlo inversion. We did \emph{not} reproduce:
(a) a genuine blind-dose challenge (all inversion tests use the same
data used for fitting; there is no held-out mouse or held-out activity);
(b) an independent \textbf{limit-of-detection (LoD)} analysis at
$<0.1$~Gy or against sham controls;
(c) any \textbf{time-window sensitivity} outside the 5 sampled days
(2, 3, 5, 7, 14);
(d) any \textbf{inter-individual CV} floor — per-mouse fluorescence is
not published, so we cannot bound biological noise below the reported SEMs.
\item \textbf{Model degeneracy.} The stretched-exponential $(1+rt)^p$
term is degenerate: in the regime $rt\!\gg\!1$ the factor collapses to
$(rt)^p$ and only the product $p\log r$ is identified. Our fit slides
$r$ and $p$ off the paper's individual values while keeping $Q_2$
unchanged. This is a real model-identifiability issue that the paper
does not flag; a re-parameterization (e.g.\ report $\log(r^p)$) would
be honest.
\item \textbf{ROC 0.09 gap.} We suspect the paper's 0.93 AUC treats each
of the 8 mice per point as an independent sample (giving $n\!\approx\!160$);
we can only reach $n=20$ (4 activities $\times$ 5 days) using group means.
The paper does not spell this out and the supplements do not include
per-mouse scores. Without individual-mouse data the gap cannot be closed.
\item \textbf{Biokinetics not re-derived.} We used Table 1's committed
doses verbatim rather than re-solving Eq.~3 with raw retention data,
which is not published. This is a spot-check, not an end-to-end
reproduction of the physics pipeline.
\item \textbf{Species / scenario relevance.} Turner et al.\ use adult
mice with acute IV injection of $^{137}$CsCl. Human relevance for
external-photon whole-body scenarios (the standard biodosimetry use
case) is not established by this replication and remains an open
translational question.
\end{enumerate}

Despite these caveats, the calibration + in-sample inversion pipeline
reproduces cleanly, so the paper's core statistical claim — that a
$(F,t)$ measurement between days 2 and 3 recovers activity with
Pearson $\approx 0.86$ — is credible.
