## 3. Computational artefacts

### 3.1 `report/evidence/resource_formulas.py`
Reproduces the two qubit-counting formulas of Section 6.2:
- `f(n)  = 7n + 4·log2(n) + 10`  (basic)
- `f'(n) = 5n + 8·sqrt(n) + 4·log2(n) + 10`  (with register sharing)

Regenerates all five rows of the paper's Table 4 and predicts qubit counts for the standard NIST/SECG ECC security levels {160, 192, 224, 256, 384, 521}. Every Table 4 row matches within the paper's own 100-qubit rounding.

### 3.2 `report/evidence/shor_dlp_ec.py`
- Elliptic-curve class `EC` over `F_p` (points, add, scalar-multiply, order-of).
- Enumerates candidate curves, picks `E: y^2 = x^3 + 3x + 3 (mod 23)` (group order 16) and locates the order-8 cyclic subgroup generated by `P = (18, 22)`.
- Builds the joint statevector `(1/q) Σ_{x,y} |x>|y>|xP + yQ>` on 9 qubits (3+3+3).
- Applies real Qiskit `QFT` gates on the x- and y-registers using `Statevector.evolve`.
- Reduces out the group register, verifies the exact `y' - s·x' ≡ 0 (mod q)` support, then samples measurements and recovers `s = y'·x'⁻¹ mod q`.
- Repeats for every hidden `s ∈ {1..7}`.

**Result:** 100% mass on the correct line (off-line mass = 5·10⁻³³, i.e. double-precision zero); s recovered for every hidden value.

### 3.3 `report/evidence/point_addition_demo.py`
- Constructs the group-shift unitary `U_{iP}: |k> → |(k+i) mod q>` as a `UnitaryGate` on 3 qubits.
- Verifies `U_{iP}` on all 8 basis states for each `i ∈ {1..7}`.
- Builds a controlled version (add P iff control = 1), verifies on all 16 (control, k) inputs.
- Also emits an ASCII circuit diagram (`point_addition_shift_by_3.txt`).
