\begin{abstract}
We replicate the core operational claims of \emph{Real Randomized Benchmarking}
(real RB) on a single qubit. Using Qiskit + Qiskit-Aer we (i) enumerate the real
Clifford group $\mathcal{C}(1)_{\mathrm{real}} = \langle Z, H\rangle$ and
confirm $|\mathcal{C}(1)_{\mathrm{real}}| = 8$, versus the full 24-element
$\mathcal{C}(1)$; (ii) inject a real-diagonal Pauli channel
$\mathcal{E}_p$ with $p_X = p_Z = p/2$, $p_Y = 0$; (iii) fit both the standard
Clifford RB decay $F(m) = A + B f^m$ and the real Clifford RB decay
$F(m) = A + B b^m$; and (iv) verify against the analytic predictions
$f_{\text{pred}} = 1 - 4p/3$ and $b_{\text{pred}} = 1 - p$. All fits match
within $\leq 1.5\sigma$, and the reduced-sequence real-RB experiment recovers
the same precision with $M=10$ sequences per length as standard RB does with
$M=30$, demonstrating the paper's efficiency claim. Verdict: \textbf{REPLICATED}
for the tractable $n=1$ portion of the claim graph; multi-qubit real-Clifford
RB and the $[[4,2,2]]$ code-space application remain out of scope for this
single-qubit wave.
\end{abstract}

\section{Paper Summary}
Real RB draws sequences from the real Clifford group
$\mathcal{C}(n) = \langle Z_i, H_i, CZ_{ij}\rangle$, a strict subgroup of the
full complex Clifford group. Key theoretical results tested here:
\begin{enumerate}
    \item $\mathcal{C}(n)$ is an \emph{orthogonal 2-design} (Theorem~4).
    \item The expected sequence fidelity is
    $\bar F(m) = A + b^m B + c^m C$ (eqs.~41/43); for real initial states only
    the $b$-branch survives, collapsing to a single exponential.
    \item Fitted $b$ and $c$ yield the average gate fidelity
    (eq.~34) and average rebit fidelity (eq.~35).
    \item \textbf{Efficiency claim}: real RB extracts the real-error component
    $b$ with approximately the same experimental cost as standard RB while the
    real Clifford group is a strict subgroup (8 vs 24 for $n=1$).
    \item Motivation: fault-tolerant gates in codes lacking a transversal full
    Clifford (e.g., $[[4,2,2]]$) and benchmarking rebit computations.
\end{enumerate}

\section{Method}
\subsection{Versions}
Qiskit 2.5.0, Qiskit-Aer 0.17.2, NumPy, SciPy in a local \texttt{.venv/}.
CPU only, single-qubit noisy simulation.

\subsection{Executed Steps}
\begin{enumerate}
    \item Fetch paper via \texttt{curl}, extract equations 17, 34, 35, 41, 43, and Protocol~2.
    \item Enumerate $\mathcal{C}(1)_{\mathrm{real}} = \langle Z, H\rangle$ by
    iterated matrix products; canonicalize global phase; count distinct
    orthogonal matrices $\rightarrow 8$.
    \item Enumerate full $\mathcal{C}(1) = \langle S, H\rangle \rightarrow 24$.
    \item Build noise model \texttt{NoiseModel.add\_all\_qubit\_quantum\_error}
    applying \texttt{pauli\_error([('X', p/2), ('Z', p/2), ('I', 1-p)])} after
    every \texttt{unitary} gate; $p = 0.02$.
    \item For $m \in \{1,5,10,20,40,80,150\}$ and each group: draw $m$ random
    elements, compute inverting element analytically, build circuit as
    \texttt{qc.unitary(...)} + inverse + \texttt{measure}, run on
    \texttt{AerSimulator}, 1024 shots, $M = 30$ sequences per $m$.
    \item Fit $F(m) = A + B f^m$ (or $b^m$) via \texttt{scipy.optimize.curve\_fit}
    with SEM weights.
    \item Reduced-sequence real RB with $M = 10$ (matches group-size ratio
    $8/24$) to test C5.
    \item Analytical cross-check via \texttt{src/theory\_check.py}:
    for $p_X = p_Z = p/2$, $p = 0.02$: $f_{\text{pred}} = 1 - 4p/3 = 0.9733$,
    $r_{\text{pred}} = 0.01333$; $\bar F_R = 1 - p/2 = 0.99 \Rightarrow
    b_{\text{pred}} = 0.98$, $r_R = 0.01$.
\end{enumerate}

\subsection{Group-Structure Spot Checks}
\begin{itemize}
    \item $|\mathcal{C}(1)_{\mathrm{real}}| = 8$ (paper eq.\ 17). \checkmark
    \item $|\mathcal{C}(1)_{\mathrm{complex}}| = 24$. \checkmark
    \item Every element of the enumerated real Clifford group has real matrix
    entries up to a global phase in $\{\pm 1, \pm i\}$. \checkmark

\section{Verdict: REPLICATED}
Structural claims C1--C2 reproduce exactly. Functional-form claim C3 is
confirmed by a clean two-parameter exponential fit. Quantitative decay
parameters for both protocols (C3--C4) match analytical predictions to
$\leq 1.5\sigma$. Efficiency claim C5 is demonstrated by matching precision
at the reduced sequence budget. Multi-qubit and $[[4,2,2]]$ claims (C6--C7)
are deferred.

\section{Critique --- Honest Limitations}
\label{sec:critique}

This replication is genuine at the $n=1$ operational level, but several
non-trivial gaps between what we tested and what the paper claims must be
disclosed:

\begin{itemize}
    \item \textbf{Fitting formula not independently rederived.} We used the
    same functional forms the paper writes down
    ($F(m) = A + B b^m$ for real initial states,
    $F(m) = A + b^m B + c^m C$ in general). We did \emph{not} independently
    derive these from the orthogonal-2-design property; we adopted them and
    verified they fit the simulation output. A stronger replication would
    reimplement the derivation from twirl integrals and confirm the closed
    form from first principles.
    \item \textbf{Only real-diagonal noise tested.} Our injected channel
    ($p_X = p_Z = p/2$, $p_Y = 0$) is precisely the type of noise the theory
    was designed to isolate cleanly. We did \emph{not} inject $Y$-component or
    coherent chiral noise, so the paper's most interesting sensitivity claim
    (that real RB is sensitive to $T$-type / chiral errors that standard RB
    averages away) was \emph{not} exercised. This is the single largest gap.
    \item \textbf{Chirality/$T$-error sensitivity not demonstrated.} A proper
    stress test would compare a chiral channel (e.g., a small coherent
    $\exp(-i\theta Y)$ rotation) against its achiral counterpart and show
    that real RB distinguishes them while standard Clifford RB does not.
    We did not run this contrast.
    \item \textbf{Single noise strength.} Only $p = 0.02$. We did not sweep
    $p$ to verify the linear scaling $r \propto p$ nor probe small-$p$ or
    large-$p$ regimes.
    \item \textbf{Sequence-length range not stress-tested.} $m$ went to 150.
    We did not test very long sequences where finite-sampling bias in the
    fitter becomes noticeable, nor did we bootstrap confidence intervals.
    \item \textbf{Sequence count is low.} $M = 30$ (respectively $M = 10$)
    is enough to see the trend but is well below what would be needed to
    tightly bound the $c$-branch amplitude were it non-zero.
    \item \textbf{2-design property tested only indirectly.} We infer the
    2-design property held on our channel/state because the predicted decay
    law fit. We did not directly compute the twirl-average
    $\int_{\mathcal{C}} U^{\otimes 2} \rho (U^\dagger)^{\otimes 2}\,dU$ and
    compare to the Haar orthogonal-group twirl.
    \item \textbf{Small-$n$ bias untested.} With only $M = 30$ sequences
    per length and 7 length points, the fit uncertainty is small but bias
    in $\hat b$ from finite-sequence non-Gaussianity was not characterized
    (would need a bootstrap or a simulation study across many repeated
    experiments).
    \item \textbf{Multi-qubit and code-space extensions deferred.} The
    paper's primary motivation is fault-tolerant benchmarking of the
    $[[4,2,2]]$ code, which our single-qubit scope does not touch. C6 and
    C7 remain untested by us.
\end{itemize}

In summary: the $n=1$ operational core is genuinely replicated, but the more
theoretically interesting sensitivity and 2-design claims are corroborated
only indirectly.
