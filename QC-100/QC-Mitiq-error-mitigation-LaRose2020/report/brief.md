# Brief

Independent replication of **LaRose et al. 2020, "Mitiq: A software package for error mitigation on noisy quantum computers"** (Quantum; arXiv:2009.04417). The paper introduces the open-source Mitiq Python package implementing quantum error-mitigation techniques (zero-noise extrapolation / ZNE, probabilistic error cancellation / PEC, Clifford data regression). We reproduced the two central reproducible claims on a noisy Cirq density-matrix simulator using a fresh `mitiq 1.0.0` + `cirq 1.6.1` venv: (1) the Fig. 5 PEC toy example — circuit `CNOT∘X∘H` measuring `|00⟩⟨00|` under single-qubit depolarizing noise p=0.1 — whose unmitigated expectation value we obtained as **0.062222**, matching the paper's **0.0622** to four significant figures, with PEC reducing the error by ~6.4× on average (paper: "almost an order of magnitude"); and (2) the ZNE claim that mitigated expectation values are closer to the noiseless truth than unmitigated ones across benchmark circuits (mean error 0.577→0.326, 1.77× reduction, 100% of circuits improved).
