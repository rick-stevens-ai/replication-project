\section{Paper}

Blackwell GA, Hunt M, Malone KM, Lima L, Horesh G, Alako BTF, Thomson NR, Iqbal Z.
\emph{PLoS Biology} 19(11): e3001421 (Nov 9, 2021).
DOI: \href{https://doi.org/10.1371/journal.pbio.3001421}{10.1371/journal.pbio.3001421};
PMID 34752446; PMC PMC8577725; CC-BY 4.0.

The paper is a \emph{Methods \& Resources} contribution: a uniformly re-processed snapshot
of every publicly available bacterial genome in the ENA as of November 2018 ---
\num{661405} samples assembled with a common pipeline (Unicycler primary, SPAdes fallback;
QC via QUAST + CheckM; typing via MLST + Clermont + SeqSero2; content annotation via
AMRFinder, plasmid replicons, Kraken2/Bracken). The paper publishes:
(i) the \num{661405} assemblies (\SI{750}{\giga\byte} tar),
(ii) a COBS index (\SI{872}{\giga\byte}) for $k$-mer search,
(iii) sourmash MinHash + pp-sketch indices (\SI{67}{\giga\byte}),
(iv) full per-genome QC + AMR + plasmid metadata on Figshare 16437939,
(v) Rnotebooks that reproduce every figure.

\section{Method}

Free-endpoint LLM policy: LLM judge run on the local Argo proxy
(\texttt{localhost:44497}, key \texttt{stevens}, model \texttt{argo:gpt-5.1}); no paid providers touched.

\subsection{Manifest verification}
Downloaded and line-counted \texttt{sampleid\_assembly\_paths.txt} (manifest) and
\texttt{checklist.chk} (MD5 index) from \texttt{ftp.ebi.ac.uk/pub/databases/ENA2018-bacteria-661k/}.

\subsection{Random-sample spot check}
Seeded \texttt{random.seed(661405)} and drew 25 sample IDs from the \num{661405}-row manifest.
Pulled all 25 corresponding \texttt{SAM*.contigs.fa.gz} via \texttt{curl}, computed MD5 with
Python \texttt{hashlib}, and cross-checked against \texttt{checklist.chk}. Uncompressed and
computed total bp, contig count, GC\%, N50. Queried ENA browser XML API for
\texttt{SCIENTIFIC\_NAME} and \texttt{TAXON\_ID}.

\subsection{Composition recount}
Fetched Figshare article metadata (16437939). Downloaded \texttt{File2\_taxid\_lineage\_661K.txt}
(\SI{95}{\mega\byte}) and \texttt{File4\_column\_descriptions.txt}. Counted rows in File2 and tallied
species. Streamed \texttt{File4\_QC\_characterisation\_661K.txt} (\SI{430}{\mega\byte}) through
\texttt{awk} to count column 39 (\texttt{high\_quality}) without materialising on disk.

\subsection{LLM-judge}
Assembled the evidence object and sent to the Argo proxy. First call to
\texttt{argo:claude-opus-4.7} returned HTTP 502; retry against \texttt{argo:gpt-5.1} returned a
valid JSON verdict.

\section{Genuine Critique}

This is the section a naive rubber-stamp report tends to omit. Every finding below is
compatible with the \textbf{REPLICATED} verdict for the \emph{paper's} claims but is a real
limitation of \emph{this replication}.

\begin{enumerate}
\item \textbf{Assembly pipeline was not re-run.} The paper's C7 claim --- that the archived
Unicycler/SPAdes wrapper, seeded with the ENA accession list, reproduces the assemblies
byte-for-byte or within-tolerance --- is entirely untested here. We verified that the
\emph{delivered} FASTA files match the paper's own MD5s, which is a strong integrity check but
does not audit the pipeline that produced them. A malicious or bugged assembler would still
pass this check as long as the MD5 file was regenerated from its own bad output.

\item \textbf{Species labels were not independently re-classified.} We accepted the
Kraken2/Bracken labels in \texttt{File2\_taxid\_lineage\_661K.txt} and cross-checked only
against ENA's own \texttt{SCIENTIFIC\_NAME}. Both sources ultimately trace back to the same
submitter-provided or Kraken-derived taxonomy. An independent classifier (e.g., GTDB-Tk on the
25-sample subset) would strengthen C3/C4 but was not run.

\item \textbf{Composition comparison is pre-QC vs post-QC.} The paper reports 2,336 species on
the HQ set; we counted 2,594 on the full 661k because File2 is not pre-filtered to
\texttt{high\_quality == TRUE}. The delta ($\Delta=258$) is quantitatively consistent with the
21,424 low-quality assemblies contributing spurious rare-species Kraken calls, but we did not
recount the HQ set to exactly 2,336. A cleaner comparison would join File2 to File4 on
\texttt{sample\_id} and recount species restricted to \texttt{high\_quality == TRUE}.

\item \textbf{Sample size for MD5/stats audit ($n=25$) is deliberately small.} At 25/25 the
posterior on a per-file corruption rate is tight for large defects but weak for rare ones.
For a paper this size ($6.6 \times 10^5$ files) a 25-sample audit gives a $95\%$ upper bound
on corruption rate of roughly $12\%$; the true rate is almost certainly $\ll 0.1\%$ (based on
storage system properties), but the audit alone does not prove that. Scaling to $n=1000$ would
tighten the bound to $<0.3\%$ at a modest bandwidth cost.

\item \textbf{Top-20 cumulative fraction was computed on the full 661k, not the HQ 639,981.}
The paper's $\sim 90\%$ statement is on the HQ set. Our $89.72\%$ is on the full set. These
agree to within $0.3$\,pp, which is comfortably inside ``$\sim 90\%$'', but they are not
literally the same quantity.

\item \textbf{One LLM-judge call, one retry, no ensembling.} The \texttt{argo:gpt-5.1}
verdict is a single sample. A stronger protocol would run three heterogeneous judges (e.g.
\texttt{gpt-5.1}, \texttt{claude-opus-4.8}, \texttt{gemini-2.5-pro}) and report majority vote
plus disagreement. The 502 on \texttt{argo:claude-opus-4.7} could have been retried more
persistently rather than swapping models.

\item \textbf{FTP endpoint availability is a point-in-time check.} All HEAD 200s were captured
on 2026-07-03. This says nothing about long-term durability of the EBI FTP path or Figshare
16437939. A future re-audit is trivial but not scheduled.

\item \textbf{No re-execution of the paper's Rnotebooks.} The paper publishes Rnotebooks that
reproduce every figure. We did not run them. Successful re-execution would independently
confirm C4 and the plasmid/AMR figures without going through raw metadata files.

\item \textbf{Excluded scope (C7) is a real gap, not just a scope cut.} The wave brief
explicitly excludes re-running the assembly wrapper on 30k CPU-months of compute, which is
defensible, but future users of this dataset should know that no one in the replication chain
has independently re-assembled even a single sample from raw reads. The 25-sample spot check
verifies delivery, not derivation.
\end{enumerate}

Bottom line: the paper's \emph{dataset-level} claims are cleanly reproduced. The paper's
\emph{pipeline-level} claim (C7) is neither confirmed nor refuted by this work.

\section{Verdict}

\textbf{REPLICATED.} Two headline cardinality numbers reproduce to the exact digit
(\num{661405} total; \num{639981} high-quality). The composition claim reproduces to within
$0.3$\,pp on the full 661k with a verbatim priority-pathogen top-20. Data availability is
confirmed end-to-end via 25/25 MD5 matches on random samples. The wave brief nominates
SPOT-CHECK as an acceptable landing; the evidence is strong enough for the stronger
\textbf{REPLICATED} verdict, with the caveats in Section \emph{Genuine Critique} explicitly on
the record.
