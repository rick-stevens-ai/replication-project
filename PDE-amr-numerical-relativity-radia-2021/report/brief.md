# PDE-amr-numerical-relativity-radia-2021 — Brief

**Paper:** Radia et al. 2022, *Lessons for adaptive mesh refinement in numerical relativity*, Class. Quantum Grav. **39** 135006 (arXiv:2112.10567). Preprint 2021, published 2022.

**What / why:** The paper documents the methodology and practical lessons of using block-structured Berger–Rigoutsos AMR (as implemented in the open-source NR code GRChombo) to evolve binary black-hole spacetimes and self-gravitating scalar (axion-star) fields. Its central contributions are METHODOLOGICAL: (i) a code comparison with the moving-boxes Lean code demonstrating that GRChombo's AMR can produce production-quality BBH waveforms (order-2nd amplitude / order-4th phase, mismatch 1−ρ ~ 10⁻³); (ii) a discussion of buffer regions and coarse-fine boundary artifacts (Sec. 3.1); (iii) two tagging criteria — gradient-of-conformal-factor χ (Eq. 51) and shadow-hierarchy truncation error (Eq. 47) — shown to give equivalent, accurate results on axion-star evolutions (Sec. 5.2). We independently re-implemented the underlying AMR mechanism (4th-order FD + RK4 + refinement-ratio-2 subcycling + Berger–Rigoutsos-analog box clustering + cubic-in-space + linear-in-time coarse-fine ghost interpolation + 2nd-order cell-averaged restriction + configurable nB buffer + both tagging criteria) in ~500 lines of Python on a 1D scalar wave equation with an analytic reference solution. We then ran four experiments to independently test the four core methodological claims. Full GRChombo BBH inspirals (Table 1 configs, weeks of HPC time on Chombo+MPI) are out of scope for a single wave-brief run; the METHOD is what we reproduce.

**Verdict:** PARTIAL. Base scheme's 4th-order convergence reproduced exactly (observed 3.95→3.99→4.00). AMR-induced degradation and irregular convergence reproduced. Buffer-region benefit reproduced (49× error reduction going nB=0→8). Tagging-criterion equivalence partially reproduced (both viable, similar coverage after tuning, similar-magnitude errors). BBH-specific quantitative numbers (waveform overlap, kick velocity) not attempted — that requires the full GRChombo/Chombo/MPI stack at HPC scale.
