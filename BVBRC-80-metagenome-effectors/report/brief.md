# BVBRC-80 — Brief

**Paper:** Verhoeve, Lehman, Driscoll, Beckmann, Gillespie (2024). "Metagenome diversity illuminates the origins of pathogen effectors." *mBio* (DOI:10.1128/mbio.00759-23, PMID:38564675). Preprint: *bioRxiv* 2023, PMID:36909625.

**What/why:** The paper is a comparative-genomics / phylogenomics study that mines 153 existing Rickettsiales genomes and metagenome-assembled genomes (MAGs) from NCBI to trace the evolutionary origin of *Rickettsia* T4SS "rvh" effectors. The core testable claim is a **rvhB4-based maximum-likelihood phylogeny** in which basal families Mitibacteraceae (MITI) and Athabascaceae (ATHA) branch deepest and Rickettsiaceae is derived. The paper is *not* a new WGS/assembly project — the BV-BRC "Genome Assembly / Metagenomic Read Mapping" workflow tag on this rank is a metadata mismatch. We replicated the phylogenetic core: parsed Table S1 (238 NCBI protein accessions), fetched a stratified 37-taxon subset + *Agrobacterium tumefaciens* VirB4 outgroup from NCBI E-utilities, aligned with MAFFT (proxy for MUSCLE), built an ML tree with FastTree LG+Γ (proxy for PhyML LG+G+I+F), and tested monophyly + basal-depth claims. **Verdict: PARTIAL** — MITI-basal + Anaplasmataceae-monophyly recovered; full 153-taxon concatenated tree not rebuilt.
