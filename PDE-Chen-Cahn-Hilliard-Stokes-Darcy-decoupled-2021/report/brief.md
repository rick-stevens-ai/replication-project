# Brief

Independent-replication attempt of Chen, Han, Wang, Wang, Wang, Zhang (2021), "Error estimate of a decoupled numerical scheme for the Cahn–Hilliard–Stokes–Darcy system" (IMA J. Numer. Anal. 42(3), 2621–2655; DOI 10.1093/imanum/drab046; arXiv 2106.03260). The paper is **purely theoretical**: it proves an optimal-rate O(τ² + h^{2q}) energy-norm error bound (Corollary 1) for a decoupled convex-splitting FEM scheme on the coupled CHSD system on karstic geometry with Beavers–Joseph–Saffman interface, but presents no numerical experiments and provides no code (it defers numerics to Chen et al. 2017, [ref 5]). We downloaded the arXiv PDF, extracted the model + scheme + main theorem, and implemented the Cahn–Hilliard sub-block of the decoupled scheme (equations 2.31a-b) as an isolated benchmark on a periodic square with a manufactured solution. Observed temporal and spatial rates (1.00 and ~2.00) match the τ + h^q rate implied by Corollary 1 for the CH piece. Verdict: **SPOT-CHECK** — CH component rate consistent with theory; full 6-field FEM/BJS system not implemented (out of scope for a one-shot run, no reference code).
