\section{Open questions}

\begin{enumerate}
  \item \textbf{Robustness of the cost advantage under relaxed
        structure.} Does the base-scheme cost advantage survive when
        the matrix is only \emph{nearly} tridiagonal (banded with a
        few off-band entries per row)?
        \emph{Basis:} the replication only tested strictly tridiagonal
        matrices with padded $S=4$; the paper does not smoothly
        parameterise a structure-perturbation axis.
        \emph{Next steps:} sweep a parametric perturbed-band family
        $A(\rho)$, record $(\text{effective } S, \alpha, \text{flag
        qubits}, \text{error})$ vs $\rho \in [0, 0.5]$, and compare
        against a generic LCU baseline on the same instance.

  \item \textbf{Downstream QSVT / HHL query cost.} Does the small
        $\alpha$ translate into a proportionally smaller QSVT query
        count end-to-end?
        \emph{Basis:} this replication stops at the block-encoding
        unitary; no QSVT pipeline was exercised, so downstream
        propagation of the $\alpha$ saving is an inherited assumption.
        \emph{Next steps:} build a QSVT pipeline (e.g.\ \texttt{pyqsp})
        for a matrix-inversion polynomial, plug in the constructed
        $U$ for $N \in \{4,8,16\}$, and compare QSVT query count to a
        generic LCU-encoded baseline.

  \item \textbf{Realistic-architecture cost.} How does the circuit
        map to a superconducting nearest-neighbour or trapped-ion
        all-to-all topology after routing?
        \emph{Basis:} the flag-qubit count is a pre-transpile count;
        the paper does not report SWAP overhead or depth on any
        particular device.
        \emph{Next steps:} transpile $U$ for $N \in \{4,8,16,32\}$
        with a heavy-hex \texttt{coupling\_map} and record
        (2-qubit gate count, depth, SWAP count) vs $N$; check whether
        the constant flag-qubit count survives routing.

  \item \textbf{Coverage of the other three families in Sec.~3.}
        Do 2D Laplacian, Toeplitz, and extended-binary-tree instances
        reproduce their quoted $\alpha$ and flag-qubit counts \emph{and}
        beat a real (compiled) generic baseline?
        \emph{Basis:} only the tridiagonal family was replicated; the
        genericity of the base scheme across all four families is not
        independently verified here.
        \emph{Next steps:} add per-family modules to
        \texttt{src/}, transpile both the paper's scheme and a
        generic LCU baseline for each family to a common gate set,
        and report real gate-count comparisons rather than closed-form
        scaling comparisons.

  \item \textbf{ML-driven scheme selection.} Could an automated
        selector over base / preamplified / PREP--UNPREP variants
        beat human hand-crafting on a mixed distribution of
        structured inputs?
        \emph{Basis:} the paper enumerates three schemes chosen by
        insight; scheme choice is not automated, and this replication
        only exercised the base scheme.
        \emph{Next steps:} sample a mixed batch of structured
        matrices, compute $(\alpha,\text{Toffoli-proxy})$ for each
        scheme, train a small classifier
        (features = structural summary $\rightarrow$ scheme), and
        evaluate expected cost against always-base-scheme.
\end{enumerate}
