# brief

Independent computational replication of Chen, Holst, Xu (SIAM J. Numer. Anal. 45(6):2298–2320, 2007), *The Finite Element Approximation of the Nonlinear Poisson–Boltzmann Equation*. We re-implemented the paper's regularized nonlinear Poisson–Boltzmann equation (RPBE, eq. 3.5) and its linear/nonlinear split u = uˡ + uⁿ from scratch in Python + scikit-fem 12, and tested the paper's core numerical-analysis claim — Theorem 6.2's quasi-optimal a priori H¹ error estimate — on (A) a manufactured-solution test with a smooth exact regularized potential, and (B) a two-atom "molecule" test using the full u = uˡ + uⁿ split. Empirical rates from the MMS run match theory exactly (||u − u_h||_L2 → 2.000, |u − u_h|_H1 → 1.000 across 7 uniform refinements), and the two-atom Newton iteration exhibits full quadratic convergence and strictly monotone energy decrease at every level, with an H¹-Cauchy-in-h proxy that drops as the mesh resolves the near-atom region.
