# Brief — OSTI-2396626

Bennett et al. (2024, *JAMES* 16, e2023MS004095) build deep-learning emulators of the ParFlow-CLM integrated hydrology model at 1 km × daily resolution over CONUS. Their novel **Forced SpatioTemporal RNN (FSTR)** — a PredRNN + action-conditioning adaptation with separate encoders for initial conditions, static parameters and meteorological forcings — outperforms baseline UNet and ResNet emulators and, they claim, delivers a **>1,000× speedup** over the original ParFlow-CLM simulation while remaining accurate on pressure heads, water-table depth and surface soil moisture. We independently retrieved the code (Zenodo 10.5281/zenodo.10730252 + GitHub `HydroFrame-ML/hydrogen-emulator-configurable`), instantiated the exact `ForcedSTRNN` module with the paper's `fstr_train.sh` hyperparameters on a real NVIDIA A100 80 GB, and measured end-to-end forward-pass wallclock across four patch/time configurations to independently check the compute claim. Training the emulator itself requires ParFlow-CLM CONUS1 zarr datasets from HydroFrame (a per-user API pin is required, which is beyond a batch-replication subagent's scope), so the accuracy claims (RMSE / correlation maps in the paper's Figures 4-6) are verified for method plausibility only, not by full retraining.
