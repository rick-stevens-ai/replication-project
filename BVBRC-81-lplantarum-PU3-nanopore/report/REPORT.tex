\section{Method (numbered, actually executed)}

All commands executed 2026-07-03. Light work on CherryRd; heavy compute on
\texttt{uicgpu} (8$\times$A100, environment \verb|/data/stevens/envs/bvbrc28|).

\begin{enumerate}[leftmargin=*]
\item Fetched paper full-text XML from Europe PMC (MDPI PDF was
      Akamai-blocked from both hosts): 200{,}906 B.
\item Verified all ten NCBI Nucleotide accessions (CP120642--CP120651) via
      EUtils \texttt{esummary}. All exist, all annotated to strain PU3, all
      sizes match paper Table 1.
\item Fetched all ten sequences (FASTA 3{,}423{,}478 B; GenBank 7{,}876{,}807 B).
\item Independent length + GC computation in Python (see
      \texttt{report/evidence/genome\_metrics.tsv}).
\item Parsed GenBank \texttt{FEATURES} tables per locus for
      \texttt{gene}/\texttt{CDS}/\texttt{tRNA}/\texttt{rRNA}/\texttt{ncRNA}/\texttt{tmRNA} counts
      (\texttt{report/evidence/genbank\_feature\_counts.txt}).
\item BV-BRC cross-check via
      \verb|/api/genome/1590.5192| and \verb|/api/sp_gene/?eq(genome_id,1590.5192)|.
\item Independent \textbf{Prokka 1.14.6} annotation on uicgpu (32 CPU,
      \texttt{--kingdom Bacteria --gcode 11 --genus Lactiplantibacillus
      --species plantarum --strain PU3}).
\item Downloaded reference genomes: M19 (GCA\_018588605.2) and WCFS1
      (GCF\_000203855.3).
\item \textbf{Mash} sketch + pairwise distances vs M19 and WCFS1.
\item \textbf{FastANI} (identical tool to the paper) against reference list.
\item \textbf{Abricate 0.5} vs CARD, VFDB, ResFinder, ARG-ANNOT at defaults
      (\texttt{--mincov 80 --minid 80}).
\item awk-filtered Prokka GFF over the bacteriocin window
      1{,}561{,}101--1{,}586{,}810 on CP120642.1.
\item LLM-judge cross-verification through Argo proxy \verb|:44497|:
      \texttt{argo:gpt-4o}, \texttt{argo:gpt-5}, \texttt{argo:gemini-2.5-pro}
      (Claude 4.7/4.8 both returned HTTP 502 that day and were not used).
\end{enumerate}

\section{Results vs paper (headline numbers)}

\begin{itemize}[leftmargin=*]
\item \textbf{Assembly:} exact match on chromosome length (3{,}180{,}940 bp),
      plasmid count (9), each individual plasmid length, and coverage
      (162$\times$). GC values match within rounding on both chromosome and
      plasmids.
\item \textbf{Species / ANI:} FastANI vs the same reference (GCA\_018588605.2)
      returns 99.6132\% vs the paper's 99.60\% --- a
      0.01 percentage-point difference, inside FastANI's own reproducibility
      envelope. Mash confirms (0.0031 dist $\approx$ 99.7\%).
\item \textbf{Structural RNAs:} 16 rRNA (exact) and 71 tRNA (paper 72), which
      is the most annotation-pipeline-stable comparison.
\item \textbf{Virulence / AMR:} Abricate at defaults returns
      \textbf{zero passing hits} against VFDB and CARD, reproducing the paper's
      central safety claim. A single sub-threshold CARD raw hit (dfrE
      67.6\% cov, 75.5\% id) fails the 80\%/80\% filter, as it should.
\item \textbf{Bacteriocin cluster:} the correct genomic window contains AgrA
      (quorum-sensing regulator), LagD$\times$2 (ABC transporter), LcnD
      (secretion accessory) and small ORFs in the correct size class
      (30--50~aa) for plantaricin core peptides. Prokka's default DB does not
      name PlnE/F/K specifically --- that requires BAGEL4, which is a
      database-coverage issue, not a genome issue.
\end{itemize}

\section{Genuine critique}
\label{sec:critique}

This section is deliberately not glossed. It records the places where the
replication is less clean than the top-line ``REPLICATED'' verdict suggests,
and what an honest peer reviewer would push back on.

\subsection{Gene-count divergence is real, not just cosmetic}
Three independent 2026 annotation runs on the exact deposited sequence
returned \textbf{3{,}273 / 3{,}617 / 3{,}794 CDS} (PGAP re-annotation,
Prokka 1.14.6, and BV-BRC's RAST-family pipeline respectively). The paper
reports 2{,}874. That is a $\sim$25\% spread, and it means any downstream
claim that pivots on ``pan-genome content'', ``accessory gene count'', or
``proportion of hypothetical proteins'' will silently drift depending on
which pipeline snapshot the reader picks. Our replication does \emph{not}
resolve this --- it documents it. The paper's number is a legitimate
2023-era PGAP snapshot; ours are legitimate 2026 snapshots. Neither can be
made ``exactly right'' without re-running the identical PGAP binary + DB from
the submission date, which is not archived. \textbf{This is a systemic
weakness of bacterial genome annotation, not a defect of this paper.}

\subsection{tRNA off-by-one}
Prokka finds 71 tRNAs where the paper reports 72. This is a one-tRNA
discrepancy that could plausibly reflect either (a) a tRNAscan-SE version
delta, (b) a differently-scored duplicate on a plasmid, or (c) an actual
mis-call in one of the two pipelines. We did not chase this down; PGAP
re-annotation returns 72, matching the paper, so the difference is
plausibly attributable to Prokka's default tRNAscan-SE cutoffs.

\subsection{Bacteriocin core peptides not directly labelled}
The paper's PlnE/F/K identification comes from BAGEL4, a specialist
bacteriocin server. We did not run BAGEL4 locally. What we \emph{did}
demonstrate is that the machinery genes (AgrA, LagD, LcnD) are present at
the exact reported coordinates and that ORFs in the correct size class
(30--50~aa) exist inside the window. A skeptical reviewer could legitimately
demand we install BAGEL4 and read out the actual PlnE/F/K labels;
we accept that as a fair follow-up.

\subsection{Wet-lab claims untouched}
The paper's probiotic-relevant claims (acid tolerance, bile tolerance,
osmotic tolerance, BIOLOG PM sugar utilization, antibiotic disc diffusion)
were \emph{not} tested here and cannot be tested from sequence alone. Our
verdict of ``REPLICATED'' covers the \emph{genomic and comparative-genomics}
claims only. A stricter framing would separate the paper into ``genomics
replicated'' + ``phenotype claims: not evaluated''.

\subsection{Judge disagreement is honest signal}
Two of the three LLM judges (gpt-4o, gpt-5) returned REPLICATED;
gemini-2.5-pro returned PARTIAL, hinging on the C8 gene-count divergence
above. We report this rather than suppress it --- the dissent is
substantively correct about the annotation-pipeline drift; we simply
disagree that it rises to a scientific contradiction.

\subsection{PDF not visually inspected}
MDPI's Akamai layer blocked direct PDF fetch from both CherryRd and uicgpu.
We used the Europe PMC full-text XML mirror. All text and tables are
complete, but figures (e.g., circular genome maps, TYGS trees) were not
visually inspected. We do not believe this changed the substantive result,
but a full replication would re-render those figures.

\subsection{Single-strain, single-technology}
The paper's assembly is Nanopore-only (no Illumina polishing beyond Racon +
Medaka on Nanopore reads themselves). Insertion/deletion accuracy in
homopolymer runs is a known weak point of Nanopore R9.4.1 assemblies; we did
not audit indel-error rates against short-read data (none exists for this
strain). The deposited genome may carry a small residual indel error rate
that would only become visible with paired Illumina data.

\section{Honest limitations}

\begin{itemize}[leftmargin=*]
\item Wet-lab (phenotype) claims not attempted.
\item BAGEL4, CRISPRCasFinder, dbCAN3 not re-run locally (web-server-only).
\item PDF figures not visually inspected (Akamai block; used Europe PMC XML).
\item PGAP-snapshot dependence of the 2{,}874-CDS number cannot be recovered.
\end{itemize}

None of these limitations conflict with the paper's core scientific claims.
