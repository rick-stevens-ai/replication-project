# Brief

Hyun, Monk & Palsson (2022) built pangenomes for 12 microbial pathogens (12,676 genomes from PATRIC/BV-BRC) by CD-HIT ORF clustering, fit Heaps' law to quantify openness, and divided each pangenome into core/accessory/unique via a two-power-function cumulative fit. We independently replicated the central pipeline for the smallest species, *Enterobacter cloacae* (104 genomes in paper, 54 with public NCBI accessions today), using their released Dataset S1 genome IDs, downloading actual proteomes via NCBI Datasets, and running CD-HIT v4.5.4 at the paper's exact parameters (`-c 0.8 -aL 0.8 -n 5`). Core (3,046 vs 2,906), accessory (4,351 vs 4,533), unique (9,562 vs 18,239, expected halving), and Heaps' κ (4,445 ± 362 vs paper 4,330 ± 451) all match within noise; α (0.337 vs 0.384) is slightly compressed as expected under subsampling. Verdict: **PARTIAL**, coverage ~45% (E. cloacae core methodology replicates on real public data; full 12-species MLST-balanced and cross-species functional analyses were not re-run).
