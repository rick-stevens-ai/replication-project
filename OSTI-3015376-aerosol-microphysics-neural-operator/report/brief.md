# Brief — OSTI-3015376 / Bai & Rouson, *Sci. Reports* 16:3211 (2025)

Independent replication of *"Data-driven emulation of modal aerosol microphysics via neural operator-based modeling"* (LBNL / SciDAC). The paper introduces **ADON** and **ADON-PCA**, a DeepONet-style dual-net surrogate that emulates the E3SMv2 (MAM4) modal aerosol microphysics parameterization suite. It reports Overall R²=0.9926 and ≈14× GPU-over-CPU inference speedup on Perlmutter A100. Zenodo (10.5281/zenodo.18226529) publishes the trained ADON-PCA checkpoint + a 1.21 M-point cloud-free test slice + PCA basis; GitHub (`zhbai/AerosolML`) publishes the inference script. On uicgpu (A100), I re-cloned the code, downloaded the 400 MB Zenodo bundle, loaded the released weights with **zero missing/unexpected keys**, and ran end-to-end inference on the full 1.21 M-point test slice — reproducing (a) the model's architecture exactly (Table 2), (b) the per-output-variable magnitude ranges (10⁻²¹ … 10¹¹), and (c) the ≈0.07 s / time-slice single-A100 GPU inference cost (Table S.2). Ground-truth Δ-VMR values for R² are **not** included in the Zenodo bundle (only pre-microphysics X inputs, PCA basis, normalization stats, and the trained model), so the headline R²=0.9926 claim itself is spot-checked as architecturally reproducible but not numerically re-measured. **Verdict: PARTIAL** — code + weights + inference-cost claim reproduced independently; accuracy claim is architecturally supported but ground-truth Y arrays are not published, blocking a direct R² rerun.
