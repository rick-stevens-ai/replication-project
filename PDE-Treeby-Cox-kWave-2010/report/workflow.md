## Independence protocol

- Paper PDF read only for the governing equations (Sec. 3.1 in the paper: coupled first-order acoustic system) and for the definition of the k-space correction κ = sinc(c₀·Δt·|k|/2).
- No k-Wave MATLAB source, no k-Wave Python port, no k-Wave demo scripts consulted. Kernel written from scratch matching Tabei et al. 2002 / Cox et al. 2007 as cited by the paper (equations only, no code).
- All analytic references derived from first principles (d'Alembert, Hankel-transform Green's function for 2D Gaussian).

## Step-by-step

1. **Distill claims → C1..C5 table.**
   Extracted 5 claims from the paper (Section 2.2 and cited refs). Three are numerical and testable (C1 temporal-dispersion / stability, C2 analytic-solution comparison, C3 spectral accuracy at ~2 PPW); two are toolbox-level (C4 PAT reconstruction, C5 heterogeneous media / PML) and marked out-of-scope for a kernel replication.

2. **Implement k-space PSTD kernel from equations.**
   Staggered leapfrog in space (pressure at n, velocity at n+½) and time. Per step:
   - `grad(p) = IFFT[ i·k · κ(|k|) · exp(+i k dx/2) · FFT(p) ]`
   - `u_{n+½} = u_{n-½} − (Δt/ρ₀) · grad(p)`
   - `div(u) = Σⱼ IFFT[ i·kⱼ · κ(|k|) · exp(−i kⱼ dxⱼ/2) · FFT(uⱼ) ]`
   - `ρ_{n+1} = ρ_n − Δt · ρ₀ · div(u)`
   - `p_{n+1} = c₀² · ρ_{n+1}`
   Plain PSTD baseline recovered by setting κ ≡ 1.

3. **Fix first-timestep leapfrog centering bug.**
   Initial implementation used a full Δt for the first velocity update, which
   miscenters the staggered leapfrog when u(t=0)=0. Symptom: C1 error floor at
   O(Δt) instead of O(10⁻¹⁵). Fix: first velocity step uses Δt/2. (See
   attempt.log; discovered by 1D d'Alembert cross-check.)

4. **Analytic references.**
   - 1D: exact d'Alembert half-split.
   - 2D Gaussian: closed-form Hankel integral, evaluated by trapezoidal
     quadrature (Nk=6000, kmax·σ=15) — Gaussian's k-decay makes it essentially
     exact.
   - 2D disk PSA: no smooth analytic (logarithmic caustic); use
     self-convergence on N ∈ {128, 256, 512, 768}.

5. **Run experiments.**
   All under `work/`:
   ```
   python3 work/exp_C1_temporal_dispersion.py   # ~1 s   -> C1_cfl_sweep.{csv,txt}
   python3 work/exp_C3_ppw_convergence.py       # ~5 s   -> C3_ppw_convergence.{csv,txt}
   python3 work/exp_C2_2d_gaussian.py           # ~5 s   -> C2_gaussian_*.{csv,txt,png}
   python3 work/exp_C2b_disk_selfconv.py        # ~45 s  -> C2b_disk_selfconv.{csv,txt,png}
   ```
   Physical constants: c₀ = 1500 m/s (water), ρ₀ = 1000 kg/m³.

6. **Compare vs claims.**
   For each of C1/C2/C3, tabulate L2 relative error, wavefront positions,
   comparison against baselines (plain PSTD, FD2). Publish CSV + TXT under
   `report/evidence/`, PNG snapshots for C2.

7. **Judge cross-check.**
   Polled Argo-hosted GPT-4o via local proxy `127.0.0.1:44497`
   (`Bearer stevens`). Prompt + response in
   `evidence/judge_prompt.txt` / `evidence/judge_response.txt`. Judge
   cross-checks writeup coverage and honesty; does not overrule numerical
   evidence.

8. **Write REPORT.md and REPORT.tex.**
   Prose replication report with all tables + a dedicated GENUINE CRITIQUE
   section covering scope limits (homogeneous/lossless only), the caveat on
   "unconditional stability" language, the disk-PSA caustic artifact, and the
   staggered-leapfrog bug found during development.

9. **Enumerate open questions.**
   Five truly-open questions in `open_questions.json`: fractional power-law
   absorption stability, heterogeneous/interface handling, GPU/multi-node
   scaling, elastic-wave extension, comparison vs high-order FDTD / DG for PAT
   accuracy.
