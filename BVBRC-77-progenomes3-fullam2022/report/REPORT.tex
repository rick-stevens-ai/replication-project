\section{Paper summary}

proGenomes3 is a curated database of prokaryotic genomes designed to sit between
the raw completeness of NCBI RefSeq and the phylogenetic consistency of GTDB.
The paper announces v3 as containing \textbf{907{,}388 high-quality genomes} in
\textbf{41{,}171 specI (species-level) clusters}, all having passed a two-stage QC
gauntlet (\textbf{CheckM completeness $>$ 90\% AND contamination $<$ 5\%}, plus
\textbf{GUNC contamination $<$ 5\% and clade-separation score $<$ 0.45}), with consistent
functional annotation via eggNOG-mapper, mobile genetic element and biosynthetic
gene cluster annotation, and habitat classification.

\section{Method}

\begin{enumerate}[leftmargin=1.5em]
  \item Paper retrieved from EuropePMC (\texttt{PMC9825469}); 90~KB XML $\to$ 33~KB plain text; abstract, DOI, resource URL confirmed.
  \item Resource probed via \texttt{curl} against \url{https://progenomes.embl.de/} (200) and \texttt{/download.cgi} (200, 16~KB HTML).
  \item Discovered a silent v3$\to$v4 backend swap: the download page still lists \texttt{proGenomes3\_*} filenames but those URLs return \textbf{404}; only \texttt{pg4\_*} files are served. Verified: 6/6 pg3 URLs $\to$ 404; 3/3 pg4 URLs $\to$ 200 (re-verified 2026-07-04).
  \item Data pull (all live, free, HTTP): \texttt{pg4\_representatives\_for\_each\_ANI\_cluster.tsv.gz} (32{,}887 mappings), \texttt{pg4\_ANI\_clustering.tsv.gz} (32{,}887 cluster members), \texttt{pg4\_ncbi\_taxonomy.tsv.gz} (1{,}891{,}269 rows), \texttt{pg4\_consensus\_gtdb\_taxonomy\_per\_ani\_cluster.tsv.gz} (29{,}602 rows), \texttt{pg4\_excluded\_genomes.txt.gz} (1{,}243{,}181 rows), \texttt{pg4\_highly\_important\_strains.tsv.gz} (820 rows).
  \item Random slice: Python \texttt{random.sample(reps, 100)} with \texttt{seed=20260703}.
  \item Independent QC re-check: NCBI Datasets REST (\texttt{/genome/accession/\{acc\}/dataset\_report}) per accession, pulling \texttt{contig\_n50}, \texttt{total\_sequence\_length}, \texttt{assembly\_level}, and NCBI's CheckM completeness + contamination. 350~ms pause between calls.
  \item Full-scale structural verification: parse all five pg4 metadata files, compute cluster$\leftrightarrow$rep bijection, rep-in-own-cluster membership, rep-in-excluded consistency, cluster-size distribution, QC-pass count, GTDB consensus coverage, and highly-important-strain retention.
  \item Statistics: distribution stats + fraction passing paper's stated gates via Python \texttt{statistics} stdlib.
  \item Taxonomy consistency: slice genomes' pg4-GTDB label vs NCBI \texttt{organism\_name} at genus / species token level.
  \item LLM judges (v1 + v2): 4 candidates via free Argo proxy at \url{http://127.0.0.1:44497} (key=\texttt{stevens}) --- \texttt{argo:gpt-4.1}, \texttt{argo:claude-sonnet-4.5}, \texttt{argo:gpt-4o}, \texttt{argo:claude-opus-4.7} (opus 502 both runs). Majority verdict = final.
\end{enumerate}

\paragraph{Endpoints (all free):} EuropePMC REST, NCBI eUtils, NCBI Datasets v2alpha REST, \texttt{progenomes.embl.de} HTTP GET, Argo proxy for LLM judging. \textbf{Zero paid API calls.} \textbf{Compute:} local (CherryRd), Python 3.13 stdlib, no venv. Wall-clock $<$ 4~min end-to-end.

\section{GENUINE CRITIQUE}

This section is a candid self-assessment of what did and did not survive
independent scrutiny. It is intentionally harsher than the executive summary.

\paragraph{What actually replicated.}
The \emph{class} of quantitative claim from the paper (a big curated
prokaryotic genome collection with QC-based selection and species-level
clustering) is real: the URL is live, the files download, the numbers add up
internally, the QC-excluded list is disjoint from the QC-passed set, and every
one of 32{,}887 species representatives is a legitimate cluster member that
never appears in the excluded roster. The GTDB consensus coverage (90.01\%)
substantively supports the paper's ``consistent taxonomy'' claim at DB scale.

\paragraph{What did NOT replicate: the paper's exact numbers.}
The paper's headline numbers --- \textbf{907{,}388 HQ genomes} and
\textbf{41{,}171 specI clusters} --- \textbf{are not reproducible from the
resource in its current state}. All pg3-branded files return HTTP 404. What we
verified is the successor pg4 (1{,}891{,}267 / 32{,}887), which is a
\textbf{different pipeline} (pure ANI clustering, not specI). This is a
substantive limitation: strict, snapshot-faithful replication of the paper's
numeric claims is presently impossible from the paper's own URL. That the
successor exhibits the \emph{same class} of well-formed statistics is
supportive but is not the same as reproducing the paper.

\paragraph{The CheckM discrepancy is not a clean pass.}
79.3\% of a 100-genome slice pass the paper's stated CheckM gate under an
independent NCBI CheckM re-run --- not 100\%. Three concrete failures
(contamination 14.2\%, 18.6\%; completeness 74.9\%) are documented. The
tool-version caveat (NCBI CheckM1 vs pg4 likely CheckM2) is real and
defensible, but it is exactly the kind of caveat that lets any QC gate
``pass'' on a technicality. A stronger test --- rerunning CheckM2 and GUNC
with pg's exact marker set on the same slice --- was out of budget. Anyone
citing this replication should not read ``QC verified'' into the 0/32{,}887
structural check; that only proves the pipeline is internally consistent
(reps are not on their own excluded list), not that the biological gate is
correctly calibrated.

\paragraph{eggNOG functional annotation (C6) was not tested at all.}
This is one of the paper's four headline consistency claims (taxonomy +
functional annotation + MGE + BGC). Skipping eggNOG-mapper cross-checking on
representatives means we have no evidence for or against ``consistent
functional annotation''. Nor did we touch MGE or BGC annotation.

\paragraph{The v3$\to$v4 silent swap is a documentation defect.}
The download page HTML still advertises \texttt{proGenomes3\_*} files that no
longer exist. This is a real reproducibility hazard: a user following the
paper's cited URL and filenames will get 404s and, if they are not paying
attention, might assume the resource is offline rather than silently updated.
This finding is arguably the most important artifact of this replication for
the community.

\paragraph{Judge-based verdicts have known failure modes.}
The v2 unanimous PARTIAL is 3/4 judges (Opus-4.7 was 502 both runs); mean
agreement of 90\% is high but LLM judges tend to converge on ``PARTIAL'' when
fed evidence that is itself framed as partial. This is not independent of the
evidence pack the judges were given. Treat the LLM-judge signal as
corroborative summary, not as a ground truth.

\paragraph{Bottom line.}
The proGenomes resource is real, healthy, and internally well-structured on
its live successor. The specific paper being replicated is a v3 snapshot that
is no longer served, and one of its four headline consistency claims (eggNOG)
was untested. \textbf{PARTIAL} is the honest verdict --- not REPLICATED
(because v3 files are 404 and eggNOG is untested), not CONTRADICTED
(because all structural checks pass and the tool-mismatched CheckM
discrepancy is not diagnostic).
