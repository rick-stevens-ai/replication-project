\section*{One-line verdict}
\textbf{REPLICATED.} The paper's core qualitative claim --- that Richardson-extrapolation-based
Zero-Noise Extrapolation (ZNE) produces expectation-value estimates whose error is dominated by
the leading unmitigated order of the noise, and that increasing the order $n$ suppresses the
residual error super-linearly --- is reproduced exactly on Qiskit-Aer density-matrix simulations
with a depolarizing noise model. At $\epsilon = 10^{-3}$ our mean absolute error drops from
$2.5\!\times\!10^{-3}$ (raw noisy) to $3.5\!\times\!10^{-5}$ (ZNE $n{=}1$) to
$5.0\!\times\!10^{-7}$ (ZNE $n{=}2$) across 8 random 4-qubit depth-6 circuits, i.e.\ improvement
factors of $\sim\!70\times$ and $\sim\!5000\times$ respectively --- consistent with the
$O(\epsilon^{n+1})$ residual predicted by Eq.~(3)--(4) of the paper.

\section{Paper summary}
The paper introduces two techniques to mitigate noise-induced bias in expectation values
computed on short-depth NISQ quantum circuits:
\begin{enumerate}
  \item \textbf{Extrapolation to the zero-noise limit (Sec.~I of the paper).} Run the same
    circuit $n{+}1$ times at rescaled noise rates $c_j \lambda$ ($c_0{=}1$, $c_j>1$), then form
    the linear combination
    \[
      \hat{E}^n_K(\lambda) \;=\; \sum_{j=0}^{n} \gamma_j \, \hat{E}_K(c_j\lambda),
      \qquad
      \sum_j \gamma_j = 1,\ \sum_j \gamma_j c_j^k = 0\ \text{for } k = 1,\dots,n.
    \]
    This is Richardson's deferred approach to the limit; the leading $n$ orders of
    $\lambda$ cancel and the residual bias is $O(\lambda^{n+1})$.
  \item \textbf{Probabilistic error cancellation via quasi-probability sampling (Sec.~II).}
    Given a full characterization of the noise map, one expresses each ideal gate as a
    quasi-probability distribution over noisy operations and Monte-Carlo samples it, with a
    sampling-cost overhead $C^2 = \prod_\alpha \gamma_\alpha^2$.
\end{enumerate}
This replication targets \textbf{Scheme 1 (ZNE)}, which is the more universally reproducible of
the two (no detailed noise-model characterization required).

\section{Method}

  \item Host: CherryRd (macOS), CPU only, wall-clock $\approx 7\,\text{s}$ for the full sweep.
\end{itemize}

\subsection{Circuits}
Following the paper's Fig.~1 ``random control problem'' description we generate $N{=}4$-qubit,
depth-6 alternating layers of Haar-random single-qubit U3 rotations and brick-wall CX
entanglers. Eight independent random-seed circuits (\texttt{seed} $= 42, 43, \dots, 49$).

\subsection{Noise model and noise scaling}
We use a uniform depolarizing channel: rate $\epsilon$ per single-qubit gate and rate $\epsilon$
per CX. To scale the noise by $c \in \{1,2,3\}$ (paper Eq.~5's rescaling protocol) we simply
build a fresh noise model with rate $c\epsilon$. This is the digital equivalent of the paper's
time-rescaling trick: because the noise generator $L$ is time-scale-invariant and the ideal
circuit is fixed, running with rate $c\epsilon$ yields the same $\rho_{c\lambda}(T)$ as
rescaling the Hamiltonian and evolving for time $cT$.

\subsection{Observable}
$\langle Z_0 Z_1\rangle$ computed exactly from the density matrix
$\rho$ as $\text{Tr}\!\left[(Z\otimes Z\otimes I \otimes I)\,\rho\right]$.

\subsection{Richardson coefficients (sanity-checked in code)}
For $c = (1, 2)$: solve $\gamma_0 + \gamma_1 = 1,\ \gamma_0 + 2\gamma_1 = 0 \Rightarrow (2, -1)$.\\
For $c = (1, 2, 3)$: adds $\gamma_0 + 4\gamma_1 + 9\gamma_2 = 0 \Rightarrow (3, -3, 1)$.\\
Our code (\verb|report/evidence/zne_replication.py|) solves the Vandermonde system numerically
and asserts these values --- both assertions pass.

\subsection{Scaling with $\epsilon$}
Fitting the aggregate columns above on log-log axes for $\epsilon \in [10^{-4}, 10^{-3}]$:
\begin{itemize}
  \item raw noisy: slope $\approx 1.00$ ($O(\epsilon)$) --- as expected.
  \item ZNE1: slope $\approx 2.00$ ($O(\epsilon^2)$) --- matches the $O(\lambda^{n+1})$ bound with $n{=}1$.
  \item ZNE2: slope $\approx 3.00$ ($O(\epsilon^3)$) --- matches the $O(\lambda^{n+1})$ bound with $n{=}2$.
\end{itemize}
This is exactly the qualitative shape of Fig.~1(a) in the paper.
