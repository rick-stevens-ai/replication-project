# Brief — Cheong+2020 Gmunu (arXiv:2001.05723)

**What:** Independent PARTIAL replication of the multigrid-convergence claim of Gmunu, the GR hydrodynamics code that uses a Full Approximation Scheme (FAS) nonlinear cell-centred multigrid (CCMG) solver for the conformally-flat-condition (CFC) Einstein constraint equations.

**Why:** The paper's headline algorithmic claim (Fig. 11) is that FAS multigrid gives an ~O(10³–10⁴)× speedup over Gauss-Seidel relaxation for the nonlinear elliptic CFC Hamiltonian constraint Δψ = -2π ρ ψ⁵, and that V-cycle depth monotonically improves convergence. We built an independent ~250-line Python FAS solver on a 2D Cartesian analog of this nonlinear PDE, reproduced the V1→V6 depth-convergence pattern, verified 2nd-order spatial accuracy (observed order 1.93→1.99), and confirmed near-optimal multigrid iteration-count scaling with N (7→11→16→20 for N=16→128). Absolute iteration counts differ from the paper because our test problem differs (Cartesian MMS vs BU8 rotating-NS lapse on spherical grid), but the qualitative Fig-11 pattern reproduces cleanly. Full Gmunu code was not built — the paper claims open-source but no public repo URL was found on the author's page / GitHub; the code stack (CFC + finite-volume hydro + xCFC spherical solver + HLLE/MC Riemann pipeline) is also too heavy for a subagent SPOT-CHECK. Verdict: **PARTIAL**.
