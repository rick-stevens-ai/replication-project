\begin{abstract}
Rendon, Watkins, and Wiebe (Quantum, 22 Feb 2024) show that classical
Chebyshev polynomial interpolation of second-order Trotter data taken at
several dimensionless step sizes $s_k$ yields \emph{spectral} (Bernstein-
ellipse) convergence to the true eigenvalue, giving Heisenberg-limited
$\widetilde{O}(1/\varepsilon)$ query complexity in place of
$\widetilde{O}(1/\varepsilon^{1+1/p})$ for a single order-$p$ Trotter
estimate. We independently reimplement the two-spin transverse-Ising
testbed (paper Eq.\ 5.1) as a real Qiskit \texttt{QuantumCircuit} and
verify: (a) single $S_2$ / $S_4$ Trotter follow textbook $1/r^{2}$ /
$1/r^{4}$ slopes; (b) Chebyshev interpolation of $S_2$ data drives error
from $9\!\times\!10^{-6}$ (n=2) to $\sim\!4\!\times\!10^{-16}$ (n=6), a
per-node reduction of $\sim\!10^{3}$; (c) at cost $\le 100$ Trotter
exponentials, Chebyshev+$S_2$ (n=4) beats single $S_2$ by
$\sim\!2\!\times\!10^{6}$ and single $S_4$ by $\sim\!10^{4}$. The
Qiskit-compiled unitary agrees with the numpy Trotter step to
$1.55\!\times\!10^{-16}$ Frobenius norm. \textbf{Verdict: REPLICATED.}
\end{abstract}

\section{Paper summary}
The paper proposes using Chebyshev polynomial interpolation as classical
\emph{post-processing} on Trotterized simulation data collected at
several $s_k \in (0, s_{\max}]$. The effective Trotter Hamiltonian
$\tilde{H}_s := (i/t) \log(S_{2k}(st)^{1/s})$ is smooth in $s$ at $s=0$
(and \emph{even} in $s$ for symmetric Suzuki-Trotter formulas), so
polynomial extrapolation to $s=0$ recovers the true value with error
controlled by interpolation error rather than raw Trotter error.

Section 5 backs the theory (Theorems 15/17, Lemmas 12/14) with two-spin
TFIM numerics:
\begin{equation}
H \;=\; -J\left(Z\otimes Z \;+\; g\,(X\otimes I + I\otimes X)\right)\quad\text{(paper Eq.\ 5.1)}.
\label{eq:TFIM}
\end{equation}
We reproduce this Section-5 numerical demonstration end-to-end from a
Qiskit circuit backbone.

\section{Method}
\subsection{Environment}
Python 3.14.6, \textbf{Qiskit 2.5.0}, NumPy 2.5.0, SciPy 1.18.0, Matplotlib 3.11.0.
Repro one-shot: \texttt{python3 code/trotter\_chebyshev\_v2.py}.

\subsection{Model}
Eq.~\eqref{eq:TFIM} with $J=1$, $g=0.3$, $t=1$. Split
$H = H_1 + H_2$ with $H_1 = -J\,Z\otimes Z$ (diagonal) and
$H_2 = -Jg(X\otimes I + I\otimes X)$ (non-commuting). Exact ground energy
by direct diagonalisation: $E_0 = -1.16619037896906$.

\subsection{Real Qiskit statevector sanity check}
The $S_2$ step is built as a real \texttt{QuantumCircuit(2)} using
\texttt{UnitaryGate}(exp$(-iH_1 t/2)$), \texttt{UnitaryGate}(exp$(-iH_2
t)$), \texttt{UnitaryGate}(exp$(-iH_1 t/2)$). Compiled unitary via
\texttt{qiskit.quantum\_info.Operator} agrees with the numpy Trotter
step to:
\begin{equation}
\|U_{\text{qiskit}} - U_{\text{numpy}}\|_F = 1.55\times 10^{-16}.
\end{equation}
Bit-for-bit at double precision. This anchors the whole experiment to a
real quantum-circuit implementation.

\subsection{Trotter and interpolation}
Standard $S_1, S_2, S_{2k}$ constructions (paper Eqs.\ 2.2--2.4).
Fractional-queries $\tilde U_s(t) = S_p(st)^{1/s}$ implemented via
\texttt{scipy.linalg.expm((1/s)\,logm(S\_p(st)))}. Effective Hamiltonian
$\tilde H_s = (i/t)\,\mathrm{logm}(\tilde U_s(t))$ (Hermitised). Ground
eigenvalue via \texttt{numpy.linalg.eigh}.

Interpolation nodes: Chebyshev-1st-kind in $u = s^2 \in
(10^{-6}, (1/3)^2]$, using the paper's evenness-in-$s$ / reflection-
symmetry observation to halve the node count. Extrapolation to
$s=0 \leftrightarrow u=0$ via barycentric Lagrange with Salzer weights
$w_j = (-1)^j \sin((2j+1)\pi/(2n))$ (Trefethen SIAM Rev.\ 46:501, \S 5).

\section{Critique --- honest assessment}
The replication is genuinely strong on the headline (C4/C5) but leaves
real gaps that a full independent audit should flag:
\begin{enumerate}
  \item \textbf{Scope is deliberately narrow.} We only test the paper's
    own two-spin TFIM ($J=1, g=0.3, t=1$). The paper's own numerical
    section is also limited to this system, but the theorems claim
    generality (arbitrary local $H$, higher-order ST). Neither we nor
    the paper's Sec 5 exercise a physically meaningful benchmark
    (e.g.\ FeMo-co, Hubbard, or a 6+ qubit lattice), so the practical
    utility on \emph{application-relevant} Hamiltonians is unverified.
  \item \textbf{Interpolation core, not end-to-end QPE.} We reproduce
    the interpolation stage that dominates the error curve (Fig 3),
    but the full $\widetilde{O}(1/\varepsilon)$ query complexity of C6
    is only inherited by composition with a Gaussian phase-estimation
    subroutine that we did not implement, simulate, or noise-model.
    The paper is explicit that GPE is a black-box subroutine; we
    inherit that boundary.
  \item \textbf{No canonical Trotter-1 baseline.} We compare against
    $S_2$ and $S_4$ (paper's own point of comparison), but not
    against $S_1$ (Lie-Trotter). $S_1$ isn't the paper's target so
    this is a minor gap, but a fully symmetric benchmark suite would
    include it.
  \item \textbf{Polynomial-order vs.\ error trade-off is bounded by
    machine precision.} We saturate at $n=6$ at $\sim 4\times 10^{-16}$,
    so the true asymptotic rate constant of the Bernstein-ellipse
    decay cannot be tightly fitted from our data --- only the
    order-of-magnitude per-node ratio ($\sim\!500\text{--}1000\times$).
    Extended precision (mpmath) would be needed to fit the constant
    and cross-check against the paper's theoretical estimate.
  \item \textbf{No noise model.} All results are noiseless statevector
    simulation. Chebyshev interpolation of Trotter data at nodes with
    non-negligible sampling / hardware noise could see the
    exponential convergence swamped by the noise floor; the paper
    hedges on this in the discussion, and we do not probe it.
  \item \textbf{Reflection-symmetry trick is exploited but not
    isolated.} Our interpolation in $u = s^2$ uses the paper's
    evenness observation. We did NOT run a control that interpolates
    in $s$ without exploiting symmetry, so the incremental value of
    the reflection trick is not quantified here (v1 code did try it;
    v2 supersedes).
  \item \textbf{Single ground-state target.} We extrapolate the
    ground eigenvalue only. Extension to expectation values of
    non-commuting observables, or to excited states, is claimed
    (Sec 4) but not tested.
\end{enumerate}
Net: the headline claim is exercised on the paper's own Sec-5 testbed
with quantitatively strong agreement, using a real Qiskit backbone. The
gaps above are honest scope-of-work gaps, not falsifications.

\section{Verdict}
\textbf{REPLICATED.} The paper's central methodological contribution
(Chebyshev-interpolation post-processing $\Rightarrow$ Heisenberg-limit
scaling for eigenvalue estimation, beating single-shot Trotter at
matched cost) is reproduced on a real Qiskit + scipy classical
simulation of the paper's own two-spin TFIM testbed.
