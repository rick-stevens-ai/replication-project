### 3. Data extraction (`code/extract_si.py`)
- Opened `SI_MOESM2_ESM.xlsx` with `openpyxl` (via pandas).
- Split into three CSVs matching the paper's three data figures:
  - `data/foci.csv`  — Fig 1 (53BP1 foci vs time, both cell lines, both qualities).
  - `data/clonogenic.csv` — Fig 2 (SF vs dose, both cell lines, both qualities, mixed XA and AX orders).
  - `data/sld.csv` — Fig 3 (SF vs inter-fraction interval, four dose-pair conditions per cell line).

### 4. Analytical replication (`code/replicate.py`)
Executed in this order (each stage writes an evidence JSON before continuing):
1. **LQ fitting** — `scipy.optimize.curve_fit` on X-ray and alpha clonogenic data per cell line; alpha fits use `beta_alpha = 0` fixed per Table S1. Writes `evidence/lq_fits.json`.
2. **RBE_D10** — analytic from fitted LQ parameters (`D10 = (-alpha + sqrt(alpha^2 + 4*beta*ln(10))) / (2*beta)`).
3. **Mixed-field additive-model check (Eq 2)** — evaluate additive-model prediction at each mixed dose point in `clonogenic.csv`, compare vs observed.
4. **SLD repair (Eqs 3-4)** — exponential fits of survival vs inter-fraction interval, joint fit with shared repair half-life across mixed-field conditions. Writes `evidence/sld_fits_and_rbe.json`.
5. **RBE_SLD (Eq 8)** — Delta-ln-S ratio at 0.5 h vs 6 h intervals between mixed-field and X+X conditions.
6. **Foci kinetics (Fig 1)** — 3-parameter exponential decay to plateau, per cell line per quality. Writes `evidence/foci_fits.json`.
7. **Cluster-foci model (Fig 5c-d)** — Poisson-mixture; observed-foci probability = 1 - Product(P(all constituent DSBs repaired)). Free parameters: N_cl, F, residual P. Writes `evidence/cluster_foci_fits.json`.
8. **Fig 4 DSB/Gy analytic surrogate** — simple-nucleus (R=2.5 um) with SSBs uniform along track, DSB pair criterion 3.2 nm intra-track opposite strands. Writes `evidence/fig4_dsb_vs_let.json`.
9. Consolidated `evidence/summary.json` with all above.
