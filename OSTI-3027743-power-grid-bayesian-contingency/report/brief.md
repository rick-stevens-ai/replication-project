# Brief

**Paper:** OSTI 3027743 — Casaprima, Dhulipala, Olivier, Hruska (INL/USC, 2025). "Improving trustworthiness of data-driven power grid contingency analysis with Bayesian residual graph neural networks."

**What/why:** The paper proposes a Bayesian residual **graph** neural network (GNN) surrogate for AC power-flow contingency analysis. It combines (i) residual learning against a DC power-flow low-fidelity model, (ii) an ensembling-with-anchoring scheme for approximate posterior inference, (iii) a novel layer-wise non-isotropic parameter prior derived by moment propagation through both dense and graph layers, and (iv) a low-rank SVD-based correlation-aware NLL / miscalibration metric for the high-dimensional graph output. The IEEE 14-bus and 118-bus test cases are used; the code is proprietary.

**Independent replication approach:** The paper's data-availability statement declares code proprietary, so we re-implemented the method end-to-end. We used **pandapower** (open source) to generate an IEEE 14-bus dataset with the exact split described (1280 train, 50/30/20% by contingency order; 1200 test, 400 per level), ran Newton-Raphson (high-fidelity) and DC (low-fidelity) power flow per sample, and trained a **40-member anchored ensemble** of small fully-connected residual networks in PyTorch using the paper's layer-wise He-style variance prior (Eq. 11) and Eq. 7 training loss. We deliberately used an FNN rather than the paper's Encoder→GNN→Decoder architecture (a fair simplification given proprietary code), so our result represents a **lower bound** on achievable performance. All three key claims — monotone n-0<n-1<n-2 RMSE ordering, calibration of predicted uncertainty, and the correlation-aware SVD miscalibration metric — were tested.

**Result:** PARTIAL replication. The qualitative claims survive (RMSE ordering, uncertainty roughly aligned with error, low-rank calibration differs from diagonal), but absolute error magnitudes are 2–10× the paper's Table 1 values — consistent with the FNN-vs-GNN architectural gap and the fact that GNNs are known to substantially outperform FNNs on graph-structured power-flow tasks.
