\section{Open questions and next probes}

The following five open questions arise directly from what this replication did \emph{not} exercise (Scoary pan-GWAS, hierBAPS clustering, full 114/498-genome scale, RAxML with bootstrap, tool substitution) and from what has changed since the 2017 paper (10$\times$ more public genomes, modern pan-genome tools like Panaroo). Each next-step is scoped to free-tier compute available on uicgpu.

\begin{enumerate}
    \item \textbf{Does the open pan-genome and $\sim$60{,}000-gene estimate hold at 5000+ genomes?}\\
    \emph{Basis:} This replication used 27 genomes; Bazinet used 114--498; NCBI now holds $\sim$10$\times$ more B.\ cereus s.l.\ assemblies (2024--2026 deposits). Whether openness persists at the new scale, and whether the accumulation curve finally shows any saturation, is the natural sanity check on C1/C6.\\
    \emph{Next steps:} Pull current BV-BRC B.\ cereus s.l.\ set (filter by 95\% ANI to reference strains), subsample at N = 100, 500, 1000, 2500, 5000, run Roary or Panaroo at 80\% identity on each, fit Heap's-law $n = \kappa N^\alpha$ to pan and core curves, report $\alpha$ ($\alpha<1$ = open). Free tier: NCBI Datasets + Panaroo on uicgpu.

    \item \textbf{Method vs sampling: how much of the 251-vs-2415-vs-600 core-count discrepancy is Roary CD-HIT/BLAST clustering vs Bazinet's HaMStR ortholog recovery?}\\
    \emph{Basis:} Core counts in this replication varied 10$\times$ (251 to 2415) with sampling and clustering-identity, vs Bazinet's 600 with HaMStR on 114 genomes. A head-to-head Roary vs Panaroo vs OrthoFinder run on identical input isolates method from sampling.\\
    \emph{Next steps:} On the 27-genome Prokka input already on disk, run Panaroo (with paralog-splitting and gene-model correction), OrthoFinder, and PIRATE side-by-side at identical thresholds (99\% presence, 80\% identity). Predict: Panaroo lifts the divergent-set core well above Roary's 251.

    \item \textbf{Do virulence/AMR gene families (cry, hbl, nhe, cytK, ces; pXO1/pXO2; bla, tet, van) distribute clade-restrictedly or crossvia HGT?}\\
    \emph{Basis:} Bazinet's Scoary pan-GWAS was not reproduced here. Whether the paper's clade model predicts virulence-gene distribution, or whether HGT scrambles it, is a first-order biological question implied by the pan-genome table but not tested.\\
    \emph{Next steps:} Annotate the 48{,}118 Roary clusters (Run A) against CARD (AMR) and VFDB (virulence); compute per-cluster clade-specificity via Fisher's exact test against the Clade-1/2/3 assignment; flag clusters with p $>$ 0.5 as HGT candidates. All free-tier.

    \item \textbf{Is B.\ cereus s.l.\ anomalously open compared to peer Bacillus complexes (subtilis group, megaterium group)?}\\
    \emph{Basis:} Bazinet analyzed one species-complex in isolation; comparative context (is 60k genes typical for a Bacillus complex or unusually large?) requires matched runs on peer complexes.\\
    \emph{Next steps:} Assemble matched 100-genome sets for (i) B.\ cereus s.l., (ii) B.\ subtilis group, (iii) B.\ megaterium group; identical Prokka + Roary (80\% i) pipeline; report pan size, core size, Heap's $\alpha$ per group. Predict: cereus s.l.\ openness comparable to subtilis but pan size shifted up by $\sim$1.5 Mbp accessory content.

    \item \textbf{Can supervised ML on the accessory-gene presence/absence matrix distinguish B.\ anthracis from its near-neighbors in B.\ cereus s.s.\ at $>$99.98\% chromosomal ANI?}\\
    \emph{Basis:} This replication confirmed the anthracis-nested-in-cereus result (C4) but did not test whether chromosomal accessory content alone can rescue species-ID (pXO1/pXO2 plasmids being the classic discriminant). This is important for BV-BRC's own species-assignment and for biosurveillance.\\
    \emph{Next steps:} Use \texttt{panacc\_clade1\_new.Rtab} as features, anthracis/non-anthracis as label; train leave-one-strain-out logistic-regression + random-forest; report per-strain confusion, top-k discriminating clusters, and whether removing pXO1/pXO2-linked clusters collapses accuracy. Scikit-learn on uicgpu CPU, minutes.
\end{enumerate}
