\section{Paper summary}

Wang et al.\ propose a closed-form mechanistic cell-survival model that links Monte-Carlo Damage Simulation (MCDS)-derived DSB induction to clonogenic survival via a Poisson NHEJ-misrepair process. The formulation is \emph{not} an ODE system --- it is an algebraic substitution of Poisson probabilities for correct joining ($P_{\text{correct}}$) into a lethal-event count $N_{\text{death}} = \mu_y \, Y D \, P_{\text{contribution}} \, (1 - P_{\text{correct}})$ and a Poisson survival $S = \exp(-N_{\text{death}})$.

\paragraph{Inputs (per radiation quality, from MCDS):}
$Y$ = DSB yield/cell/Gy; $\lambda$ = DSBs/primary particle; $n_p$ = avg primaries producing $\geq 1$ DSB per cell; $\lambda_p$ = avg DSBs per primary (given a DSB was produced). $(n_p,\lambda_p)$ are derived from $(Y,\lambda)$ via eqs.\ (5)--(6).

\paragraph{Fit parameters (6 per cell line):} $\mu_x, \mu_y, \zeta, \xi, \eta_{\lambda_p\to 1}, \eta_{\lambda_p\to\infty}$.

\paragraph{Core equations:}
\begin{align*}
P_{\text{interaction}} &= \frac{1 - e^{-\eta(\lambda_p) n_p}}{\eta(\lambda_p) n_p} \tag{7}\\
\eta(\lambda_p) &= \eta_\infty - \frac{\eta_\infty - \eta_1}{\lambda_p} \tag{8}\\
P_{\text{track}} &= \frac{1 - e^{-\xi \lambda_p}}{\xi \lambda_p} \tag{9}\\
P_{\text{correct}} &= \mu_x \, P_{\text{track}} \, P_{\text{interaction}} \tag{10}\\
P_{\text{contribution}} &= \frac{1 - e^{-\zeta \lambda_p}}{\zeta \lambda_p} \tag{11}\\
N_{\text{death}} &= \mu_y \, Y D \, P_{\text{contribution}} \, (1 - P_{\text{correct}}) \tag{13}\\
S &= \exp(-N_{\text{death}}) \tag{15}
\end{align*}
Eqs.\ (18)--(19) give the low-dose LQ limit ($\alpha,\beta$) via Taylor expansion at small $n_p$; eq.\ (20) gives the analytic $\alpha/\beta$ ratio.

\paragraph{Cell lines / data:} HSG (human salivary gland tumour, 6 Gbp) and V79 (Chinese hamster, 5.6 Gbp). 54 HSG + 52 V79 clonogenic-survival curves from the PIDE database (based on Furusawa et al.\ 2000, \textit{Radiat.\ Res.} \textbf{154}, 485--496). DSB yields from MCDS (Stewart 2011). Ion types: e$^-$, H, He-3, C-12, Ne-20, Fe-56.

\section{Method used in this replication}

\subsection{Model implementation (\texttt{src/wang2018\_model.py})}
Line-for-line implementation of eqs.\ (1)--(20). Each $(1 - e^{-x})/x$ term has a numerically safe small-$x$ Taylor branch. Algebraically verified: (a) eq.\ (8) limits exactly reproduce the Table 1 $\eta_{\lambda_p\to 1}$ and $\eta_{\lambda_p\to\infty}$ values; (b) $P_{\text{contribution}}$ and $P_{\text{track}}$ monotonically decline with $\lambda_p$; (c) the closed-form $\alpha/\beta$ from eqs.\ (18--20) grows roughly linearly with $\lambda_p$ at high LET, consistent with Fig.\ 6.

\subsection{X-ray survival: the $Y_X$ ambiguity}
At low LET, $\lambda_p \to 1$ and $n_{p,\text{perGy}} \to Y$. With Table 1 parameters fixed, the only remaining unknown is $Y_X$ --- and \textbf{Wang 2018 does not publish the MCDS input $Y$ table it used}. Three scenarios were tested:

\begin{enumerate}[nosep,leftmargin=1.4em]
\item $Y_X$ from McMahon 2017 MCDS calibration (5.738 DSB/Gy/Gbp): HSG 34.4, V79 32.1.
\item $Y_X$ solved to match the paper's D10: HSG $\approx$55.5, V79 $\approx$50.9.
\item $Y_X$ from Kukla's independent MCDS 3.10A run (low-LET limit): $\approx$8.3.
\end{enumerate}

Only scenario 2 (which treats $Y_X$ as a free parameter) reproduces the paper's D10 values. Scenarios 1 and 3, both grounded in first-principles MCDS, over-predict D10 by 60\%--570\%. This ambiguity is a \emph{real artefact of the paper omitting its MCDS input table}, not a bug in the replication.

\subsection{Data blockers}
\begin{itemize}[nosep,leftmargin=1.4em]
\item \textbf{PIDE v3.2}: registration-gated (institutional email + manual approval). Blocks the 106 raw survival-curve LQ refits.
\item \textbf{Furusawa 2000 raw points}: BioOne paywall. Same blocker.
\item \textbf{MCDS Fortran tool}: free download; not installed in the original replication window. Kukla's later MCDS 3.10A run partially closes this gap but only for the Y(LET) input, not the fit.
\item \textbf{Furusawa $\alpha,\beta$ vs LET table}: not extracted (available implicitly via PIDE).
\end{itemize}

\section{Critique --- honest assessment of what did and didn't work}

\subsection{What worked}
\begin{itemize}[nosep,leftmargin=1.4em]
\item \textbf{Model algebra reproduces exactly.} All 20 equations implemented, all limit cases verified, all Table 1 $\eta$ limits reproduce to the printed precision.
\item \textbf{Closed-form LQ collapse works.} Eqs.\ (18)--(20) recovered from Taylor expansion --- the paper's mathematics is internally consistent.
\item \textbf{Qualitative LET trends match.} $\alpha$-peak location, $\beta$-decline, and $\alpha/\beta$-rise-with-LET all reproduce.
\end{itemize}

\subsection{What did not work}
\begin{itemize}[nosep,leftmargin=1.4em]
\item \textbf{The published parameterization is not first-principles-reproducible.} The Table 1 parameters + \emph{any} independent MCDS-derived $Y_X$ (McMahon 34; Kukla-MCDS-3.10A 8) fail to reproduce D10 to within a factor of 1.6--6. The parameters only ``work'' when $Y_X$ is free-fit to the D10 --- which is circular.
\item \textbf{Raw-curve refits (106 curves) not performed.} PIDE registration + Furusawa paywall blocked the primary fitting exercise. The paper's central methodological claim --- that the 6-parameter model fits 106 curves with the quoted $R^2$ values --- is untested here.
\item \textbf{RBE claims (mixed beam, cross-particle) untested.} Requires per-particle MCDS $Y(\text{LET}), \lambda(\text{LET})$ tables that would need MCDS installed and run for each of the 5+ ion species.
\item \textbf{The 2026-06-21 MCDS promotion test failed.} It was designed to close the $Y_X$ gap using Kukla's fresh MCDS run and would have promoted PARTIAL$\to$REPLICATED. Instead, first-principles $Y_X \approx 8$ gave D10 27--30 Gy (paper: 4.08/7.07 Gy). The test strengthened, not overturned, the PARTIAL verdict.
\end{itemize}

\subsection{Which claims were tested vs.\ assumed}
\begin{itemize}[nosep,leftmargin=1.4em]
\item \textbf{LET dependence:} \emph{Qualitatively tested} (peak location, $\alpha/\beta$ trend). \emph{Not quantitatively tested} (no $R^2$ against Furusawa/PIDE data).
\item \textbf{Mixed-beam prediction (Fig.\ 5):} \emph{Not tested.} Requires MCDS per particle and PIDE mixed-beam curves.
\item \textbf{Dose-rate dependence:} \emph{Not addressed by the paper} (single-dose-rate assumption is baked into the Poisson NHEJ model). Not a replication gap; a paper limitation.
\item \textbf{In-sample vs out-of-sample fit:} The paper fits and evaluates on the same 106 curves --- \textbf{no held-out validation set}. The reported $R^2$ values are in-sample. This is a paper-side methodological weakness worth calling out.
\item \textbf{DSB$\to$lethal-lesion conversion:} \emph{Phenomenological}, not mechanistic. The $\mu_y, \zeta, \xi, \eta$ parameters are effective fit coefficients, not derived from NHEJ biochemistry. The paper frames this as a mechanistic model; more precisely it is a semi-empirical framework whose functional forms are motivated by Poisson misrepair heuristics.
\end{itemize}

\subsection{Residual uncertainty}
The $Y_X$ ambiguity is the load-bearing uncertainty. Without the paper's original MCDS input table, no third party can distinguish between: (a) Wang used a non-standard MCDS configuration that happens to give $Y_X \approx 55$; (b) the Table 1 parameters absorb calibration errors from a different $Y_X$; (c) the reported D10 values themselves are anchored to a specific experimental subset whose MCDS pre-processing is undocumented. This is not resolvable from published information alone --- resolving it requires either the authors' MCDS input files or a from-scratch full-fit rerun on the 106 PIDE curves.
