# Failure Analysis: BVBRC-43 (Akter 2023 E. faecalis fish streptococcosis)

**Verdict:** PARTIAL REPLICATION (strong). This document is a candid accounting of what did **not** replicate, what was **not tested**, and why — separate from the (also self-critical) GENUINE CRITIQUE section in REPORT.tex.

## 1. Claims not tested (out of scope this pass)

### 1.1 C4 — Bacteriocin / secondary-metabolite clusters (antiSMASH)
- **Paper claim:** bacteriocin gene clusters in BFFF11 and BFPS6; NRPS in BFFF11.
- **Status:** UNTESTED.
- **Why:** antiSMASH 5.1.2 was not rerun this pass. This is the paper's second-most specific claim and remains the largest untested surface.
- **What would close it:** run antiSMASH 7.x on each of the three fish genomes and compare cluster inventories and boundary calls to the paper's Table.

### 1.2 PHASTER prophages, ISfinder IS elements, PlasmidFinder replicons
- **Paper claims:** descriptive inventories only.
- **Status:** UNTESTED.
- **Why:** deprioritized under the wave's "test the concrete high-signal claims first" scope. PlasmidFinder is the highest-leverage of these because it would resolve whether the BFPS6 tet(L)+tet(M) cassette is on a plasmid vs chromosomally integrated — directly relevant to open question #3 (one-health AMR transfer).
- **What would close them:** rerun each tool; for PlasmidFinder specifically, long-read resequencing of BFPS6 to close contig NZ_JADBGH010000009.1 would give a definitive plasmid vs chromosome answer.

### 1.3 Wet-lab phenotype claims
- **Paper claims:** disc-diffusion / MIC results (where reported).
- **Status:** OUT OF SCOPE for in-silico replication.
- **Note:** genotype (tet(L)+tet(M) in BFPS6) → phenotype (tetracycline resistance) inference is highly likely from prior literature but is not evidence generated by this replication.

## 2. Claims tested but only partially matched

### 2.1 C2 — 39 AMR genes across 16 groups (paper count)
- **Result:** conserved-core structure (lsa(A) in all three) confirmed; **the aggregate count of 39 was NOT reproduced.**
- **Why (not a failure of biology, a difference of framework):** AMRFinderPlus 3.12.8 (curated acquired-AMR calls) excludes intrinsic/housekeeping/point-mutation loci — gyrA, gyrB, rpoB, rpoC, murA, EF-Tu, EF-G, folA, folP, Alr, Ddl, MprF, LiaFSR, etc. — that CARD RGI / ARG-ANNOT / ResFinder (homology mode) count. This is a well-known and documented divergence between tool families; the paper's 39-gene tally aggregates all four tool outputs (ResFinder + ARG-ANNOT + CARD RGI + PATRIC).
- **Honest framing (per GENUINE CRITIQUE §2 of REPORT.tex):** we did not test the 39-gene claim; we tested a stricter claim (acquired-AMR only) and got a different number — expected under the framework change. To actually test the paper's 39, we would need to rerun the paper's exact four-tool union.

### 2.2 C5 — Phylogeny / clustering
- **Paper claim:** BFF1B1 + BFFF11 cluster together; BFPS6 branches separately (CSIphylogeny SNP tree, V583-referenced).
- **Result:** directionally consistent (BFFF11 closest to V583; three distinct STs) but ANI saturates at ~98.7% between all three fish strains — cannot definitively resolve the exact topology.
- **Why:** fastANI at species level (98–99% range) is inside the noise band of the tool and does not reliably order three strains. MLST distinguishes the strains (BFF1B1 = ST482, BFPS6 = ST81, BFFF11 = novel/untyped) but is not a topology test.
- **What would close it:** rerun CSIphylogeny (or Parsnp / kSNP3 / snippy → RAxML) with V583 as reference and inspect the actual tree topology.

### 2.3 C1 — 69 virulence genes (paper count)
- **Result:** conserved-core marker structure and the specific agg/prgB differential both confirmed at the marker level; the **aggregate count of 69 was NOT reproduced.**
- **Why:** paper's 69 is a VFDB + VirulenceFinder + PATRIC_Victors union; our 13-marker curated V583 query is deliberately narrower and probes only well-characterized VFs.
- **What would close it:** rerun VFDB VFanalyzer (as the paper used) on each fish genome and compare gene inventories.

## 3. Assembly-quality caveats

### 3.1 BFPS6 tet-allele completeness
- **Paper:** four tet alleles — tet(M), tet(L), tet(S), tet(45).
- **Replication:** confirmed tet(L) + tet(M) at 100% id / 100% cov, tandem on NZ_JADBGH010000009.1; **did NOT confirm tet(S) or tet(45).**
- **Why (multi-cause, honest):**
  1. Curation gap — AMRFinderPlus's curated DB may not include the specific tet(S) / tet(45) allele variants the paper's tools called.
  2. Allele-divergence — variants below AMRFinder's threshold that ARG-ANNOT-style homology mode still picks up.
  3. Draft-assembly artifact — BFPS6 is a 45-contig draft; tet(S) or tet(45) could sit on an unassembled fragment.
- **Robustness of the C3 claim:** the **exclusivity direction** (tet only in BFPS6) is fully confirmed; the **BFPS6 has all four tet alleles** sub-claim is not something we can verify or refute from the deposited draft with a single-tool call.

## 4. Methodological gaps disclosed

### 4.1 V583-anchoring bias in the VF marker panel
- The 13 VF markers were sourced from V583 (canonical human clinical reference). If fish-adapted E. faecalis carries divergent VF alleles, tblastn at pident≥80/qcov≥70/e≤1e-20 may **under-report** them.
- Direct consequence: cylLS / cylLL absence in all three fish strains cannot be cleanly distinguished from "true absence" vs "allele divergence below threshold." The paper itself reports cyl as weak/inconsistent, so our result is consistent with the paper but the deeper question is unresolved.

### 4.2 Framework-substitution ≠ framework-equivalence
- We replaced four AMR tools (ResFinder + ARG-ANNOT + CARD RGI + PATRIC) with one (AMRFinderPlus). Independent tool ≠ four-tool consensus.
- This produces a fundamentally different acquired-only view of AMR and a smaller count — appropriate for validating the exclusivity claim (C3), less appropriate for validating the total-count claim (C2).

### 4.3 LLM-judge is a consistency check, not an external oracle
- The `argo:gpt-5.2` judge returned the same PARTIAL verdict; it was prompted with our evidence bundle and our claim structure. It usefully catches internal contradiction; it does not constitute an independent third-party replication.

## 5. What would upgrade this to FULL replication

In descending order of leverage:

1. **antiSMASH 7.x rerun on all three genomes (C4).** Currently the largest untested surface.
2. **VFDB VFanalyzer rerun on all three genomes (C1).** Would validate/refute the 69-count.
3. **CSIphylogeny SNP rerun with V583 reference (C5).** Would give a definitive topology test.
4. **Four-tool AMR union (ResFinder + ARG-ANNOT + CARD RGI + PATRIC) rerun (C2).** Would validate/refute the 39-count.
5. **PlasmidFinder + long-read reassembly of BFPS6.** Would resolve the tet-cassette plasmid context and close the BFPS6 tet-allele completeness question.
6. **PHASTER + ISfinder reruns.** Descriptive inventories; low-priority but easy.

## 6. What did NOT go wrong (honest)

- Data availability: all four assemblies still resolvable and downloadable, no dead accessions.
- Tool availability: all tools free and functional (AMRFinderPlus, mlst, fastANI, BLAST+, Python, Argo).
- Cost: zero — no paid API needed, ~10 min compute, no GPU.
- Positive control: V583 recovered its expected AMR set (vanB, erm(B), aac(6')-aph(2''), qacZ) — the acquired-AMR pipeline is functioning correctly, so tilapia-strain tet-negative calls are not false negatives.
- No claim tested was **contradicted** by the replication.
