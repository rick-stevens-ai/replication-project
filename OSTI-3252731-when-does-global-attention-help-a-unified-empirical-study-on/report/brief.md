# Brief — OSTI 3252731

Chowdhury & Pasini (ORNL, 2026, J. Cheminform. 18:54) present a unified, controlled empirical study of when global attention (GPS-style transformer blocks) actually helps MPNN-based graph neural networks on 7 open atomistic benchmarks (QM9, ZINC, TMQM, NIAID, OGB-PCQM4Mv2, OGB-PPA, OGB-molPCBA), using their public HydraGNN framework with four toggleable schemes (S1: MPNN only, S2: MPNN+encoders, S3: MPNN+GPS, S4: MPNN+encoders+GPS). Independent replication verified: (a) HydraGNN GitHub repo is public and current; (b) the GPS/global-attention module, all 13 MPNN stacks, and the qm9 driver that switches schemes at CLI are actually present in code; (c) both an S1-style (MPNN only) and an S3-style (MPNN+GPS) SchNet run train end-to-end on the QM9 1000-molecule example on 1× A100, and adding GPS increased peak training GPU memory from 0.0755 GB to 0.1174 GB (+55.6 %), directly supporting the paper's stated "attention memory overhead" claim.
