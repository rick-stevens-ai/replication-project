\section{Paper summary}

APBS (Adaptive Poisson-Boltzmann Solver) is an open-source package for
numerically solving the Poisson-Boltzmann equation (PBE) over biomolecular
geometries. This paper is the periodic ``software refresh'' (v1.5 era)
covering: (i) new finite-difference and finite-element solvers; (ii)
integration of the TABI-PB boundary-element method; (iii) a geometric-flow
non-polar solvation module; (iv) tighter coupling with PDB2PQR (structure
preparation, ligand parameterization, membrane systems); (v) Python
bindings; (vi) an updated regression test suite. The methodological core
(multigrid FD Poisson-Boltzmann) is essentially unchanged from earlier
APBS releases; the paper's central claim is that the software works, is
numerically stable, and continues to serve the biomolecular community ---
reflected by the citation count.

Because APBS is a \emph{software} paper, the strongest independent-replication
test is: \textbf{install the current APBS + PDB2PQR, run the bundled canonical
benchmarks, and confirm they match published (per-version) reference values.}
That is exactly the test performed here.

\subsection{Manual Born-ion analytical check}
Hand-wrote a two-state input (\texttt{sdie=78.54} vs \texttt{sdie=1.0}).
Analytical answer for a 3 \AA, $+1$ e Born ion is
$-691.85 \cdot z^2 / R = -230.62$ kJ/mol.
\begin{lstlisting}
apbs born/born.in    # -> -229.5879 kJ/mol
\end{lstlisting}

\subsection{Independent case: 1AKI lysozyme}
\begin{lstlisting}
curl -sL https://files.rcsb.org/download/1AKI.pdb -o 1AKI.pdb
pdb2pqr30 --ff=AMBER --apbs-input=1AKI.in 1AKI.pdb 1AKI.pqr
# then hand-wrote 1AKI_solv.in (two-state focusing MG-auto, dime 129^3,
# LPBE, pdie=2, sdie=78.54/2.0, 150 mM NaCl, T=298.15 K,
# srfm smol, srad 1.4, chgm spl2, sdens 10, bcfl sdh)
apbs 1AKI_solv.in                                # -> -4345.23 kJ/mol
sed 's/dime 129 129 129/dime 161 161 161/g' 1AKI_solv.in > 1AKI_solv_fine.in
apbs 1AKI_solv_fine.in                           # -> -4258.03 kJ/mol
\end{lstlisting}

\section{Genuine critique}

This section deliberately steps out of the ``verdict'' voice to record
independent, adversarial concerns about the paper, the software, and the
replication as performed.

\subsection*{On the paper}

\begin{itemize}
  \item \textbf{Software papers as citation attractors.} The 2{,}081-citation
        count reflects APBS's role as \emph{the} canonical PBE tool much
        more than any specific novel result in this 2017 paper. Most
        citations are ``we used APBS, [Jurrus 2018]'' methods-line
        citations. The paper is a periodic refresh --- its scientific
        claim surface is genuinely thin.
  \item \textbf{Improvements list is not benchmarked head-to-head.} The
        paper advertises new solvers (TABI-PB, geoflow) and coupling
        features but does not present head-to-head accuracy/performance
        tables against the pre-existing FD-multigrid path on a common
        biomolecular test set. A reader cannot easily tell \emph{when} to
        prefer TABI-PB over MG-auto without reading the underlying
        method papers.
  \item \textbf{Reference values in the regression README are
        under-documented.} The per-version numbers we reproduce to 6+
        decimals are treated as ground truth, but the README does not
        explain the exact grid, boundary condition, or solver options
        used to generate them beyond what is in the input file --- so
        ``reproduce to 6+ decimals'' means ``the multigrid solver is
        deterministic on the same input,'' not that the reference values
        are anchored to a converged / analytical answer.
\end{itemize}

\subsection*{On the numerics}

\begin{itemize}
  \item \textbf{Born discrepancy sign and size.} The bundled
        \texttt{apbs-mol-auto.in} result ($-229.7736$) sits 0.37\% away
        from the analytical answer ($-230.62$). The manual tutorial input
        gives $-229.59$ (0.45\%). Both underestimate the magnitude,
        consistent with the well-known finite-difference dielectric
        boundary blurring, but the paper does not discuss residual
        discretization bias in its self-tests.
  \item \textbf{1AKI 2\% grid-refinement gap} between $129^3$ and $161^3$
        is normal but non-trivial for a 129-residue protein. A production
        study would need at least one more refinement level and a
        Richardson-style extrapolation --- the ``pipeline works'' claim
        should not be mistaken for a converged solvation energy.
  \item \textbf{LPBE vs NPBE.} All tests here used the linearized PBE.
        The paper's contribution list emphasizes highly-charged systems
        (nucleic acids, membranes) where the nonlinear PBE is required;
        none of those regimes were touched by this replication.
\end{itemize}

\subsection*{On this replication}

\begin{itemize}
  \item \textbf{Coverage was breadth-first, not depth-first.} C1--C5
        confirm the software \emph{runs and is stable}. C6--C8 (TABI-PB,
        geoflow, Python API) were skipped; a stronger replication would
        rebuild APBS with the boundary-element and geoflow backends
        enabled and compare TABI-PB vs MG-auto on a shared benchmark.
  \item \textbf{Single-machine, single-compiler.} All numbers come from
        one conda-forge binary on one Linux host. A more defensible
        replication would repeat on macOS/ARM and a source build with
        a different BLAS to expose any platform-dependent numerical
        drift.
  \item \textbf{No comparison to explicit-solvent MD.} The paper is
        implicitly claiming that continuum PBE solvation is a useful
        approximation. That claim is not tested here (see
        \texttt{open\_questions.json}).
  \item \textbf{LLM-judge concurrence is confirmatory, not independent.}
        The Argo \texttt{gpt-5} judge saw the same evidence pack; its
        99\% agreement should be read as ``the writeup is internally
        consistent,'' not as independent scientific validation.
\end{itemize}

\subsection*{What a stronger replication would add}

\begin{enumerate}
  \item Build APBS from source with TABI-PB and geoflow enabled; run the
        shared example set through all three solvers and tabulate deltas.
  \item Run the nonlinear PBE on a highly-charged nucleic-acid test
        case; report Newton-iteration convergence behavior.
  \item Compare APBS polar solvation to a matched TIP3P/MD FEP
        calculation on a small drug-like molecule (single-ion, methanol,
        or a Mobley-set molecule) to quantify the continuum-vs-explicit
        gap.
  \item Repeat the regression suite on macOS/ARM and on a source build
        with an alternate LAPACK to expose any platform-dependent
        rounding.
\end{enumerate}
