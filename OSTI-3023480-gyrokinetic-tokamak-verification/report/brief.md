# Brief — OSTI 3023480

Huang et al. (Nucl. Fusion 66, 036050, 2026) use the global gyrokinetic PIC code GTC to verify a Beta-induced Alfvén-Acoustic Eigenmode (BAAE) in ST40 discharge #09894. In the ideal-MHD limit GTC agrees with the NOVA MHD eigenmode code on mode structure; with kinetic thermal ions GTC finds the same BAAE unstable at f ≈ 90 kHz, γ/ω ≈ 0.06, driven by ion pressure/temperature-gradient resonance. With energetic particles included the mode damps out, contradicting the ST40 experimental observation that the mode persists — the authors attribute this to the isotropic-Maxwellian EP approximation. We independently reproduce the analytic BAE/BAAE-gap frequency (≈90 kHz for T_e=4.18 keV, q≈2.5 at the mode-peak radius), the ion diamagnetic drift frequency (~97 kHz for L_n≈a/5), the sub-TAE character (TAE gap 588 kHz ≫ observed 100–150 kHz), and the δB∥/δB⊥ order of magnitude from β_th ≈ 8%. Full GTC/NOVA rerun is out of scope (no INCITE allocation, source code not on hand).
