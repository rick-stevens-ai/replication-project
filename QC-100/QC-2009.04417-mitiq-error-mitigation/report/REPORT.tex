\paragraph{Paper.} LaRose et al., \emph{Quantum} \textbf{6}:774 (2022), arXiv:2009.04417v4, DOI \href{https://doi.org/10.22331/q-2022-08-11-774}{10.22331/q-2022-08-11-774}. Code: \url{https://github.com/unitaryfund/mitiq}. Open access, CC-BY 4.0.

\paragraph{Verdict.} \textbf{REPLICATED.} The paper's central \emph{capability} claim --- that Mitiq's Zero-Noise Extrapolation (ZNE) and Clifford Data Regression (CDR) each produce error-mitigated expectation values measurably closer to the noiseless truth than the raw noisy expectation value --- is directly reproduced on independent Qiskit-Aer + Cirq simulations of small 2-qubit circuits under depolarizing noise. Three ZNE inference methods (Richardson, quadratic polynomial, linear) all yielded post-mitigation errors strictly smaller than raw noisy; CDR converged to the exact noiseless value on a Clifford-dominant circuit.

\section{What was tested}
Two independent replication scripts (\texttt{code/zne\_replicate.py}, \texttt{code/cdr\_replicate.py}) run real simulations on CPU using \texttt{mitiq 1.0.0}, \texttt{qiskit 2.5.0}, \texttt{qiskit-aer 0.17.2}, and \texttt{cirq 1.7.0}.

\begin{itemize}
  \item \textbf{ZNE (Fig.~3 headline).} 10 random 2-qubit RB-like circuits (depth 8, layered $R_z R_x R_z$ + CX, then exact inverse; noiseless $\langle 00|\rho|00\rangle=1$). Noise: Qiskit-Aer depolarizing with $p_1=0.01$, $p_2=0.04$. Three factories: \texttt{RichardsonFactory}, \texttt{PolyFactory(order=2)}, \texttt{LinearFactory}, all with \texttt{scale\_factors=[1.0, 2.0, 3.0]} and \texttt{fold\_gates\_at\_random}.
  \item \textbf{CDR (\S6 bonus).} 7-op 2-qubit Cirq circuit with $H$, CNOT, $R_z$ rotations; observable $Z\otimes I$; noise \texttt{cirq.depolarize(p=0.02)} per moment; exact density-matrix simulation; \texttt{execute\_with\_cdr(num\_training\_circuits=10, fraction\_non\_clifford=0.2)}.
\end{itemize}

\section{Headline-exercised check}
The paper's \emph{operational headline} is the demonstration that Mitiq's one-line calls (\texttt{execute\_with\_zne}, \texttt{execute\_with\_cdr}) reduce observable error on noisy circuits. This exact API was called on two independently-constructed circuit families with two different simulators (Qiskit-Aer + Cirq), and in every case the mitigated value beat the raw noisy value. \textbf{Headline: exercised and confirmed.}

\section{Honest critique --- what was NOT reproduced}
\begin{itemize}
  \item \textbf{Fig.~3 exact numeric values.} The paper's Fig.~3 uses \emph{real hardware} traces (IBMQ London, Rigetti Aspen-8). We used a Qiskit-Aer depolarizing noise model. The capability claim replicates; the exact error magnitudes are not directly comparable because the noise channel is different (idealized depolarizing vs.\ real device noise with coherent errors, readout error, drift, and crosstalk).
  \item \textbf{Fig.~4 (H$_2$ VQE PES).} Not attempted. This would require the additional \texttt{openfermion} + \texttt{openfermion-pyscf} stack and $\sim$5 min per bond-length point. The Fig.~3 headline was chosen as the more direct capability test.
  \item \textbf{Probabilistic Error Cancellation (\S5).} Not exercised. The paper's own PEC example is a template rather than a headline numerical claim, but a full replication would still verify PEC on a small circuit.
  \item \textbf{Cross-technique comparison.} We tested three ZNE variants and CDR, but did \emph{not} put them head-to-head on the same circuit / same observable / same noise level. The paper (\S3.1) itself declines to declare a winner, so this is not a claim to falsify --- but a rigorous cross-technique study is still outstanding here.
  \item \textbf{pyQuil / Braket adapters.} Only Cirq and Qiskit frontends were tested. C8 (framework-agnosticism) is only partially verified.
  \item \textbf{Hardware runtime.} \emph{No real quantum hardware was used.} All results are on classical simulators. The paper's Fig.~3 hardware runs (which drive their $\sim$2--3$\times$ error reductions) are the aspirational headline; we replicated the capability on simulators only.
\end{itemize}

\section{Verdict rationale}
The paper is fundamentally a \emph{software-package} paper. Its main empirical claims are: (i)~the package installs and is usable, (ii)~its one-line APIs produce mitigated results, (iii)~those mitigated results beat raw noisy on canonical toy problems. All three replicated cleanly on a modern Qiskit/Cirq stack with no code changes to Mitiq itself. This is a paradigmatic REPLICATED outcome for a software-tool paper. We stop short of ``REPLICATED (strong)'' because the exact hardware numbers from Fig.~3/4 were not re-produced --- only the capability behind them.
