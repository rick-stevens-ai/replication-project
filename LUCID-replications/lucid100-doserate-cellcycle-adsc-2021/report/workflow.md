# Workflow — Rusin et al. 2021 replication (hADSC dose-rate × cell-cycle)

## 1. Source acquisition
- **Paper.** PLoS ONE 16(4):e0250160 (open access) — downloaded PDF, HTML, and text extract.
- **Raw data.** Mendeley deposit DOI `10.17632/8t594k4w8z.1` (17 files, ~52 MB). Enumerated via
  the public Mendeley Data API. Fetched the 5 `.xlsx` source-data workbooks corresponding to
  Figs 1, 2, 3, 4, 5 (and Fig 8 for completeness), plus the image-only TIFFs. Microscopy RAR
  archives (Fig 7, 9) skipped — qualitative micrographs only.

## 2. Parse and per-replicate extraction
- Each figure's `.xlsx` was parsed with `openpyxl` (via pandas). Per-replicate rows extracted
  under the same block layout the authors used.
- A single off-by-one row-index anomaly in the cell-cycle sheet was isolated by `find_subset.py`:
  a label-vs-data alignment quirk (spreadsheet artifact, not paper claim). Fix documented in
  `find_subset.log`.

## 3. Recompute mean / SD
- Per-condition mean and $n-1$ SD computed with `numpy` (ddof=1).
- Cross-checked against the summary block the authors typed into the same sheet.
- Recorded per-figure to `replication_*_results.json`.

## 4. Statistical re-derivation
- Pairwise Welch's $t$-test via `scipy.stats.ttest_ind(equal_var=False)` across
  {Control, LDR, HDR} for every timepoint / stage / phase / gene.
- Compared each paper-claimed pairwise significance vs the recomputed $p$-value.
- Explicit substitution: paper used JMP Pro 12 one-way ANOVA + unspecified post-hoc; Welch is an
  independent, not-identical check.

## 5. Compare
- 27/27 cell-cycle means match; 27/27 SDs match ($\pm 0.05$ pp).
- 48/48 apoptosis cells match ($\le 0.005\%$).
- 8/8 proliferation contrasts verified; MTS standard curve $y=160797x-29124$ reproduces exactly.
- 6/8 gene-expression contrasts verified; disagreements are all LDR-vs-HDR at borderline $p$.

- **REPLICATED (PARTIAL on stat-pattern boundary).** Verdict preserved from source REPORT.md.
- 41/52 (78.8%) pairwise-significance contrasts agree; disagreements attributable to
  Welch-vs-JMP-post-hoc test choice, not data discrepancy.
