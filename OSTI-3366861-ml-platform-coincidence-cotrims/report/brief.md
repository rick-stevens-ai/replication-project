# Brief — OSTI 3366861 (SCULPT / CoInML)

We independently replicated the D₂O double-ionization case study from Daoud et al., "SCULPT: An Interactive ML Platform for Analyzing Multi-Particle Coincidence Data from COLTRIMS" (Rev. Sci. Instrum. 97(5), 2026; DOI 10.1063/5.0313735). Using the paper's own released Zenodo dataset (10.5281/zenodo.18478576; 953,120 coincidence events over 8 water-dication electronic states) and a fresh Python environment on UICGPU, we computed the paper's four UMAP input features (KER, EESum, TotalE, α₁₂), ran UMAP (n_neighbors=15, min_dist=0.1), applied DBSCAN clustering, re-implemented the paper's adaptive-confidence-score formula (Sec. II.C, Eq. 1) with all tier weights and normalizations, and computed all seven quality metrics reported in the paper's Fig. 3. We recover the paper's headline qualitative outcome — **five stable clusters, high Hopkins clusterability (0.9998 vs paper 0.9769), near-perfect stability (0.9994 vs 0.9996), overall confidence in the High band (0.87 vs 0.71)** — plus an independent physics-validation cross-check (ARI = 0.62 between our DBSCAN clusters and the true 8-state quantum labels), which the paper does not report. Silhouette, Calinski–Harabasz, Davies–Bouldin, and physics-consistency differ quantitatively because the paper does not publish its 1 %-sampling seed or DBSCAN-selected eps, so partition boundaries drift run-to-run as the paper explicitly acknowledges ("These values can vary slightly from run to run"). Verdict (LLM judge, argo:gpt-5.2): **PARTIAL** — the central scientific claim reproduces end-to-end, but several per-metric numbers do not match exactly.
